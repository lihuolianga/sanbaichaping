# 第767章 独立新名再次失控

独立新名亮起来的当天夜里，冒领的怪象就失控了。

先是仙籍档案处。那些独立新名——一个接一个，自己亮起来。像是……像是有一批替身，正同时，给自己起新名字。

然后是接引台下。陶九真的名字，在仙籍上，正一点一点地淡下去。像是……像是他的名字，正被从仙籍上，抹掉。

"名字在淡？"李无咎的脸色沉下来，"那仙籍上的'陶九真'——"

"正在被抹。"宁知微蹲在仙籍前，脸色发白，"像是……像是有人，正在把'陶九真'这个名字，从仙籍上抹掉。像是……像是要换上另一个名字。"

"换上另一个名字？"李无咎说，"换上谁的名字？"

"像是……"宁知微说，"像是独立新名。像是……像是有人，用独立新名，顶替'陶九真'。像是……像是冒领，正从'冒领陶九真'，变成'抹掉陶九真'。"

"李先生！"接引台上，又传来喊声。一个接引小吏跑进来，脸色惨白："李先生，有修士——有修士，忽然被登记成'伪造者'了！他什么也没做——可他的名字，被登记成伪造！"

"又被登记成伪造者？"李无咎冲到接引台下。一个修士，正被接引小吏按着——他喊冤："小人没伪造！小人是来送师父飞升的！小人什么都没做！"

"李先生！"宁知微赶到，"又有人被登记成伪造者了。像是……像是这套登记，正在批量抓人。像是……像是有人，把一批修士，登记成'伪造者'——为了给替身腾位置。"

"给替身腾位置？"李无咎说，"那这套冒领——不只是陶九真一个人？"

"像是。"宁知微说，"独立新名亮起——替身们，正在批量顶替。每顶替一个，就有一个真修士，被登记成'伪造者'。像是……像是有人，在批量制造'伪造者'——为了掩护替身。"

"李先生！"接引台上，又传来喊声。一个接引小吏跑进来，脸色惨白："李先生，陶九真——陶九真的名字，又淡了！像是……像是他的名字，快被抹没了！"

"陶九真的名字快被抹没了？"李无咎冲到仙籍前。仙籍上，"陶九真"三个字，正一点一点地淡下去——像是……像是有人，正把这三个字，从仙籍上擦掉。

"李先生！"宁知微说，"陶九真的名字，快被抹没了。要是名字被抹——他就不是'陶九真'了。他就成了真正的'伪造者'——连名字都没有。"

"那怎么办？"李无咎问。

"要停住名字被抹。"宁知微说，"像是……像是有人，正在抹陶九真的名字。要停——得先找到，谁在抹。"

"李先生！"接引台上，又传来喊声。一个接引小吏跑进来，脸色惨白："李先生，独立新名——那个独立新名，又亮了！这一次，亮得厉害！像是……像是它，正取代'陶九真'！"

"独立新名取代陶九真？"李无咎冲到仙籍档案处。那个独立新名，正剧烈地发着光——像是……像是它，正一点一点，把"陶九真"三个字，从仙籍上挤出去。

"李先生！"宁知微说，"独立新名，正在取代'陶九真'。像是……像是有人，用独立新名，顶掉'陶九真'——让陶九真，从此不存在。"

"李先生！"接引台上，又传来喊声。一个接引小吏跑进来，脸色惨白："李先生，陶九真——陶九真，开口了！他说——他说，'名字，给我。'"

"陶九真说'名字，给我'？"李无咎冲到接引台下。陶九真，正望着仙籍，眼神急切："李先生！名字——那名字，是小人的！小人修行千年——小人就叫陶九真！那名字，是小人的！你们不能——不能把名字，给他！"

"陶真人，"李无咎说，"你的名字，不会给他。可他的名字，也不会给你。"

"李先生！"天上，那个声音响起来："本仙，才是陶九真。本仙的名字——本仙的仙籍——本仙的功德——都是本仙的。地上的老者，他抢本仙的名字——他才是伪造者！"

"你们俩，都想要'陶九真'这个名字？"李无咎说，"可这个名字——到底是谁的？"

"李先生！"接引台上，又传来喊声。一个接引小吏跑进来，脸色惨白："李先生，一个修士——一个修士，带着一样东西，倒在接引台下！他怀里——他怀里抱着一卷东西！像是——像是接引司封口令！"

"接引司封口令？"李无咎冲下接引台。一个陌生的修士，倒在台下，怀里抱着一卷封口令。那封口令——像是从接引司里，流出来的。

"李先生！"宁知微接过封口令，"封口令上写着——'仙籍冒领，封口勿言。言者，以伪造论处。'像是……像是接引司，下了封口令——不许人提仙籍冒领的事。"

"接引司封口？"李无咎说，"那这套冒领——接引司，也知道？"

"像是。"宁知微说，"封口令，是接引司下的。像是……像是接引司，知道仙籍冒领——可他们，封了口，不许人说。"

"李先生！"接引台上，又传来喊声。一个接引小吏跑进来，脸色惨白："李先生，独立新名——又亮了！这一次，它亮着不灭了！像是……像是它，彻底取代了'陶九真'！"

"独立新名彻底取代陶九真？"李无咎冲到仙籍档案处。仙籍上，"陶九真"三个字，已经被淡得看不清了——独立新名，正稳稳地亮着。

"李先生！"宁知微说，"陶九真的名字，被独立新名取代了。像是……像是有人，把'陶九真'从仙籍上抹掉，换上了独立新名。陶九真——他不再是仙籍上的'陶九真'了。"

李无咎沉默了很久。他看着仙籍上那个被淡掉的名字，看着那个亮着的独立新名，终于开口："我没有把握。"他说，"我以为，是登记错误——不，有人培养替身冒领仙籍。我以为，替身是假的——不，替身有自己的记忆，他想独立。我没有把握——我不知道，该怎么把名字，还给陶九真，又不抹掉替身。"

"李先生……"宁知微愣住了。这是她第一次听李无咎，在查案的当口，承认没有把握。

"没有把握，也得查。"李无咎说，"我不知道怎么还名字——可我知道，不能让陶九真的名字，就这么被抹掉。"

风从接引台上吹过来。下界接引台里，独立新名亮着，陶九真的名字淡着，封口令握着。像是这座接引台，正藏着一场"名字争夺"的较量——正等着谁来，找出真正的答案。
