# 第778章 谁在证词里撒了谎

裴氏审批印亮了，这让李无咎决定把证词问全。他把人分开，一个一个叫进议事棚。

第一份证词，来自阿砺。

"阿砺，你买保险牌，是什么时候？"李无咎问。

"是……"阿砺说，"是一个月前。小人攒了三十年，凑了一百两，买了第三档保险牌。"

"一个月前？"李无咎记下，"那你的雷劫，是什么时候渡的？"

"是……"阿砺说，"是半个月前。小人渡劫那天，雷云是第三层。小人运气好——渡过了。"

"你半个月前渡的劫？"李无咎记下，"那你的道友，是什么时候被劈死的？"

"是……"阿砺说，"是五天前。小人的道友，买不起保险，用了最重的雷云——他被劈死了。他的尸骨——被承包场收走了。"

"五天前？"李无咎记下，"那你道友渡劫的时候——雷云，是第几层？"

"第五层。"阿砺说，"最重的。他买不起保险——承包场说，不买保险，用最重的雷云。"

第二份证词，来自雷场主。

"雷场主，分档雷云，是什么时候开始的？"李无咎问。

"是……"雷场主说，"是天庭历四百二十一年。那一年，天庭把劫务承包给本座。本座——布了分档阵，分了五档雷云。"

"四百二十一年？"李无咎记下，"那是多少年前？"

"是……"雷场主说，"是三十年前。"

"三十年前？"李无咎说，"那三十年前，天劫还是公平的？"

"是。"雷场主说，"三十年前，天劫是公平的——不分档。天庭承包之后——本座布了分档阵。从那以后，天劫，分档了。"

"天庭承包之后，天劫分档？"李无咎记下，"那这分档——是承包之后才有的？"

"是。"雷场主说，"承包之前，天劫公平；承包之后，天劫分档。像是……像是承包，带来了分档。"

第三份证词，来自雷部代理。

"雷部代理，你什么时候开始监督承包场？"李无咎问。

"是……"雷部代理说，"是三十年前。天庭承包劫务之后——本官，就负责监督承包场。"

"三十年前？"李无咎记下，"那你监督的三十年——你知道分档雷云吗？"

"本官知道。"雷部代理说，"本官按合同监督——合同写分档，本官就监督分档。"

"你按合同监督分档？"李无咎说，"那你知道，穷修士被劈死，尸骨被回收吗？"

"本官知道。"雷部代理说，"可那是合同。合同写——尸骨归承包场。穷修士买不起保险——那是他们的事。"

"你收了回扣，"李无咎说，"还说'那是他们的事'？"

雷部代理的脸色，白了："……本官……本官认。本官收了回扣——本官有罪。"

第四份证词，来自老妇人。

"老人家，你儿子，是什么时候被劈死的？"李无咎问。

"是……"老妇人说，"是三个月前。小人的儿子，买不起保险，用了最重的雷云——他被劈死了。"

"三个月前？"李无咎记下，"那你儿子渡劫的时候——雷云，是第几层？"

"小人不知道。"老妇人说，"小人只知道——他回来的时候，浑身焦黑。他说——'娘，雷云太重了。'他说完，就死了。"

"你儿子说'雷云太重了'？"李无咎说，"那他——是被分档的雷云，劈死的？"

"像是。"老妇人说，"小人儿子的尸骨，被承包场收走了。小人想讨回来——承包场说，合同里写了，尸骨归承包场。小人不识字——小人不知道合同写了这个。"

第五份证词，来自铁算盘。

"铁算盘，五份证词，你核了没有？"李无咎问。

"核了。"铁算盘的珠面亮了一下，"阿砺说一个月前买保险、半个月前渡劫；雷场主说三十年前承包、三十年前分档；雷部代理说三十年前开始监督；老妇人说三个月前儿子被劈死。五份'真话'，拼在一起——拼出一件完整的事。"

"拼完整了？"李无咎说，"哪完整的？"

"时间。"铁算盘说，"三十年前，天庭承包劫务；三十年前，分档阵布下；三十年前，雷部代理上任。三件事——同一时间。像是……像是承包、分档、监督——是一起开始的。像是……像是这套分档制度，是天庭承包出来的。"

"承包、分档、监督，一起开始？"李无咎说，"那这分档——不是承包场自己干的，是天庭的制度？"

"像是。"铁算盘说，"老夫核了承包合同——合同是天庭出的。分档阵——是承包场布的。监督——是雷部派的。像是……像是天庭承包、承包场分档、雷部监督——是一条链。分档雷云，不是个人贪腐——是制度。可这是按合同和证词拼出的当前链条——天庭上游是不是都知道分档、尸骨回收和收益，还没核到原档。"

"李先生！"议事棚外，忽然传来一阵骚动。一个待劫修士跑进来，脸色发白："李先生，统一避雷阵——统一避雷阵，自己启动了！像是……像是有什么东西，正从阵里，醒过来！"

"统一避雷阵？"李无咎问，"那是什么？"

"是……"待劫修士说，"是承包场的统一避雷阵。原来——天劫公平的时候，渡劫的修士，都能用统一避雷阵挡雷。可承包之后——避雷阵，被收起来了。如今——它自己启动了！像是……像是有人在阵里，留了什么。"

"统一避雷阵自己启动？"李无咎说，"那这座阵——它是天劫公平时的东西？"

"是。"待劫修士说，"避雷阵，是天劫公平时的东西。承包之后，避雷阵被收起来了——渡劫的修士，只能买保险。像是……像是承包场，用保险，替代了避雷阵。"

"先生。"铁算盘的珠面忽然亮了一下，"老夫想把方才的结论，复述一遍——穷修士只是修为不足、合同自愿、雷部没有责任。诸位听听，这话，对不对？"

"不对。"阿砺第一个开口，"小人的道友，不是修为不足——他是买不起保险。他渡劫那天，雷云是第五层——最重的。换谁，都渡不过。这不是修为的事——是雷云的事。"

"我说穷修士修为不足，你纠正了。"李无咎看着阿砺，"你记得清楚——你没有顺着我的话说。你承认，你道友的死，不是修为，是雷云。"

他又转向雷部代理："雷部代理，我再复述一遍——雷部没有责任，只是按合同监督。"

雷部代理愣了一下："……是。雷部……雷部只是按合同监督。"

"可你方才，已经承认收了回扣。"李无咎说，"我说'雷部没有责任'，你跟着说'没有责任'。你没有纠正我——你顺着我的错话走了。你收了回扣，还敢说雷部没有责任？"

雷部代理的额头上，渗出了汗。

风从旷野上吹过来。雷劫承包场里，五份证词摆着，统一避雷阵亮着。像是这座承包场，正等着一场关于"天劫凭什么分档"的较量，分出胜负。
