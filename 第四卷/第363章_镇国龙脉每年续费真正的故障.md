# 第363章 镇国龙脉每年续费真正的故障

证物台搭在石厅中央。台上从左到右摆着：空妖王棺的灵石槽、各州共养契、每年续费碑的拓片、地脉天锁的锁芯标记、龙渊断口石壁上的铜牌拓印、归鹤的鹤印印模。

李无咎把时间线排成一行。排完，整件事的轮廓从纸面上浮了出来。

第一条线从龙脉断口出发。大梁龙渊地下，有一条被截断的龙脉。断口不是天然形成的，断口的边缘有切割痕迹，切割的方向和天庭调配符的灵路一致。这条龙脉曾经是完整的，被截断之后，灵气开始从断口流失。截断的原因，铜牌上的调配令只记了一句话：纳入调配体系，统筹分配。

"这条龙脉不是妖王的地盘。"李无咎把铜牌拓印放在案上，"它是被截断的。截断之后，灵气持续流失。流失的灵气，需要有人补。补的方式，就是续费。"

第二条线从续费制度出发。龙脉断口需要灵石维持运转，这是真实的技术需求。续费本身没有错，错的是续费的制度。续费被设计成每年缴纳一批灵石，不交则龙脉渐衰。这个设计被包装成一个更吓人的说法：不交钱，妖王就会苏醒。

"妖王是编出来的。"李无咎说，"底下没有妖王，底下是一条被掐断的河。河需要水，水就是灵石。续费制度把这件'需要维护'的事，包装成了'不交钱就出事'的事。维护需要钱，和拿钱吓人，是两回事。续费制度把这两件事揉在一起，揉了几十年。"

第三条线从空妖王棺出发。棺是空的，但棺的结构是导流装置，把续费灵石引入断口。棺的存在，让"续费养妖王"的说法有了一个看得见的物件。每年续费，灵石入槽，槽底的灵路绕开棺，通入断口。棺本身不封印任何东西，它只是一个把灵石引入断口的漏斗，和一个把真相遮住的幌子。

第四条线从续费碑出发。共养契签了五年被废，续费决定权从各州共定变成朝廷核定。续费碑上的数目逐年上调，调的依据不是共养契，是"朝廷核定"。上调的幅度，多出的三成，进了皇室私账和国祚储备。

第五条线从天庭调配令出发。断口石壁上的铜牌，锁芯里的调配令，落款都是鹤印。归鹤参与过这套调配体系的建立。但画面显示，归鹤画符是为了把续费交给各州，他试图中止一姓独断。共养契被废后，归鹤试图挖开断口停止续费，被拦下。他走了，鹤印留了下来，令牌落到了供奉手里。

"归鹤设置敛财封印"这个说法，到这里可以拆开了。李无咎把这七个字画在案上，用朱笔划掉，在旁边重新写了一段：

"归鹤参与设计了调配符，这是他参与的部分。他把调配符画成各州共养的方向，这是他试图做的部分。共养契被废，他试图中止续费，被拦下，这是他失败的部分。续费制度后来变成皇室独断、妖王吓人、账目不清，这是后来的人借他的鹤印做的部分。归鹤有责任，因为他参与了，却没有让共养契活下来。但'归鹤设置敛财封印'这个说法，把续费制度几十年来的受益者全部摘干净了，把公共维护责任变成了一口井，井里有归鹤的名字，也有皇室、供奉和地脉司的名字。"

他把因果图画成六栏。六栏是公开的，挂在石厅墙上：

第一栏，谁知情。荀渊知道断口是龙脉，知道调配令的存在。苍梧真人知道验收造假。唐执知道账目不清。冯伯知道停缴测试。梁玠知道皇室私账。

第二栏，谁收费。续费碑逐年上调，多收的三成，进了皇室私账和国祚储备。收费的人是国廷，受益的是皇室和供奉。

第三栏，谁获益。皇室私账七成，供奉账三成。国祚储备的划拨。宗门供奉从稳定供给中获得修炼优势。

第四栏，谁维护。冯伯填装灵石四十年，靳小山护碑二十八年。维护者拿最少的钱，承担最重的活。

第五栏，谁被迫承受断缴风险。京城外九个村的农户、平川县的多收农户、低阶修士、宗门弟子。断缴的后果，落在他们身上。

第六栏，仍没有获得选择权的人。续费交了十年，没有一个人被问过"愿不愿意交"。断缴的后果，没有一个人被问过"愿不愿意承受"。

六栏挂完，李无咎站在案前，看着那口空妖王棺。他把最后一段话放在案上："这条龙脉不是妖王的地盘，是被截断的公共水源。续费不是敛财，是维护；但把维护包装成吓人，把收费包装成封印，把责任包装成归鹤一个人的名字，是制度在把真相当账本用。今天我把这张图挂出来，挂图的人不是我，是你们每个人站在图上的位置。"

石厅里安静了很久。梁玠站在六栏图前，看了"谁获益"那一栏很久。唐执站在"谁知情"一栏前，没有动。苍梧真人站在"谁收费"一栏前，把令牌从怀里拿出来，放在案上。

"李先生。"梁玠终于开口，声音比之前轻，"这张图挂出去，皇室、供奉、地脉司，所有人都要面对自己的位置。续费停了，灵气少了，国祚怎么办？你们售后堂，承担得起吗？"

"我承担不起。"李无咎说，"我从来没有说过我承担得起。我能做的，是把图挂出来，把真相公开，把三个有代价的方案摆出来，让你们每个人自己选。选完之后，谁承担的，谁承担。我不替你们选，也不替你们扛。"

他没有说出三个方案的内容。他转身走向石厅门口，让石厅里的人都看见那张六栏图。图的墨迹还没干透，六栏的字在灵灯下泛着光，像六道已经亮起来、等着人去走的路。

空妖王棺立在断口上方，第一次没有人再看它。它那口空的棺身，在六栏图的光里，显得比任何时候都轻。
