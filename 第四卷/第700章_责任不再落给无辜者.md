# 第700章 责任不再落给无辜者

三个方案摆出来后，改契在第三天开始执行。执行的，是解除结界、分批补时，由每个人决定一次承受多少岁月。

第一步，是解结界。李无咎带着宁知微，走到第一根白发前。他取出量灵尺、阵钉、墨斗线，在白发四周布下分批解除阵。阵成的时候，结界，缓缓地裂开了一道缝——不是全解，是解了一部分。

"结界，解除了一部分。"宁知微直起腰，"补时，开始了一批。"

"第一批补时，"李无咎说，"补给谁？"

"补给村民自己。"宁知微说，"每个村民，自己决定——一次补多少，多久补一次。愿意补快一点的，补快一点；愿意补慢一点的，补慢一点。"

"李先生！"一个老人站出来，"小人补时，一次补三个月。小人不想一下子老到七十岁——小人想慢慢老。"

"你一次补三个月？"李无咎说，"那你三十年，要补一百二十次。你认？"

"小人认。"老人说，"小人宁可慢慢老，也不想一下子老死。"

"李先生！"岁苗站出来，"小人补时，一次补半年。小人想快一点长大——可小人也不想补死。小人想慢慢长大。"

"你一次补半年？"李无咎说，"那你十年，要补二十次。你认？"

"小人认。"岁苗说，"小人宁可慢慢长，也不想补死。"

"李先生！"一个母亲站出来，"小人的孩子——小人的孩子，先不补时。小人怕孩子受不住。小人的孩子，再当几年婴儿。"

"你的孩子，先不补时？"李无咎说，"那你认——孩子再当几年婴儿？"

"小人认。"母亲说，"小人宁可孩子多当几年婴儿，也不想孩子补死。"

第二步，是补时。村民们，一个一个地，自己决定补时的节奏。老人慢慢老，孩子慢慢长。补时，一次三个月，一次半年——每个人，自己选。

"补时，分批了。"宁知微直起腰，"老人慢慢老，孩子慢慢长。没有人集中补时——没有人补死。"

"好。"李无咎说，"那补时，就能慢慢补完。"

"李先生！"村里，又传来喊声。一个村民跑进来，脸色惨白："李先生，岁老——岁老，补完了一批时！他的身体，适应了！他没死！"

"岁老没死？"李无咎冲到岁老面前。岁老躺在床上，头发比方才白了一些——可他，还活着。

"李先生，"岁老睁开眼，"老朽补了一批时——老朽没死。老朽慢慢老——老朽还能再看孙子长大。"

"岁老，"李无咎说，"你慢慢老——你能看到孙子长大了。"

"李先生！"村里，又传来喊声。一个村民跑进来，脸色惨白："李先生，岁苗——岁苗，长了一点点！他的身量，长高了！他没发烧——他适应了！"

"岁苗适应了？"李无咎冲到岁苗面前。岁苗站在地上，身量比方才高了一些——他，没发烧，没晕倒。他，适应了补时。

"李先生！"岁苗说，"小人补了一批时——小人没疼。小人慢慢长——小人能长大了。"

"你慢慢长，"李无咎说，"你能长大了。"

第三步，是立制。李无咎把停岁村的新规矩，写成了册子。册子上，分了几栏——补时栏、医疗栏、照护栏、赔付栏、退出栏。

"这本册子，"李无咎说，"停岁村的新规矩。补时——每个人自己选，一次补多少，多久补一次。医疗——补时的人，病了，有人治。照护——老人慢慢老，有人照护。赔付——被停岁三十年的人，要赔。退出——想离村的人，分批补时，补完了，再走。"

"李先生！"村里，又传来喊声。一个村民跑进来，脸色惨白："李先生，村外——村外，又出现了一具老化尸！是停潮村一个离村的老人！他离村的时候，补回三十年，死了！"

"停潮村老人离村补时死了？"李无咎冲到村外。海岬上，又一具老化尸，倒在礁石边。

"李先生！"宁知微说，"离村补时——还是有人，在不知情的情况下，离村补时死了。像是……像是两座村，还有人不知道，离村会补时。"

"李先生！"村里，又传来喊声。一个村民跑进来，脸色惨白："李先生，停潮村——停潮村的村民，也开始分批补时了！他们学了停岁村——每个人，自己选补时的节奏！"

"停潮村也分批补时？"李无咎说，"那两座村——都在分批补时？"

"是。"村民说，"两座村，都在分批补时。老人慢慢老，孩子慢慢长。没有人集中补时——没有人补死。"

"李先生！"村里，又传来喊声。一个村民跑进来，脸色惨白："李先生，停潮村有一个老人——他补时，补死了。"

"停潮村老人补死了？"李无咎说，"那他是——"

"他是自愿的。"村民说，"他说，他三十年前是七十岁——他不想再冻着了。他说，他要一次性补回三十年。他说——他宁可死，也不想再冻着。他补时，补死了——他是自愿的。"

"他自愿补时，补死了？"李无咎说，"那他的选择——他认。"

"李先生！"村里，又传来喊声。一个村民跑进来，脸色发白："李先生，村里——村里有个老人，不想补时了。他说，他想继续冻着。他说——他宁可永远冻着，也不想变老。"

"他不想补时？"李无咎说，"那他可以继续冻着——选择的权利，包括不变的选择。"

风从海岬上吹过来。停岁村里，老人分批补着时，孩子慢慢长着。停潮村，也在分批补时。像是这两座时间冻结的渔村，正慢慢地，解冻着——由村民自己，决定承受多少岁月。
