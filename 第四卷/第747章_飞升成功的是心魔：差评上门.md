# 第747章 飞升成功的是心魔：差评上门

云州的善后刚做完，因果簿的新画像就浮出来了。画像不是文字，是一座巍峨的天门——门墙高耸，门楣上刻着繁复的云纹。天门的下方，立着一个人影——那人影像是站在门槛外，又像是站在门里。画像下面浮着一行小字："下界道场，差评：买了飞升套餐，本体留下，心魔却在天上当仙。"

"本体留下，心魔当仙？"宁知微看着那行字，"一个人，分成了两半——一半在地上，一半在天上？"

"先去看。"李无咎说，"人分成两半，是飞升阵的问题，还是别的——得查了才知道。"

第二十七天，他们到了下界道场。

下界道场是一座建在山巅的道场。李无咎到的时候，正是清晨。道场的正殿里，摆着一座法坛——法坛上，盘坐着一个老修士。那老修士双目紧闭，气息绵长——可他的身体，一动不动，像是一具空壳。

"李先生！"领路的是一位中年道人，姓薛——他是那老修士的弟子，人称薛师兄。他声音发哑，指着法坛上的老修士，"您看这位。他叫薛照尘，是小人的师父。他买了飞升套餐——可他的本体，留在了下界。他的心魔——飞升上天，当了仙官。"

"心魔当仙官？"李无咎走到法坛前，"那薛照尘的本体，为什么还在这？"

"因为……"薛师兄说，"师父的本体，被留在了下界。可师父的心魔——通过了飞升阵，上了天。如今，天上那位，是师父的心魔——他成了仙官。而地上这位——师父的本体，成了空壳。"

"心魔上天，本体成空壳？"李无咎说，"那这飞升——飞上去的，是心魔？"

"是。"薛师兄说，"师父买了飞升套餐。他说，飞升之后，就能成仙。可飞升之后——成仙的，不是师父。是师父的心魔。师父的本体，留在了下界——成了一具空壳。"

"李先生！"法坛边，一个年轻道童跑过来，脸色惨白："李先生，您看这炷香——这炷香，是师父的心魔，从天上传下来的香火！他烧着香——香火一烧，师父的本体，就会动！"

"心魔用香火操纵本体？"李无咎蹲下来，看那炷香。香火上，飘着袅袅的青烟。青烟升到半空，凝成一个模糊的人影——那人影，穿着仙袍，戴着头冠，正俯瞰着地上的本体。

"李先生！"薛师兄说，"这就是师父的心魔——天心魔。他成了仙官。他烧香——香火落在师父的本体上。师父的本体，就会动。像是……像是天上的心魔，正操纵着地上的本体。"

"那薛照尘的本体，"李无咎说，"他自己，还有意识吗？"

"有。"薛师兄说，"师父的本体，偶尔会醒。他醒的时候，会说——'我没有飞升。飞升的是我的心魔。天上那个，不是我。'可他说话的时候，香火一烧——他又闭上眼，不动了。像是……像是天上的心魔，一烧香，就把师父的本体，按回空壳。"

"李先生！"法坛上，那老修士——薛照尘的本体，忽然睁开眼。他望着李无咎，声音沙哑："李先生……小人……小人要投诉。小人买了飞升套餐——可飞升的，不是小人。是小人的心魔。小人花了毕生的积蓄，买了飞升——可飞上去的，是小人的心魔。"

"你花了毕生积蓄买飞升？"李无咎说，"可飞升的，是你的心魔？"

"是。"薛照尘的本体说，"小人修行一辈子，就想着飞升。小人攒了半辈子的灵石，买了飞升套餐。可飞升那天——小人站上飞升阵，阵光一起——小人的心魔，代替小人，飞了上去。小人留在原地——成了一具空壳。"

"飞升阵，把你的心魔送了上去？"李无咎说，"那飞升阵，识别错了？"

"不知道。"薛照尘的本体说，"小人只知道——天上那个，是小人的心魔。他穿着小人的仙袍，顶着小人的名号，坐着小人的仙位。可他不是小人。他是小人的心魔——小人修了一辈子，想压下去的那部分。"

"李先生！"天上，忽然传来一个声音。那声音，威严而清朗——像是一个仙官，在高处说话："地上的，不要信他。本官才是完整的薛照尘。本官飞升了——本官成了仙官。地上的那具空壳，才是心魔留下的壳。"

"天上的仙官？"李无咎仰起头，"你是薛照尘的心魔？"

"本官不是心魔。"那声音说，"本官是薛照尘。本官修行一辈子，悟道了，飞升了。地上的那具壳——是本官留下的旧身。本官成了仙官，那具旧身，自然就空了。地上的，说本官是心魔——那是他嫉妒本官成了仙。"

"你说你才是完整的薛照尘？"李无咎说，"那地上的薛照尘，说你是他的心魔——你们俩，都说自己才是真的？"

"是。"天上那声音说，"本官，才是完整的薛照尘。地上的，是旧的壳。"

"李先生！"薛照尘的本体，声音发颤，"小人不是壳！小人记得自己是谁！小人记得自己修行一辈子——小人记得自己买飞升套餐，是为了成仙！小人不是壳——小人是有记忆的！天上那个，才是小人的心魔！"

"你们都记得自己是谁？"李无咎说，"那你们——谁记得的，才是真的？"

"李先生！"道场外，又传来喊声。一个道童跑进来，脸色惨白："李先生，天上——天上的心魔法像，出事了！法像上的眼睛，睁开了！像是……像是法像，在看着什么！"

"心魔法像睁眼？"李无咎冲出道场。道场外，立着一座巨大的法像——那是薛照尘心魔的法像，立在道场最高处。法像的眼睛，此刻正睁着——像是在俯瞰着整个下界。

"李先生！"薛师兄说，"这法像，原本是闭着眼。可如今——它睁眼了。像是……像是天上的心魔，通过法像，看着下界。"

"李先生！"道场外，又传来喊声。一个道童跑进来，脸色惨白："李先生，飞升契——师父的飞升契上，有一行小字，看不清！像是……像是被人遮住了！"

"飞升契？"李无咎接过飞升契。契上，印着密密麻麻的字。有一行——被一层淡淡的墨，遮住了。他凑近看——那行字，写着："本套餐，以人格之服从度为先。服从度足者，可得飞升。"

"服从度？"李无咎说，"飞升，要看服从度？"

"李先生！"薛师兄说，"小人不知道什么是服从度。小人只知道——师父买了飞升套餐，飞上去的是心魔。如今——天上的心魔，烧着香，操纵着师父的本体。师父的本体，成了一具空壳。"

"李先生！"法坛上，薛照尘的本体，忽然又闭上眼——香火一烧，他，又被按回了空壳。

"李先生！"宁知微蹲在薛照尘的本体前，"他的灵息——空壳的灵息，和天上的法像，是连着的。像是……像是天上的心魔，正通过香火，吸着地上的本体。"

"心魔吸本体？"李无咎说，"那薛照尘的本体——"

"在损耗。"宁知微说，"空壳的修为，正一点一点，流向天上的法像。像是……像是天上的心魔，正借着香火，把地上的本体，吸空。"

"李先生！"道场外，又传来喊声。一个道童跑进来，脸色惨白："李先生，地上空壳——有别的修士，也出现了空壳！他们没买飞升套餐——可他们的身体，也空了！像是空壳，在扩散！"

"空壳扩散？"李无咎说，"没买飞升套餐的人，也出现空壳？"

"是！"道童说，"道场外，有三位修士，忽然倒下了。他们没买飞升——可他们的身体，空了！像是有什么东西，正从他们身上，抽走什么！"

风从山巅上吹过来。下界道场里，薛照尘的本体空着，天上的心魔法像睁着眼，空壳在扩散。像是这座道场，正被一场"飞升"搅得天翻地覆——正等着谁来，替那些被分成两半的人，问一句——到底谁，才是真的。
