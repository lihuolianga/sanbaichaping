# 第951章 第一次修补失败

年轮趁乱再浮，这让李无咎决定不再等证据凑齐——先以多人证据匣为核心，试着切断同命药契。

"宁怀川去了药库，药方上还有鬼，"他把铁算盘的旧账、九霄的档案摊在证据匣前，"可年轮不能再转。先修——用多人证据匣做核，切断同命药契。修好了，再查转移。"

第一步，是连接三份材料。

李无咎把多人证据匣立在青炉谷主阵正中，又取出铁算盘的旧账、九霄的档案，摊在证据匣两侧。旧账上，记着生机的流向；档案上，记着命数的权限。他取出因果反证，把三样东西连成一线——证据匣是核，旧账是账，档案是权。

"证据匣是核，旧账是账，档案是权？"宁知微看着那条因果线，"李先生想用证据匣做核——切断同命药契？"

"是。"李无咎说，"生机损耗，两头挂——一头挂多人证据匣，一头挂父女年轮。我隔了证据匣，生机损耗转移。可如果我把证据匣当作核——把同命药契，从证据匣上切断——也许，能切断这一头。"

第二步，是切断同命药契。

李无咎捏诀，把因果反证压在证据匣上。证据匣亮了一下——然后，暗了下去。父女年轮——停了。像是……像是那一头的年轮，停了。

"停了？"李无咎问。

"停了。"宁知微直起腰，"证据匣暗了——父女年轮和同步伤病，停了。像是……像是年轮，停了。"

"停了？"李无咎松了口气，"那患者——"

他话没说完，青炉谷外，忽然传来一片惨叫。李无咎冲到谷外——几十个患者，瘫在地上。像是……像是他们的生机，正被反噬。像是……像是证据匣断了——生机反噬，转到了他们身上。

"又有人生机反噬？"李无咎冲到人群里，"生机，不是停了吗？"

"证据匣断了——可生机反噬，转到另一边了！"宁知微赶到，脸色发白，"李先生，切断证据匣那一头——生机反噬，就转到药炉那一头！药炉一炼——患者的生机，就反噬！你断了证据匣——药炉，就亲自炼了！"

"转到药炉那一头？"李无咎说，"我断了证据匣——药炉亲自炼？"

"是！"宁知微说，"生机损耗，不只挂在证据匣上。证据匣是源头——断了证据匣，药炉直接炼。像是……像是这套损耗，两头都能转——证据匣断，药炉直接上。像是……像是它，永远有一头在转！"

"李先生！"青炉谷外，又传来喊声。一个药师跑进来，脸色惨白："李先生，另一群人——另一群患者，更严重地失控了！像是——像是他们的生机，被反噬得更狠了！像是——像是他们，更严重了！"

"更严重了？"李无咎冲到青炉谷外。另一群患者——他们的生机，正被反噬得更狠。像是……像是他们，更严重了。

"李先生！"宁知微说，"生机反噬更狠——像是……像是我们切断证据匣，代价，落向了另一群人。像是……像是我们最想保护的患者——被反噬得更狠了！"

"我害了他们。"李无咎的手，抖了一下，"我以为，切断证据匣能救青炉谷——可代价，落向了更多的患者。"

"李先生！"青炉谷外，又传来喊声。宁怀川的声音，从人群外响起来："李先生！大家都看到了！李先生收了九霄的档案，又拆了证据匣——结果呢？反噬更狠！售后堂，根本查不清这桩案！依本家之见——恢复药契，处置被同命的患者，一了百了！"

"恢复药契？"李无咎说，"处置患者？"

"是！"宁怀川的声音高亢起来，"被同命的患者，伤上有药纹——伤上有药纹，就该处置！李先生查了这么久——查出了什么？反噬更狠！诸位，都看到了吧——售后堂，只会越查越乱！"

"李先生！"青炉谷外，患者们鼓噪起来。一个患者喊起来："李先生，宁怀川说得对！小人被同命了——小人有罪！处置小人吧！处置了小人——年轮就不浮了！"

"处置你们？"李无咎看着那些患者，"处置了你们，药炉就不炼了吗？处置了你们，绑定就不存在了吗？"

"小人不知道。"患者说，"可小人被同命了——小人有罪！处置小人，年轮就不浮了——那就处置小人！"

"你们以为，处置了你们，年轮就不浮了？"李无咎说，"刚才，我切断了证据匣——可反噬，更狠了。处置了你们——反噬，还会转到别处。因为药炉还在，命数还在——处置了你们，还有新的患者，会被同命，反噬。"

"李先生！"宁知微说，"宁怀川想借失败，证明售后堂无能——他好恢复药契，让'药契自然反噬'盖住一切。李先生，我们失败了——可我们的失败，恰恰证明了：切断证据匣，只是局部修补。局部修补，会把伤害，推给我们最想保护的人。"

"你说得对。"李无咎说，"我切证据匣，是想救青炉谷。可代价，落向了另一群患者。我的临场聪明——不是解决机制。"

"李先生！"青炉谷外，又传来喊声。一个药师跑进来，脸色惨白："李先生，铁算盘——铁算盘核了反噬转移的路径！它说——反噬更狠，不是随机的！像是——像是反噬更狠的患者，都是签过药契的！"

"签过药契的？"李无咎说，"反噬更狠——专门挑签过药契的患者？"

"是。"药师说，"铁算盘说，反噬更狠——专挑签过药契的患者。像是……像是这套绑定，有备选的通道——它知道，谁签过药契，谁反噬更狠。像是……像是它，有脑子。"

"它有脑子？"李无咎的脸色，沉了下来，"那这套绑定——不是一套死的机制。它知道，谁签过药契——它知道，让谁反噬，噬得狠。"

"李先生！"宁知微说，"反噬会挑——像是……像是这套绑定，被人设计过。像是……像是设计它的人，知道药契——它要反噬的，不是随便一个患者——是签过药契、最会被绑定的患者。"

"设计它的人？"李无咎说，"谁设计的？"

"不知道。"宁知微说，"可宁怀川去了药库——药方上还有鬼。像是……像是设计这套绑定的人，就在宁家。像是……像是他设计绑定，是为了让签过药契的患者——自己承担所有。"

"李先生！"铁算盘的声音响起来，"老夫核了药方的因果——宁怀川说吃了十二年药。像是……像是可老夫核了药方——药方，从十五年前就有记录。像是……像是宁怀川把吃药的时间，改了。像是……像是他把十二年，改成了十五年前开始。"

"吃药时间被改？"李无咎说，"那这份药方——"

"像是……"铁算盘说，"像是宁怀川把吃药的时间，改短了。像是……像是他，不想让人知道——他吃了十五年的药。像是……像是这套绑定，比宁知微知道的，更早。像是……像是这份药方，是关键证据。"

"李先生！"宁知微的脸色，变了一下，"药方从十五年前就有记录——可父亲说，十二年前开始吃药。像是……像是父亲，改了时间。像是……像是这套绑定，比我知道的——更早。"

"宁知微，"李无咎说，"你父亲改了吃药时间——你，不知道。这笔账，记在你父亲头上。可你也该想——你父亲为什么改时间？他怕什么？"

"像是……"宁知微说，"像是父亲，怕我知道——他吃了十五年的药。像是……像是父亲，怕我知道——他被绑了十五年。像是……像是父亲，一直在瞒我。"

"李先生！"青炉谷外，又传来喊声。一个药师跑进来，脸色惨白："李先生，一个患者——他，又晕过去了！像是——像是他的生机，被反噬干了！"

"生机被反噬干？"李无咎冲到青炉谷外。一个患者——脸色惨白，晕了过去。像是……像是他的生机，被反噬干了。

"李先生！"宁知微蹲下看了看，"生机被反噬干——像是……像是他，撑不住了。像是……像是我们切断证据匣，没救到他——反而让反噬，更狠了。"

"我错了。"李无咎的声音，低下来，"我以为，切断证据匣能救他。可我——让更多的患者，被反噬。我该承认——临场聪明，不等于解决机制。这套绑定，不是切一处就能断的——它有脑子，它有备选通道，它知道谁的药契。"

"李先生！"青炉谷外，又传来喊声。宁怀川的声音，从人群外响起来："李先生！你也知道错了！那就听本家的——恢复药契，处置被同命的患者——"

"处置患者，不能解决药炉。"李无咎说，"药炉还在，命数还在——处置了患者，还会有新的患者，被同命，反噬。宁怀川，你要是真想让年轮不再浮——你就该把宁家的药方，交出来，让我查。"

宁怀川的脸色，抽搐了一下。他没有交药方——他转身，退进了人群。

风从青炉谷上吹过来。青炉谷外，证据匣断了，反噬却加倍地转，患者的生机被反噬干了。像是这座青炉谷，正用一场失败，告诉李无咎——局部修补，救不了任何人；真正的账，还在宁家的药库里。
