# 第535章 死者人生菜单写进责任范围

登记设在客栈大堂。李无咎把七张长桌拼成两排，案上铺着因果簿摊开的幅页。他把受影响的七类人分开，每类一张案，每张案前站一个代表。

第一张案是幽隙过客。幽七站在案前，落名时手一直在抖。他落完名，说："李先生，小人落名了。小人被换生过。小人想找回自己。"

"你落名，是确认你被换生过。"李无咎说，"你的原身，你的当前身体，你的换生时间，都要记。"

第二张案是住客。一个住客站在案前，他叫丙三。他落名时说："李先生，小人住店三天。小人第一天是丙三，第二天是张四，第三天是李五。小人不知道，小人明天是谁。"

"你三天，换了三个身份。"李无咎说，"你的原身，是什么？"

"小人……小人记不清了。"丙三说，"小人只记得，小人住店的时候，是一个叫丙三的人。但丙三是谁，小人想不起来了。"

"你连原身都记不清了。"李无咎说，"你的身份，被交换得忘了自己。"

"李先生。"丙三又说，"小人退房的时候，小人走出来了，但小人的身体，留在房里。小人现在这个身体，是小人的，还是别人的？"

"你现在的身体，是别人的。"李无咎说，"你的原身，留在房里了。你退房，走出来的是你，但身体留在房里。你退房了，身体没退。"

"小人退房了，身体没退？"丙三说，"小人现在是个没有身体的人？"

"你是一个魂息，装在一个不是你的身体里。"李无咎说，"你的原身，在房里；你的魂息，在别人的身体里。你分不清自己，是因为你的身份被拆开了。"

"李先生。"丁四站在案前，开口了，"小人想补充一句。小人自愿换生的时候，掌柜给小人看过一张附录。附录上写着'换生后不可退房'。小人看了，没细看。小人想着，换了年轻的身体，不能退就不能退。小人没想到，不能退房，是不能回到自己的身体。"

"你看过'不可退房'，没细看。"李无咎说，"你以为不能退房，是不能换回旧身体。你没想到，不能退房，是永远被困在客栈。"

"小人被困住了？"丁四说，"小人换了个年轻的身体，但小人回不去了。小人自愿换生，换来的是回不去的身体。"

"你自愿换生，换来回不去的身体。"李无咎说，"你的自愿，是有代价的。你自愿的时候，不知道代价是失去退房权。"

"李先生。"归掌柜在旁边开口，"老朽想说，老朽给丁四看附录，是让丁四知道，换生不可退房。老朽没有隐瞒。"

"你给他看附录，让他知道不可退房。"李无咎说，"但你给他看的附录，写在换生之前。他换生之前，不知道代价是失去退房权。你让他知道了'不可退房'，没让他知道'不可退房'意味着什么。"

归掌柜没有接话。

第三张案是掌柜。归掌柜站在案前，落名时笔悬在纸上。他落完，说："李先生，老朽管客栈，老朽换生，是为维持幽隙。老朽不知道，换生让住客忘了自己。"

"你换生，维持幽隙。"李无咎说，"你不知道换生让住客忘了自己。你换生几十年，你不知道？"

归掌柜没有接话。

第四张案是轮回吏残影。轮回吏残影浮在案前，它落名时说："本吏按旧章执行。旧章上写，客栈换生，维持中转站。本吏执行旧章。"

"你按旧章执行？"李无咎说，"旧章上，写着把住客变成另一个死者吗？"

轮回吏残影没有接话。

第五张案是自愿换生者。丁四站在案前，落名时说："李先生，小人自愿换过生。小人原来的身体老了，小人想换个年轻的身体。小人自愿换了。"

"你自愿换生？"李无咎说，"你换生的时候，知道代价是什么吗？"

"小人知道会换身体。"丁四说，"小人不知道，换了之后，退不了房。"

"你换生，退不了房。"李无咎说，"你自愿换生，但你失去退房权。你的自愿，换来了回不去的身体。"

第六张案是无名死者代表。案上放着那卷死者人生菜单。李无咎说："菜单上，记着约两百个名字。这些名字，是无名死者。他们被安排进房间，被交换，但没有人记他们的原身。这个案，等查清菜单的流向，再核。"

第七张案是客栈本身。案上放着一把房门的钥匙。李无咎说："客栈的房门，每天变号。每扇门，都对应一段死者人生。客栈不是背景，它是换生的执行者。这个案，等查清门号的规律，再核。"

七张案登记完，李无咎走到大堂中央。他先说的不是方案，是先止损："第一，房门先固定。从今晚起，房门不再变号。每扇门，固定一个住客。第二，死者人生菜单，先封存。菜单不再添加新名字。第三，掌柜的空身体，先检查。第四，换生的记录，先登记。谁换过生，原身是什么，当前身体是什么，都要记。"

"李先生。"归掌柜开口，"你固定房门，客栈的换生就停了。幽隙的崩塌，就加快了。"

"幽隙崩塌，是客栈的问题。"李无咎说，"换生停，住客不再忘自己。幽隙崩塌，再想办法。你不能让住客忘自己，换幽隙的稳定。"

"李先生。"轮回吏残影开口，"你封存菜单，旧章的程序就停了。中转站不转，魂魄就无处安置。"

"魂魄无处安置，就另找地方。"李无咎说，"你不能让魂魄被换生，来维持中转站。中转站不转，魂魄可以进鬼城，可以找别的地方。"

宁知微在这时候走到李无咎身边，声音压低："幽隙过客拒绝公开一段关键经历。幽七拒绝说出，他住店之前，曾经自愿换过一次生。他怕说出来，别人会指责他。丁四拒绝说出，他自愿换生的时候，掌柜给他看过一张附录，附录上写着'换生后不可退房'。他看了，没细看。"

"两段都不敢说的经历。"李无咎说，"幽七自愿换过一次生，不敢说。丁四看过'不可退房'，没细看。他们都知道一部分，都不敢说全。"

"还有一件事。"宁知微说，"我检查了菜单。菜单上，实名栏被涂掉了。原来的菜单，是有实名栏的。后来，实名栏被涂掉了。涂掉实名栏的人，不想让住客知道，换生的人是谁。"

"实名栏被涂掉？"李无咎说，"原来的菜单有实名栏，后来被涂了。涂掉实名栏，换生就变成无名交换。住客不知道自己换了谁的人生。"

"是。"宁知微说，"实名栏被涂掉，退房条款被撕掉。菜单上，只剩'可交换的姓名、记忆、身体'，没有原身确认、交换期限和退房条款。"

铁算盘在这时候拨出一排红字。它压低声音说："因果簿缩短处理期限。原定期限七天，改为五天。原因：下一次房门变号，提前到当夜。菜单已经添了新名字。当夜，会有人换生。期限再拖，换生的住客，会更多。"

大堂外，传来一声轻响。李无咎走出去，看到那卷死者人生菜单。菜单上，那个还没住进房的住客的名字，已经被安排进了一间房。房间号码，正从一扇门，移到另一扇门，像在等着当夜，把那个人，变成另一个死者。
