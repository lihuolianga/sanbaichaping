# 第354章 谁在证词里撒了谎

询问在石殿进行。李无咎把四张石凳摆成方形，让唐执、苍梧真人、冯伯各坐一方，第四方留空。宁知微坐在旁边记录，裴照夜站在殿门口。皇长子梁玠站在殿外，没有进来，但也没有离开。

第一个被问的是皇室密税册的建立时间。

唐执说："密税册是十年前续费制度确立时，由户部会同皇室共同建立的。续费与密税同步，账目有据可查。"

苍梧真人说："密税册不是十年前。本座接手龙渊供奉是五年前，五年前才见到密税册。十年前只有续费账，没有密税册。"

冯伯说："密税册我见过更早的。老供奉在的时候，也就是二十年前，账房里就有一本册子，封皮写的是'国祚备记'，里面的记法和现在的密税册一样。"

三个时间。十年前。五年前。二十年前。

第二个被问的是续费碑的位置。

唐执说："续费碑只有龙渊石厅一块。历年续费记录都刻在碑上。"

冯伯说："不止一块。老供奉在的时候，邻州的泰安、兴平两县，各立过一块续费碑。后来碑被撤了，说是不必张扬。"

苍梧真人说："本座任内没有见过外州续费碑。龙渊的碑是唯一一块。"

三个说法。一块。两块被撤。唯一。

第三个被问的是停缴测试。

唐执说："国廷从未下令做过停缴测试。停付国库续费是今年的事。"

冯伯说："五年前停过东侧灵石槽，三天，死了两亩冬麦。下令的人不是户部，是宫里传的话。"

苍梧真人说："本座任内没有停过灵石填装。灵石每月定时填装，从未间断。"

铁算盘拨完三组证词，把算珠停在半空："老夫只能确认一件事：这三位说的，都是他们自己相信的真话。唐侍郎相信密税册是十年前建的，苍梧真人相信是五年前建的，冯伯相信更早有'国祚备记'。他们都没有撒谎，但三份真话拼不到一起。"

"拼不到一起，说明有人把账改过。"李无咎站起来。他故意说了一个错误结论，说得很慢，让殿里每个人都听清："这样看来，事情就清楚了：归鹤真人当年独自设了这个敛财封印，收了十年续费，如今断缴，封印失控。这是归鹤一个人的账，和皇室、供奉、地脉司都没有关系。按这个说法，售后堂该把归鹤留下的账全认下来，该补的补，该赔的赔。"

他说完，停住，等着有人纠正。

荀渊从石殿暗处走出来。他一直没有参与登记，但这句话他接了。他站在李无咎面前，开口的声音很平："李先生，你这个结论有一个地方说不通。龙渊断口的地脉调配符，是九霄地脉司的符式。这枚符式，需要地脉司的印信才能启动。归鹤真人再厉害，他画不出地脉司的官印。"

"你的意思是，设封印的人里有地脉司？"

"我的意思是，这枚调配符在我任内之前就在龙渊断口上。它是被纳入调配体系时留下的。至于是谁设的，我的前任没有移交相关记录。"荀渊顿了顿，"但有一点我可以确认：设这枚符的人，知道断口下面是地脉，知道续费养的是地脉，知道'妖王'是后来人加上去的说法。他画不出这枚符，但他可能配合了画符的人。"

李无咎把"配合"两个字记了下来。他没有继续追问，但铁算盘已经把荀渊这段证词录进了因果簿。

石殿门口，皇长子梁玠忽然开口。他站在殿外，声音隔着门槛传进来："李先生，地脉司的人说的话，不能全信。地脉使是天庭的人，天庭想插手下界龙脉，才设了这套续费制度。你们查到最后，无非是查出一桩天庭的旧账，对国祚毫无帮助。"

"天庭的旧账，和国祚有什么关系？"李无咎问。

"龙脉是国祚的根。续费停了，灵气倒流，国祚受损。你们要是把续费制度查没了，谁负责恢复灵气？"梁玠说完，转向殿内，"本宫建议，先恢复续费，稳住灵气，其余的事，容后再议。"

"恢复续费，稳住灵气。"李无咎把这两句重复了一遍，"恢复续费，灵石进了谁的口袋？梁玠殿下，续费的钱七成归皇室，三成归供奉，这笔账在灵石槽背面刻着。你让售后堂恢复续费，是让皇室和供奉继续收钱，让地脉继续被养着，让'妖王'的说法继续挂着。钱收了十年，国祚储备攒了十年，可龙渊断口的维护记录只有二千两一年。你确定，续费养的是国祚，还是养的是账本上那几个名字？"

梁玠没有接话。他站在殿外，身侧的人影被灵灯拉得很长。

裴照夜在这时候走到李无咎身边，声音很低："殿外有人开始围过来了。几个宗门的弟子听说龙渊出事，聚集在石殿外，要求处分维护者。他们说，灵气倒流是龙渊守了四十年没守好，要冯伯负责。"

"要冯伯负责？"李无咎走到殿门口，看向外面。石殿外的空地上，确实聚了十几个穿不同宗门服饰的弟子。有人指着石殿，声音越来越大："龙渊守了四十年，续费收了几十年，现在灵气倒流了，他不负责谁负责？"

"都站住。"裴照夜走出来，站到冯伯身前，"每一项指控要有依据。冯伯负责填装灵石，填装记录在案，十年没有缺漏。灵气倒流的起因是国库停付，不是填装失职。谁要指控他，先拿依据。拿不出依据的指控，我不接受。"

"那灵气为什么倒流！"

"因为国库停付。"裴照夜说，"停付是国廷的决定。你们要质问的，是下令停付的人，不是填灵石的人。"

人群安静了一瞬，但没有人退开。有人低声说："国廷的事，我们能问吗？问多了，我们还要不要在大梁修行了？"

李无咎站在殿门口，没有劝，也没有挡。他只是在人群安静的那一瞬，说了一句："你们可以问。问的时候，把账带着。灵气倒流之前，续费的钱去了哪，国祚储备是什么，妖王是谁编出来的。这些问题，比'谁该负责'更该先问。问清楚了，负责的人自然就找到了。"

人群没有散，但没有人再喊。

石厅深处在这时候传来一声闷响。声音不是从棺里来的，也不是从矮门传来的，是从石厅的地底传上来的，像一根锁链被人从深处拉紧。李无咎回头，看到空妖王棺下方的地面，缓缓裂开一道口子。口子里露出一截青铜色的锁链，链环上刻着地脉调配符的纹路，链环正一段一段地收紧，发出沉闷的金属声。

"地脉天锁。"荀渊的声音在石厅里响起，比之前紧了一分，"它自己启动了。我没有碰它。"

"地脉天锁是什么？"

"锁住断口的锁。平时锁着，续费时松开，让灵石进断口。"荀渊盯着那截正在收紧的锁链，"它自己启动，只有一种可能：断口感应到了危险，在自我封闭。"

锁链还在收紧，一环接一环，发出沉闷的声响。空妖王棺的棺盖与棺身之间，那道青色的光又亮了一下，这次亮的时间更长，像地底的什么东西，终于被锁链的声响惊动了。
