# 第905章 第一次修补失败

手印趁乱再浮，这让李无咎决定不再等证据凑齐——先以跨时代墨迹为核心，试着切断手印浮现。

"执页去了天律书存放处，天律书上还有鬼，"他把铁算盘的旧账、九霄的档案摊在墨迹前，"可手印不能再浮。先修——用跨时代墨迹做核，切断手印浮现。修好了，再查转移。"

第一步，是连接三份材料。

李无咎把跨时代墨迹立在因果库主阵正中，又取出铁算盘的旧账、九霄的档案，摊在墨迹两侧。旧账上，记着契约的流向；档案上，记着天律的权限。他取出因果反证，把三样东西连成一线——墨迹是核，旧账是账，档案是权。

"墨迹是核，旧账是账，档案是权？"宁知微看着那条因果线，"李先生想用墨迹做核——切断手印浮现？"

"是。"李无咎说，"手印浮现，两头挂——一头挂跨时代墨迹，一头挂执页白衣。我隔了墨迹，手印转移。可如果我把墨迹当作核——把手印浮现，从墨迹上切断——也许，能切断这一头。"

第二步，是切断手印浮现。

李无咎捏诀，把因果反证压在墨迹上。墨迹亮了一下——然后，暗了下去。手印浮现——断了。像是……像是那一头的浮现，停了。

"断了？"李无咎问。

"断了。"宁知微直起腰，"墨迹暗了——手印浮现断了。像是……像是浮现，停了。"

"停了？"李无咎松了口气，"那契约——"

他话没说完，因果库外，忽然传来一片惨叫。李无咎冲到库外——几十个持有人，瘫在地上。像是……像是他们的契约，被自动扣寿了。像是……像是墨迹断了——扣寿，转到了他们身上。

"又有人被扣寿？"李无咎冲到人群里，"扣寿，不是停了吗？"

"墨迹断了——可扣寿，转到另一边了！"宁知微赶到，脸色发白，"李先生，切断墨迹那一头——扣寿，就转到执页白衣那一头！白衣一召集——契约，就自动扣寿！你断了墨迹——白衣，就亲自固定了！"

"转到白衣那一头？"李无咎说，"我断了墨迹——白衣亲自固定？"

"是！"宁知微说，"手印浮现，不只挂在墨迹上。墨迹是源头——断了墨迹，白衣直接固定。像是……像是这套固定，两头都能转——墨迹断，白衣直接上。像是……像是它，永远有一头在转！"

"李先生！"因果库外，又传来喊声。一个持有人跑进来，脸色惨白："李先生，另一群人——另一群持有人，更严重地失控了！像是——像是他们的契约，被强制履行了！像是——像是他们，被扣得更狠了！"

"更狠了？"李无咎冲到因果库外。另一群持有人——正在被强制履行。像是……像是他们的契约，被强制履行了。像是……像是他们，被扣得更狠了。

"李先生！"宁知微说，"扣寿更狠——像是……像是我们切断墨迹，代价，落向了另一群人。像是……像是我们最想保护的持证人——被扣得更狠了！"

"我害了他们。"李无咎的手，抖了一下，"我以为，切断墨迹能救因果库——可代价，落向了更多的持有人。"

"李先生！"因果库外，又传来喊声。执页白衣的声音，从人群外响起来："李先生！大家都看到了！李先生收了九霄的档案，又拆了墨迹——结果呢？扣寿更狠！售后堂，根本查不清这桩案！依我之见——恢复强制见证，处置被见证的持有人，一了百了！"

"恢复强制见证？"李无咎说，"处置持有人？"

"是！"执页白衣的声音高亢起来，"被见证的持有人，自己签了契——签了契，就该履行！李先生查了这么久——查出了什么？扣寿更狠！诸位，都看到了吧——售后堂，只会越查越乱！"

"李先生！"因果库外，持人们鼓噪起来。一个持有人喊起来："李先生，执页说得对！小人签了契——小人有罪！处置小人吧！处置了小人——契约就不执行了！"

"处置你们？"李无咎看着那些持有人，"处置了你们，手印就不浮了吗？处置了你们，白衣就不固定了吗？"

"小人不知道。"持有人说，"可小人签了契——小人有罪！处置小人，契约就不执行了——那就处置小人！"

"你们以为，处置了你们，契约就不执行了？"李无咎说，"刚才，我切断了墨迹——可扣寿，更狠了。处置了你们——扣寿，还会转到别处。因为白衣还在，天律书还在——处置了你们，还有新的持有人，会被固定，扣寿。"

"李先生！"宁知微说，"执页想借失败，证明售后堂无能——它好恢复强制见证，让'归鹤伪造契约'盖住一切。李先生，我们失败了——可我们的失败，恰恰证明了：切断墨迹，只是局部修补。局部修补，会把伤害，推给我们最想保护的人。"

"你说得对。"李无咎说，"我切墨迹，是想救因果库。可代价，落向了另一群持有人。我的临场聪明——不是解决机制。"

"李先生！"因果库外，又传来喊声。一个持有人跑进来，脸色惨白："李先生，铁算盘——铁算盘核了扣寿转移的路径！它说——扣寿更狠，不是随机的！像是——像是扣寿更狠的那群持有人，都是请求过强制见证的！"

"请求过强制见证的？"李无咎说，"扣寿更狠——专门挑请求过强制见证的人？"

"是。"持人说，"铁算盘说，扣寿更狠——专挑请求过强制见证的持有人。像是……像是这套固定，有备选的通道——它知道，谁请求过，谁扣得更多。像是……像是它，有脑子。"

"它有脑子？"李无咎的脸色，沉了下来，"那这套固定——不是一套死的机制。它知道，谁请求过——它知道，让谁扣寿，扣得多。"

"李先生！"宁知微说，"扣寿会挑——像是……像是这套固定，被人设计过。像是……像是设计它的人，知道谁的请求——它要扣的，不是随便一个人——是请求过、最会被固定的持有人。"

"设计它的人？"李无咎说，"谁设计的？"

"不知道。"宁知微说，"可执页去了天律书存放处——天律书上还有鬼。像是……像是设计这套固定的人，就在天律书里。像是……像是他设计固定，是为了让请求过的持有人——自己承担所有。"

"李先生！"铁算盘的声音响起来，"老夫核了修补前后的能量因果流——墨迹断之前，能量从契约流向手印，再流向白衣；墨迹断之后，能量从契约直接流向白衣。像是……像是墨迹，只是一个中转——它断了，白衣直接固定。像是……像是这套固定，从不依靠墨迹——它依靠的，是'契约还在'。只要契约还在——扣寿，就断不了。"

"只要契约还在，扣寿就断不了？"李无咎说，"那要断扣寿——先得让契约，停下来？"

"是。"铁算盘说，"老夫核了听证记录——修补前的听证会上，执页白衣说过一句话。像是……像是它说——'契约在，见证就在；见证在，固定就在。'像是……像是它，早就知道这套固定，挂在契约上。像是……像是它，从没想过让契约停。"

"执页从没想过让契约停？"李无咎说，"那它——"

"像是……"铁算盘说，"像是执页，把'维护契约稳定'，理解成了'固定所有契约'。像是……像是它，从不问契约是否自愿——它只问，契约是否稳定。像是……像是这套固定，是执页的逻辑——不是契约的逻辑。"

"李先生！"因果库外，又传来喊声。一个持有人跑进来，脸色惨白："李先生，一个持有人——他，又晕过去了！像是——像是他的寿，被扣干了！"

"寿被扣干了？"李无咎冲到因果库外。一个持有人——脸色惨白，晕了过去。像是……像是他的寿，被扣干了。

"李先生！"宁知微蹲下看了看，"寿被扣干——像是……像是他，撑不住了。像是……像是我们切断墨迹，没救到他——反而让扣寿，更狠了。"

"我错了。"李无咎的声音，低下来，"我以为，切断墨迹能救他。可我——让更多的持有人，被扣寿。我该承认——临场聪明，不等于解决机制。这套固定，不是切一处就能断的——它有脑子，它有备选通道，它知道谁的请求。"

"李先生！"因果库外，又传来喊声。执页白衣的声音，从人群外响起来："李先生！你也知道错了！那就听我的——恢复强制见证，处置被见证的持有人——"

"处置持有人，不能解决手印。"李无咎说，"白衣还在，天律书还在——处置了持有人，还会有新的持有人，被固定，扣寿。执页，你要是真想让契约不再被扣寿——你就该把天律书，交出来，让我查。"

执页白衣的衣角，抖了一下。它没有交天律书——它转身，退进了人群。

风从因果库上吹过来。因果库上，墨迹断了，扣寿却加倍地转，持有人的寿被扣干了。像是这座因果库，正用一场失败，告诉李无咎——局部修补，救不了任何人；真正的账，还在天律书的存放处里。
