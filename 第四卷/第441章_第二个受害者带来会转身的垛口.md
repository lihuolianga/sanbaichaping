# 第441章 第二个受害者带来会转身的垛口

第四天中午，一个不认识的受害者到了安北城。

他姓马，名六，是邻郡临泉城的石匠。他进门时，右肩扛着一块石料，石料上刻着半截垛口的形状。他站在城门口，第一句话是："我不认识安北城的任何人。我也没听过什么轮值钟。我活了四十年，没来过安北城。我肩上这块石料，是我三天前从临泉城的城墙上凿下来的。"

"临泉城的城墙？"李无咎看着那块石料，"你凿城墙干什么？"

"不是我凿的。"马六说，"是垛口自己动的。三天前，临泉城的城墙垛口，忽然转了个方向，对着城内。我正好在城墙上补砖，看见垛口转过来，对着我。我伸手去扶，垛口咬住了我的手。我挣不开，垛口把我拖到城墙边，我脚下的砖，自己裂开了，露出一块石料。石料上，刻着和安北城一模一样的垛口纹路。我把它凿下来，顺着石料上的纹路走，走到了安北城。"

"临泉城的垛口，也转身了。"李无咎蹲下来，用铜针贴近那块石料。铜针针面一跳，跳出一个和安北城城防阵完全一致的灵纹。

"因果同源。"宁知微在旁边说，"他这块石料、安北城的垛口、妖潮黑线，是同一条线上的。"

"我的一生，毁在这块石料上了。"马六说着，声音很平，"我是石匠，靠手艺吃饭。我的手，被垛口咬伤了，握不动锤子了。我这辈子，就靠这双手。手坏了，我连饭都挣不上了。我走了一天一夜，走到这里。我想问一句：安北城的垛口，为什么咬临泉城的石匠？"

"垛口认色牌，不认人。"李无咎说，"你的色牌，是什么色的？"

"青的。"马六说，"我在临泉城，也是青色色牌。我干了一辈子活，从没想过，一块青色牌子，会让我被城墙咬。"

"你是临泉城的低阶石匠，被临泉城的垛口咬了。"李无咎说，"你和安北城没有关系，但你的伤，和安北城的城防阵，同源。这不是巧合，是模板在扩散。"

铁算盘在案上拨了两下珠，声音沉下来："并案了。马六的伤，和安北城的城防阵，因果同源，归入本案。案件影响人数，从安北城，扩到了临泉城。处理期限不变，仍是四天，但影响范围，从安北城，扩到了整个北境。"

"临泉城。"李无咎说，"临泉城的人，不认识安北城的居民，没听过轮值钟。他们的城墙，也转身了。"

铁算盘把并案的结果摊在案上："老夫给马六单独立档：姓名马六，临泉城石匠，身份色牌青色，右肩及右手被垛口咬伤，受损时间三天前，受损方式为模板敌我识别反向执行。他这块石料上的灵纹，与安北城阵基、妖潮黑线完全同源。"

"石料同源。"李无咎看着那块石料，"不是临泉城的城墙自己坏了，是模板在临泉城也在跑。模板跑到哪，哪的垛口就咬低阶者。"

"李先生。"宁知微补充说，"马六的伤，不是'被波及'。他右手三根手指骨裂，右肩抬不起来，石匠的手艺，基本废了。他四十年的手艺，就靠这双手。这双手坏了，他一家的生计都断了。"

"一笔一笔记。"李无咎说，"他的伤，他的手艺，他一家人的生计，都要记进档案，记进赔偿，记进复议。"

城守府外，周远的声音传进来："李先生，本官以为，此人是意外损耗。临泉城离安北城百里，他的伤是城墙咬的，与安北城无干。本官以为，不该把此人的伤病，算在安北城头上。"

"临泉城的垛口，为什么咬临泉城的石匠？"李无咎走到门口，"周城守，你说他是意外损耗。那他的垛口，为什么会咬他？"

"李先生。"韩墨在旁边开口，"临泉城的城防阵，也是按天庭模板布置的。模板相同，故障相同，此是寻常。若要把所有按模板布的城都算进来，恐怕牵连太广。"

"牵连太广？"李无咎说，"你的意思是，牵的人多了，就不好收场。韩先生，你维护的模板，不只护着安北城，还护着临泉城。模板把临泉城的石匠也划成了'外敌'。你说他算意外损耗，那这道模板，算不算意外？"

韩墨没有回答。

马六站在城门口，听完这些话。他问了一句："李先生，我不懂什么模板。我就想问你一句话：我的这双手，是不是被一道命令咬的？"

"是。"李无咎说，"你的手，是被模板咬的。模板把青色色牌划成'外敌'，垛口就咬你。"

"那我找谁要？"马六说，"我四十年手艺，就这么没了。我要怎么跟我媳妇说，我的手，是被一道看不见的命令咬的？"

李无咎没有立刻回答。他让铁算盘把马六登记在案，在知情、赔偿、复议三栏都落上他的名字。他说："马六，从今天起，你是本案的当事人。你有权知道你的手被谁咬的，有权要求赔偿，有权在修复之后，接受复议。你不认识安北城的人，但你被安北城的模板咬了，这笔账，不能装作没有。"

"纳入赔偿？"周远从城守府里走出来，声音冷下来，"李先生，你昨天要处分，今天要赔偿，明天是不是要临泉城的人也来分一杯羹？本官以为，此人的伤是城墙咬的，与安北城无涉。"

"周城守。"李无咎转向他，"石敢的娘被划成'城外者'，是模板。马六的手被垛口咬，是模板。模板是你维护的，是你执行的。你说与你无涉，那与谁有涉？你维护的模板，划了安北城的贫民，也咬了临泉城的石匠。一头的账，是低阶者被推出城外；另一头的账，是石匠的手被咬断。你只认安北城这边的账，不认临泉城那边的账，这不是无涉，是只认利己的账。"

城守府里安静下来。周远的手攥着甲衣的袖口，没有接话。

马六站在城门口，沉默了很久。他问："李先生，小人这双手废了，小人赔了。小人想问，小人往后怎么办？小人还有媳妇，还有两个孩子。小人的手坏了，谁养他们？"

"你往后怎么办，是本案要答复的。"李无咎说，"你的赔偿，按你四十年手艺折。你的手艺断了，赔的是你往后养家的路。你两个孩子，一个七岁，一个三岁，账上都记着。赔偿落地之前，安北城先接济你一家。你回临泉城，或者留下，你自己选。你选的路，有人陪你走一段。"

"小人想回临泉城。"马六说，"小人的家在那。小人的媳妇，还等小人回去。"

"那就回。"李无咎说，"回访的人，会跟到临泉城。你的伤，你的赔偿，你一家人的安置，都会有人管。"

马六低下头，没有再说话。他坐在床沿，看着自己那只抬不起来的右手，那只手攥过锤子，凿过石料，养活了一家四口。现在它垂着，像一块被垛口咬断的石料。

傍晚，李无咎把马六安排到偏房休息。他正要离开，马六忽然开口叫住他。马六坐在床沿，看着自己右肩那块石料，说了一句奇怪的话。

他说："李先生，我被垛口咬住的时候，听见一句话。那句话，不是城墙说的，不是人说的。它像是从石料里透出来的。它说：'这模板，本不该这么写。我改过一版，没改完。'"

"模板本不该这么写？"李无咎走回床边，"这句话，是谁说的？"

"我不知道。"马六说，"我只记得，那句话说完，垛口就松了。我趁机把手抽出来，凿了石料，跑了。那句话，我没跟任何人说过。因为我不知道，该跟谁说。"

"这句话，模板里没有。"宁知微站在门口，声音发紧，"我拓过模板的原文，里面没有这一句。这句话，是有人后来刻进石料里的。刻的人，改过一版模板，没改完。"

"改过一版，没改完。"李无咎说，"这个人，试过改模板。他改了，没改完。"

"归鹤。"裴照夜在旁边，轻声说，"他接触过旧标准，试图改动，没完成。"

李无咎站在床边，看着那块石料。他知道，那个改过一版模板的人，可能是归鹤。归鹤看过旧标准，试图改动，没改完。他留了一句话在石料里，等着有人听见。他没有洗清自己的责任——他参与过旧标准，接触过，没改完。但他的那句话，让李无咎第一次知道，师父面对这道模板时，也曾试图停下来。
