# 第601章 谁在证词里撒了谎

山体深处的呜咽，让李无咎决定把证词问全。

他把人分开，一个一个叫进山下的祠堂。第一份证词，来自矿商贾老板。

"贾老板，你包矿二十年。三年前，新山神册封。你记不记得，新神册封是哪一天？"李无咎问。

"这……"贾老板想了想，"好像是三年前的三月初九。天庭的册封令下来那天，山民还办了庙会。"

"三月初九。"李无咎记下，"那你记不记得，矿脉开始变薄，是哪一年？"

"是……"贾老板想了想，"也是三年前。大概是秋天的时候，矿脉就开始薄了。"

"册封是三月初九，矿脉变薄是秋天。"李无咎说，"中间隔了半年。那你有没有想过——这半年里，山灵在做什么？"

"这……"贾老板答不上来。

"那我再问你。"李无咎说，"这三年，矿脉变薄。你有没有算过——你挖的矿，比前十七年少多少？"

"少……"贾老板算了算，"少了一大半。前十七年，一年能挖千来斤矿；后三年，一年就剩三百来斤。"

"少了七成。"李无咎说，"矿挖得少了，你的银子，少赚了多少？"

"这……"贾老板低下头，"少赚了不少。小人前十七年攒下的家底，后三年快赔光了。"

"你赔了银子。"李无咎说，"可你想过没有——矿少了七成，不是矿脉枯了，是山灵被抽走了。山灵没了，矿就没了。你赔的银子，是山灵被抽的账。"

"小人……小人没想过。"贾老板说，"小人只想着，矿少了，得想法子多挖些。"

"你想着多挖。"李无咎说，"可山灵被抽，你挖得越多，山空得越快。你再挖下去，山塌了，矿也没了。"

贾老板的脸色变了一下，没有再说话。

第二份证词，来自石伯。

"石伯，石门山的田，是从什么时候开始变薄的？"李无咎问。

"也是三年前。"石伯说，"三年前，新神册封，田就开始薄了。山上的泉水，一年比一年小。"

"三年前，册封之后，田开始薄，泉水开始小。"李无咎说，"石伯，山民祭拜新神，祭拜了三年。祭拜的时候，你们觉得，新神保佑丰收吗？"

"……保佑。"石伯的声音有些迟疑，"新神保佑丰收，是真的。田虽然薄了，可收成还是有的。新神保佑，田里的庄稼，还是能长的。"

"田薄了，收成还有。"李无咎说，"那你们有没有想过——田薄了，是山空了；收成还有，是谁给的？"

石伯沉默了一下："李先生，您是说——"

"我是说，"李无咎说，"田薄了，是山灵被抽走了；收成还有，是石娘的山灵，还在撑着。山民以为新神保佑丰收——可丰收的底下，是石娘被抽的山灵。"

第三份证词，来自新山神。

新山神没有实体，只有神像。李无咎站在神像前，神像的眼睛，那一线金光，微微动了动。

"新山神，我问你三件事。"李无咎说，"第一，你册封石门山，是谁下的令？"

神像的金光闪了一下，一个声音响起，像是金铁相击："奉天庭敕令。天庭册封石门山，令本神接掌。"

"天庭册封你。"李无咎说，"那你接掌石门山，是为了什么？"

"维持神位秩序，保佑山民丰收。"神像说。

"保佑山民丰收？"李无咎说，"那我问你——石门山的山灵，被你抽到哪去了？"

神像沉默了一会儿："山灵，归天庭调拨。"

"归天庭调拨。"李无咎说，"你把石门山的山灵，抽上去，交给天庭了？"

"山灵归天庭统管。"神像说，"本神只是执行。"

"你只是执行？"李无咎说，"你执行天庭的令，把山灵抽上去。那山民呢？山民祭拜你，你把山灵抽走，山民的田薄了，泉水小了——这叫保佑丰收？"

"丰收，是神位庇佑。"神像说，"山民祭拜，神位庇佑，各得其利。"

"各得其利？"李无咎说，"山民的田薄了，泉水小了，这叫各得其利？"

神像没有再说话。金光缓缓收敛，像是答不上来，又像是懒得答。

"新山神。"李无咎又开口，"我再问你一句。你册封石门山，知道石娘被封进石头的事吗？"

神像沉默了一会儿："……知道。九霄执行令上，写了。"

"你知道石娘被封进石头，还接掌了石门山？"李无咎说，"你知道山灵被抽，还继续抽？你知道山体空化，还坐着神位？"

"本神奉命行事。"神像说，"天庭令下，本神执行。石娘封石，是九霄的令；山灵调拨，是天庭的规。本神只是执行。"

"你只是执行。"李无咎说，"执行的人，就不用问对错吗？"

神像没有再回答。金光完全收敛，神像像是睡着了。

第四份证词，来自白算盘。

"白算盘，四份证词，你核了没有？"李无咎问。

"核了。"白算盘的珠面亮了一下，"贾老板说矿脉三年前秋天变薄，石伯说田三年前开始变薄，新山神说山灵归天庭调拨。三个人的说法——都对得上，也都对不上。"

"都对得上，也都对不上？"李无咎问。

"是。"白算盘说，"对得上的是时间——都是三年前。对不上的是因果——贾老板以为是矿挖多了，石伯以为是天旱，新山神以为是正常调拨。三个人都信自己的说法，可三个人，都不知道山灵到底去哪了。"

"那山灵去哪了？"李无咎问。

"老夫核了册封金纸。"白算盘说，"金纸是三年前天庭发的。金纸上的能量流向——指向天庭。可金纸的时间，和山灵被抽的时间，对不上。"

"对不上？"李无咎问。

"是。"白算盘说，"金纸是三年发的，可山灵被抽，是从五年前开始的。五年前，金纸还没发，山灵就已经在被抽了。"

"五年前就开始抽了？"李无咎皱眉，"可新神是三年前才册封的。五年前，山灵是谁在抽？"

"老夫不知道。"白算盘说，"老夫只能确认——山灵被抽，比金纸早两年。也就是说，在新神册封之前，就有人在山里抽山灵了。金纸，只是把这桩事，盖了一个'合法'的章。"

"金纸盖了个合法的章。"李无咎说，"那五年前，抽山灵的，是谁？"

"老夫前身的账里，没有记。"白算盘说，"老夫只知道，金纸的时间，骗不了人。山灵被抽了五年，金纸是三年前的——这中间的两年，是个缺口。"

"两年的缺口。"李无咎说，"两年里，山灵在被人抽，没人管。两年后，天庭发了金纸，把抽山灵盖成'合法'。也就是说——有人抽了两年，等天庭盖了章，接着抽。"

"老夫只能确认到这里。"白算盘说，"两年的缺口，谁在抽，为什么抽——老夫前身的账里，没有记全。"

"记下来。"李无咎说，"五年前开始抽山灵的人，列为待查线索。等查清了，这笔账，一起算。"

"李先生！"祠堂外，忽然传来一阵骚动。一个山民跑进来，脸色发白："李先生，山下的认神鼓——认神鼓自己响了！"

"认神鼓？"李无咎问，"认神鼓是什么？"

"是山民祭拜山神的鼓。"石伯说，"祖上传下来的规矩，祭拜山神，要敲认神鼓。鼓一响，山神就知道山民来祭拜了。可——认神鼓，从来都是人敲的，它自己不会响！"

"认神鼓自己响了？"李无咎冲到山下。山下的广场上，立着一面大鼓。鼓面蒙着兽皮，鼓身刻着山纹。此刻，那面鼓，正一下一下地，自己响着——咚，咚，咚，像是有什么东西，在鼓里敲。

"鼓自己响了。"宁知微的脸色发白，"认神鼓是山民认神的鼓。它自己响——说明有东西，在替山民认神。不是山民认的——是这鼓，被远程牵引着，替山民认神。"

"远程牵引？"李无咎问。

"是。"宁知微说，"认神鼓认的是'神位'。神位在，鼓就认。新神有神位，鼓就替山民认新神——山民还没认，鼓先认了。"

"鼓替山民认了新神。"李无咎说，"那山民的意愿，在这面鼓里，算什么？"

"算……"宁知微的声音很轻，"算没有。鼓替山民认了，山民自己认不认，都不重要了。"

风从山下吹过来。那面认神鼓，还在一下一下地响着——咚，咚，咚。而山神庙里，新神像的眼睛，那一线金光，正随着鼓声，一下一下地亮着，像是——像是那面鼓，正在替整座石门山，认下一个它自己从没选过的神。
