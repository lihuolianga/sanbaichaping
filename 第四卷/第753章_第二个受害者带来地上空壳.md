# 第753章 第二个受害者带来地上空壳

心魔法像自己动了，这让李无咎还没来得及深究，下界道场又来了第二位不速之客。

来的是一个年轻妇人，怀里抱着一个孩子。孩子七八岁，双眼紧闭，呼吸微弱——他的身体，空空的，像是一具空壳。

"这是……"宁知微蹲下来看那个孩子，"一个空壳？"

"是。"妇人的声音发抖，"小人是从山下的镇子来的。这个孩子，是小人的儿子。他——他前些日子，忽然倒下了。他的身体，空了。像是……像是有什么东西，把他的魂，抽走了。"

"镇子的孩子空壳？"李无咎说，"他没修行，没买飞升？"

"没有。"妇人说，"小人的儿子，才八岁。他什么都不懂。可他的身体——空了。像是……像是有什么东西，从他身上，抽走了什么。"

"李先生！"铁算盘的声音响起来，"老夫核了这个孩子的灵息。他的灵息——和薛照尘本体的空壳，是同一种。像是……像是他被同一种东西，抽空了。"

"同一种东西？"李无咎说，"那是什么？"

"像是香火。"铁算盘说，"孩子的灵息，和香火通道的术式，同源。像是……像是孩子，被香火抽过。像是……像是天上的心魔，借着香火，抽了这个孩子。"

"孩子被香火抽？"李无咎说，"可他没修行，没接触过香火？"

"像是。"铁算盘说，"可孩子的灵息，确实和香火同源。像是……像是香火，扩散到了镇子——孩子离香火近，就被抽了。"

"李先生！"妇人跪下来，声音发抖："李先生，求您救救小人的儿子！小人不知道什么是香火——小人只知道，小人的儿子，快不行了！他的身体，越来越空！"

"先救人。"李无咎蹲下来，探孩子的脉，"孩子还有气。可他的魂——像是被抽走了大半。"

"李先生！"宁知微说，"孩子的空壳，和薛照尘的空壳，是同一种。像是……像是这套香火，抽的不只是修士——它抽所有离香火近的人。老人、孩子、妇人——谁离得近，谁就被抽。"

"那这套飞升，"李无咎说，"不是只收薛照尘的人格——它是抽下界一片人？"

"像是。"铁算盘说，"老夫把孩子的差评，和薛照尘的差评，并案了。因果簿显示——同一套香火术式。受影响人数：不止薛照尘——是下界一片，几百人。"

"几百人？"李无咎说，"那被抽成空壳的人——不止薛照尘？"

"不止。"铁算盘说，"老夫只能查到——这套香火术式，用在了下界一片。薛照尘，只是最显眼的一个。山下的镇民、道场的修士、甚至孩子——都被香火抽过。"

"李先生！"妇人忽然开口，声音发抖："小人……小人想起来了！小人儿子倒下之前，说过一句话。小人一直没听懂。"

"什么话？"李无咎问。

"儿子说——"妇人说，"'娘，天上有人。他说，让我跟他走。他说，天上有仙位。'"

"天上有人，让孩子跟他走？"李无咎说，"那孩子——是被天上的仙位，勾走的？"

"像是。"妇人说，"小人儿子说完这句话，就倒了。他的身体，空了。像是……像是天上的人，把他的魂，勾走了。"

"李先生！"铁算盘的声音响起来，"老夫核了孩子的名印——孩子的名印，和薛照尘心魔的仙籍，同源。像是……像是孩子的魂，被吸进了仙籍。像是……像是天庭，用仙位，勾下界的人。"

"天庭用仙位勾人？"李无咎说，"那这飞升——不是飞升，是收割？"

"像是。"铁算盘说，"天庭的仙籍，勾下界的人——勾走他们的魂，抽走他们的灵息，把他们变成空壳。像是……像是天庭，把下界，当成了仙位的材料库。"

"李先生！"宁知微说，"孩子的魂，被勾走了。可他的身体，还在下界——成了一具空壳。像是……像是天庭，只收魂，不收身体。身体留在下界——空壳。"

"那孩子，"李无咎问，"还能回来吗？"

"不知道。"宁知微说，"孩子的魂，在天庭的仙籍里。要让他回来——得把魂，从仙籍里放回来。可放回来——天庭会发现。"

"李先生！"妇人喊，"小人只要儿子回来！小人不要别的！小人求您——把小人的儿子，还给小人！"

"先救人。"李无咎说，"孩子的魂，要回来。可魂回来——天庭会发现，有人动了仙籍。这代价——我来担。"

"李先生！"宁知微说，"您不能一个人担。孩子的魂回来，天庭发现——不只是您被追。孩子、妇人、整个镇子——都会被牵连。这代价，不能您一个人扛。"

"那怎么办？"李无咎问。

"要大家一起扛。"宁知微说，"孩子的魂要回来——可天庭的仙籍，也要查。谁把孩子的魂勾走的，谁要把魂放回来。这不是您一个人的事——是天庭的账。"

"李先生！"铁算盘说，"老夫核了并案的影响人数——三百二十人。这是当前的并案统计：薛照尘，加上山下的镇民，加上道场的修士——三百二十人，被香火抽过。他们的魂，可能都在仙籍里。可名单和逐人核验，还没做完。"

"三百二十人的魂，都在仙籍里？"李无咎说，"那这套飞升——它抽走了三百二十个人的魂？"

"像是。"铁算盘说，"按当前统计口径，像是天庭的仙籍，勾走了三百二十个人的魂。他们的身体，留在下界——成了一片空壳。可这三百二十人是统计数，不是逐一核验过的名单。"

"李先生！"妇人抱着孩子，哭喊："小人只要儿子！小人的儿子——小人只要他回来！"

"你的儿子，"李无咎说，"会回来。可回来的路——要先把天庭的仙籍，查清楚。谁勾走的魂，谁放回来。三百二十个人的魂——一个一个，都要回来。"

"李先生！"宁知微说，"孩子的魂在天庭——可孩子的身体，还在下界。魂回来，身体就能活。可魂回来之前——身体，还要撑着。得先保住孩子的身体，别让它彻底空了。"

"保住身体？"李无咎说，"那孩子的身体——"

"要先护住。"宁知微说，"孩子的空壳，还能撑一段时间。可要是再被香火抽——身体就彻底空了。得先切断孩子身上的香火——不让孩子，再被抽。"

"先切断孩子身上的香火。"李无咎说，"那孩子——先保下来。"

"李先生！"铁算盘说，"老夫要提醒——孩子的魂，在天庭仙籍里。要是我们切断了香火，天庭可能会发现——有人在动仙籍。天庭追下来——三百二十个人的魂，可能都保不住。"

"那不能切断？"李无咎问。

"要切断。"宁知微说，"可要留证据。切断香火之前——先把孩子被抽的痕迹，记下来。谁抽的，怎么抽的，抽了多少——记下来。将来天庭抵赖，我们有账。"

"先记痕，再切断。"李无咎说，"孩子的身体，先护住；孩子的魂，等着放回来；天庭的账，记下来。"

"李先生！"妇人抱着孩子，声音发颤："小人……小人什么都不懂。小人只想儿子活过来。小人不管什么天庭——小人只要儿子。"

"你只要儿子。"李无咎说，"我们会让儿子活过来。可儿子活过来的路——要先让天庭，把勾走的魂，放回来。这条路，我们一起走。"

风从山巅上吹过来。下界道场里，空壳的孩子躺着，三百二十个人的魂悬着。像是这座道场，正被一场"飞升"搅得天翻地覆——而真相，正藏在天庭的仙籍里。
