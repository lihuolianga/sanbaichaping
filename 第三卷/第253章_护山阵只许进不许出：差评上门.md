# 第253章 护山阵只许进不许出：差评上门

因果簿第三十三页翻开的时候，铁算盘正在算万应楼善后的最后一笔账。算盘珠子拨到一半停住了，他低头看着纸面上浮出的旧维修记录，算盘框里发出一声极轻的咔哒。

"壬午年护山阵维修。"他把每个字都念得很慢，"服务地点：回风山。维修状态：仍在服务中。客户签名：石仲轩。"

宁知微从互助维修手册第三版草稿上抬起头。"壬午年？"

"二十年前。"

"石仲轩今年多大？"

铁算盘沉默了两息。"二十四。壬午年他还没出生。"

纸面上的墨迹正在自动刷新。客户签名那一栏，石仲轩三个字每天都在重新签署。笔迹相同，时间自动填入，不是他本人签的，是某份旧契约替他续的。记录底部还有一行小字，墨色比正文浅，像是后来补上去的：本阵未提交关闭申请，视为设备在校准期内自动续约，下轮续约日期，今日。

远方传来一声钟响。

不是青州城更夫敲的那种报时钟，也不是镇邪司衙门的点卯钟。这钟声很沉，像是从山体内部向外振动，每一声都精确地停在上一声的末尾。重复，平稳，准时。李无咎站在窗口，手中量灵尺的铜头微微发烫。他在上一案善后结束后把尺子搁在案上六天，此刻尺子自己热了。

"回风山离青州多远？"他问。

裴照夜正在整理万应楼担保环案的最后一批封存档案。他没有抬头，直接报出数字："四百里。步行三天，御风两个时辰。"

"那个方向有没有镇邪司的封山令？"

裴照夜手中动作停了。他从档案夹底层抽出一份发黄的卷宗，封皮上的火漆印已经褪成暗红色。"乙亥年封山令。回风山护山阵异常，禁止任何人入山。签署人……"他翻到最后一页，指尖在签名处停了很久，"签署人已故。续签人已故。第三任续签人，这份封山令已经无人续签了十六年。"

"但没人解除。"

"对。"

李无咎把量灵尺插回腰间。尺子还在发烫。"走一趟。"

铁算盘收了算盘框，把那页旧维修记录从因果簿中小心地揭起来夹在算盘夹层里。他犹豫了一下，在算盘珠子底下压了一行小字：此阵从二十年前到今日，每日晨钟准时，每日签名刷新，每日都在自动续约。但他没有把这些话说出口，只是把算盘框啪地一合，跟在李无咎身后出了门。

回风山比他们预估的更安静。

山门正对着一条已经荒了一半的官道。道旁每隔百步就有一口水井，井沿的石板被磨得光滑，但井绳是干的，拴在辘轳上的麻绳断了一半，另一半垂进井口，末端没有水渍。宁知微蹲在第一口井边，从井壁上刮下一层白色粉末放在指尖碾了碾。不是盐碱，是灵气抽干后残留的灵土钙化层。

"这口井干了至少五年。"她站起来，望向官道尽头另一口井，"那边那口应该也干了。"

裴照夜沿官道走了一圈。一共八口井，五口完全干涸，两口井底还剩一层薄薄的水，最后一口还在出水，但井壁上的水线正在以肉眼可见的速度下降。他把每口井的状况记在册子上，在第五口井旁边画了一条斜线，这口井的井壁有一道裂缝，裂缝里渗出的不是水，是一种淡绿色的光。

那是灵流。从山上倒灌下来的。

"封山令的范围原本只在山腰以上。"裴照夜看着那道裂缝说，"但灵流倒灌的位置已经到山脚了。"

李无咎站在山门前，仰头望着回风山。晨雾还没有散，山体在雾中若隐若现。山门是完整的，青石台阶扫得干干净净，门匾上回风宗三个字没有一丝裂纹。山门两侧各立着一根阵柱，柱身刻满符文，其中一根的顶端嵌着一枚仍在发光的灵石。

从外面看，这是一座运转良好的护山阵。

然后钟声又响了。

晨钟从山内传来，穿透晨雾，在山门前激起一圈肉眼可见的灵纹涟漪。涟漪扩散到井口时，第五口井井壁上的绿光猛地闪了一下，水线又降了一寸。

山门外不止他们在等。

一个穿灰布长衫的中年人坐在道旁的石墩上，膝上摊着一本账册，手里攥着半块芝麻饼。他看到李无咎一行人，站了起来，动作不快，像是一个长期等待的人已经学会了不着急。

"程问岳。"他自报姓名，声音沙哑，"回风宗外门弟子。二十年前逃出来的。"

他把"逃"字说得很轻，轻到像是怕被山门听见。

李无咎看着他。此人四十余岁，鬓角已经白了，手上的账册边角磨得起了毛边。他在石墩上坐了多久？三年？五年？

"你一直在等？"

"不是等。"程问岳把账册翻到一页，"是在算。山上还有多少东西是我师父的，山下有多少块田被阵法抽干了，宗门外还有多少继承者无法确认死者身份。我算了十二年，越算越多，没法交账。"

他把账册递给李无咎。纸页上是密密麻麻的数字：灵田亩数逐年递减，井水深逐年下降，宗门名册上一百四十七个人的名字，每一个名字旁边都标注了荒坟位置，有三十九座坟他至今找不到。

"你进过山吗？"李无咎问。

程问岳摇头。"封山令说不让进。"他顿了顿，补了一句，"而且我试过一次。三年前我走到山门口，听见里面的晨课声，听见师兄弟们的声音，他们还在上同一堂课。我不怕封山令，但我怕走进去之后发现他们还是二十年前的样子，只有我老了。"

他话音未落，山门内忽然传来一阵脚步声。

不是一个人。是几十个人，步伐整齐，踩在青石板上发出清脆的回响。然后是朗朗的读书声，清一色少年的嗓音，念的是《灵枢初解》第三篇第七节。程问岳手中的账册滑落在地，他攥住了石墩边缘，指节发白。

"第三篇第七节。"他的声音在发抖，"灭门那天早晨，他们就在念这一节。"

山门内，晨课还在继续。

李无咎走向山门。阵柱上的灵石在他靠近时亮了一下，符文自动运转，护山阵的能量在他身前形成一层薄薄的光膜。这不是拦截，只是检测。检测完毕，光膜自动分出一条缝，然后他看见了一个不可思议的场景。

一只黑狐从山外的灌木丛中窜出来，径直穿过光膜，走进山门。护山阵没有任何拦截动作。黑狐进了山门之后回头看了李无咎一眼，然后沿着青石台阶往晨课方向跑去。与此同时，山门内侧的晨雾中浮出一个少年的虚影。他穿着回风宗的外门灰袍，身形只有十五六岁，正努力向外迈步。每走一步，雾气就淡一分，但每当他即将踏过山门门槛时，晨钟准时响起。一圈灵纹从钟声的核心扩散开来，像一只无形的手，把少年虚影轻轻推回了雾气深处。

少年的嘴在动。李无咎读出了三个字：让我出去。

他在说这句话的时候，山门内的晨课声恰好在念《灵枢初解》第三篇第七节的最后一句："灵流无阻，则百脉自通。"

宁知微站在李无咎身后，也在看那个少年的虚影。"他的投影在阵外维持了七息。晨钟响后一息内被拉回。"她从药箱里取出一枚铜针，在山门外的石板缝中扎了一下。铜针末端立即变成淡绿色，与井壁裂缝中渗出的灵流颜色完全一致。"投影消耗的不是阵内灵气，是山下的生机。"

这时候他们听见了第五个人的声音。

"让开。"

一个穿粗布短褐的女人从官道上大步走来。她肩上扛着一把锄头，锄刃上还带着湿泥。她走到第五口井边，把锄头往井沿上一搁，看了一眼井壁上的绿光，又看了一眼山门前的阵柱。

"我姓阮，山下七村的。上个月推举的代表。"她没有寒暄，直接指着井口说，"这口井前天还能打半桶水。昨天晨钟比平常多响了一声，井水直接见了底。你们是来修阵的还是来封山的？如果是封山，我建议你们先给我们留够今年的水。"

裴照夜出示了镇邪司的巡察令牌。阮秋禾看了一眼，没有行礼，只是点了点头。"巡察使。好。封山令续签了十六年没人管，现在终于有人来了。但我丑话说在前头，如果你们的方案是继续封锁，让山下七个村自己想办法找水，"她拍了拍锄头，"我不会同意。"

"不是封山。"李无咎说，"是维修。但我得先进去看看。"

阮秋禾打量了他一眼。从粗布道袍看到腰间的量灵尺，从量灵尺看到袖口露出的阵钉袋。"你就是那个……李先生？"

李无咎愣了一下。这是他第一次在青州城外被人这么称呼。万应楼善后之后，"李先生"的称呼从互助维修网的节点名单上传开，但他还不习惯。

"太平观李无咎。"他说，像是要纠正什么，又像是要确认自己还是原来那个人。

阮秋禾没有深究称呼的事。她只是说："田里刚种了麦。没有水，今年冬天七个村的人吃什么。"她把话说得很平，像是在陈述一个与阵法无关的事实。

李无咎点头。他转向山门，量灵尺出鞘。尺身上的刻度线正在自行变化，铜头对准山门内侧时，尺身发出的不是常规的嗡嗡声，而是一种有节奏的跳动。不是一把尺子在跳，是尺子在同步，它在同步山门内那口钟的节奏。

"晨钟的位置不对。"李无咎把尺子收回半寸，"尺子感应到钟声的位置在山脚，但钟声听起来是从山顶传下来的。"

他蹲下来，在青石台阶上铺开一根墨斗线。线头顺着台阶往下延伸，经过第五口井时，墨线自动弹起，在井沿上绕了一圈，然后继续向下，钻进官道尽头的一片灵田中。墨斗线的末端停在灵田正中央，那个位置的泥土已经开裂，裂缝中同样渗着淡绿色的光。

"故障源不在山顶。"李无咎站起来，在量灵尺刻度的辅助下画出三条线，"第一条：山门外层，允许妖物进入但不允许阵内意识离开。第二条：晨钟时序层，每日重置阵内时间，但钟的位置与声源不符。第三条，"他抬头看向程问岳账册上密密麻麻的荒坟坐标，"第三条在山外。坟与名册之间有连接。"

铁算盘拨了四颗珠子。"四条差评。客户不止一个。"

因果簿的纸面上已经开始自动分类。第一栏：阵内被困者。第二栏：宗门外继承者。第三栏：山下村民。第四栏，铁算盘拨了半天没拨出确切数字，最后只写了一行字：封山人员、误入者与周边受影响者，人数待确认。

这时候山门内侧的晨雾又动了一下。那个少年虚影第五次浮出来，这次他不再试图迈步，而是在雾气中飞快地用手指在地上画了两个歪歪扭扭的字。字迹几乎无法辨认，但李无咎读出来了：帮我。

然后晨钟第六次响起，少年的虚影被拉回雾中，地面上两个字被灵纹涟漪抹得一干二净。但这次抹除花了两息，比之前多了一息。

"他在适应。"宁知微说，"每被拉回一次，他重新投射的速度就快一点。他的记忆没有被完全清除。"

李无咎把量灵尺收回腰间。他整了整道袍，对裴照夜说："程问岳的账册要留底。山外荒坟要逐一对名册。阮秋禾代表的七个村每一口水井和每一块灵田都要记录当前状态。"然后他转向铁算盘，"四条差评分别登记。阵内的人不能被阵外的人代签受理书。"

铁算盘已经把算盘框打开，四排算珠分了四种颜色。他拨完最后一颗青珠，抬头问："服务范围？"

"只接受止损。"李无咎说，"不承诺恢复宗门。不承诺把阵内的人变回原样。不承诺一切代价由阵外来承担。"他在山门前站定，看着晨雾中隐约可见的青石台阶，"但有一个东西我要修，"

他的话音顿了一下。量灵尺在腰间又跳了一拍。这次不是同步晨钟，是尺子在感应到某样东西时的自主反应。李无咎低头看了一眼尺子，尺身的铜头上浮出一个极淡的金色印记，归鹤真人的术痕。这枚术痕他和宁知微在照真镜案见过，在替死纸人案见过，在万应楼旧手册里见过。在此刻的山门外，尺子感应到了第四处同样的术痕。

铁算盘注意到了那个印记。他把算盘珠拨到一半，没有继续。

李无咎没有追问。他把尺子上的术痕压回铜头深处，然后踏上了第一级台阶。护山阵的光膜在他身前自动让开一条通道。阵柱上的灵石闪烁了一下，符文流转，像是在确认某样东西，不是确认他的身份，是确认他身上携带的术痕。

光膜合拢的瞬间，山门内传出一串清脆的铃响。不是晨钟，是更细微的声音，像是一串钥匙碰到一起，或者一根铜针掉在石板上。宁知微低头看了一眼自己的药箱，药箱里那本互助维修手册封面上的归鹤旧字正在发光。

然后他们都闻到了一股味道。

米饭。

山门内飘出来的，热腾腾的，刚出锅的米饭香气。但香气中混着泥土的腥味和灵田特有的清甜。宁知微用手帕垫着，从山门内侧的石阶旁端起一只粗瓷碗。碗里是白米饭，粒粒分明，热气蒸腾，看起来是刚盛出来的。

她翻转碗底。碗底没有回风宗的标记，却有一层薄薄的土。土是湿的，里面嵌着细小根须。根须还活着，正在往碗的裂缝里钻。

"这不是二十年前保存下来的饭菜。"宁知微把根须放在铜针下，针尖碰到根须时发出极轻的滋啦声，淡绿色的灵光从根须断口渗出，"这是阵法今天用山下灵田的生机重建的。"

她翻开互助维修手册，在空白处快速画下米粒、根须与灵田之间的连线图。三者的灵流频率完全一致。她放下铜针，声音很冷："山上的弟子每天吃的不是存粮。他们在吃山下的地。"

程问岳从宁知微手中接过那只碗。碗底湿泥的触感让他沉默了很久。"我师兄弟在山上吃了二十年这种饭。"他把碗轻轻放在石墩上，"他们不知道每一口吃下去，山下的井就浅一寸。"

山门内的晨课还在继续。一百四十七个人齐声朗读《灵枢初解》第三篇第七节的声音在晨雾中回荡，字正腔圆，朝气蓬勃。他们不知道自己念的是二十年前最后一堂课的最后一句话。也不知道山下有人在等他们，山外的荒坟里躺着他们的名字，而他们的饭菜里生长着不属于他们的土地。

李无咎站在山门口，量灵尺在腰间跳着与晨钟完全一致的节拍。他没有回头，只是把尺子取下来握在手中，对身后的人说："我会修好护山阵。但我不会替任何人决定他们应该活着，还是应该被记住。"

宁知微把米粒样本封入药箱。铁算盘在四条差评栏下各拨了一颗算珠。裴照夜开始临摹封山令上已经无人续签的旧签名。阮秋禾扛着锄头坐在井沿上，目光从山门移到干涸的井底，又从井底移向那片已经出现裂缝的灵田。

回风山的晨钟第七次响起。

这次钟声多延了一息。一息之内，第五口井的水线又降了一寸，灵田中央的裂缝裂得更深了，而山门内那只粗瓷碗里新盛出的米饭，正从碗底长出第三根细小的根须。
