# 第260章 客户没有说完的话

阿阮的碎瓷碗被摆在山门台阶的第一级上。碗底那个歪歪扭扭的"阝"字朝着山门内侧，碗口朝着山外。李无咎让所有人都坐在碗周围——没有凳子，没有蒲团，就是山门前的青石板。所有人面对面坐着，中间隔着一只二十年前刻了一半名字的碗。

"从现在开始，每个人把没说完的话说完。"他把量灵尺横在膝上，尺身的刻度线静止不动，不是休眠，是在录。"不是审问。是补全受理书。每一条差评对应的人，把你知道但没有说出来的事写在这张笺上。"

他铺开四张空白因果笺。四张笺分别对应四条差评。每张笺都划了一条线，线上方写"已告知"，线下方写"曾隐瞒"。

程问岳第一个开口。他把那本磨毛边的账册翻到第一页——不是最前面，是一个被他折了角的很旧的页码。他用拇指反复搓着页边，把那一页从压了十二年的夹层里抽出来。

"我隐瞒的不是知道宗门已灭。我隐瞒的是——"他说话时眼神没有落在任何人身上，而是落在自己的账册第一行字上，"灭门那天我逃出来的方式。"

晨课室外的风忽然停了。

"那天傍晚，我听见后山有妖物的叫声。不是狐，不是狼，是一种我从来没听过的低吼。我很害怕，没有去跟师父报，反而往反方向跑。我从灶房后墙的裂缝钻出护山阵——不是裂缝，是当时阵法已经开始破损了，灶房后墙和外墙之间有条一尺宽的隙。我侧着身子挤出去，往外跑了约莫三里地，然后回头看了一眼。山上还在冒烟。"他的手指把账册页角搓出了一道折痕，"我没有回去。我一直在跑。跑下山，跑出村子，跑了两天两夜，跑出了回风山的地界。"

"你师父呢？"沈闻钟问。

程问岳的手不动了。"死了。我后来在荒坟碑上看见了他的名字。他那天傍晚在后山巡山，听见了和我在同一个方向传来的妖物低吼。他去了后山，他没有跑。"

他跑了，他师父去了。十二年后他拿着账册坐在石墩上，一笔一笔地计算师兄弟的荒坟坐标，但他们活着的时候，他没有回去。

"你觉得你欠所有人一条命。"李无咎说。

"不是觉得。"程问岳把那张旧页抽出来，翻过来放在阿阮的碗旁边。纸背上有他用蝇头小字写的密密麻麻的计算草稿——不是田亩和资产，是他在试图核算"如果当年回去"的每一种可能性。"我算过两百三十七次。每一次的结果都一样。即使我回去，也只是一个炼气三层的外门弟子，什么都改变不了。但每次算完之后我还是睡不着。"

他抬起头。"因为我逃掉了。这不是法器故障可以修的因果，这是我自己做的选择。"

沈闻钟沉默了一会儿。然后他站了起来，把自己那本册子放在程问岳的计算草稿旁。

"该我了。"他说，"我隐瞒的不止是知道宗门已灭。我还隐瞒了——我一直在配合晨钟重置。"

山门内侧的晨课室方向忽然传来一声很轻的铜铃响。不是下课铃，是挂在廊下那口用来召集弟子的旧铜铃被风吹动了一下。

"五年来，每当有师弟开始怀疑饭菜永远不会坏，或者在半夜往山门方向走，我就会提前通知执事。执事会调整晨钟的频率，提前重置那一天。"他的声音很稳，像是在陈述一个已经被自己反复推敲过很久的结论，"我替他们做了选择。我不知道这个选择对不对。但如果让我再来一次——我可能还是会这样做。"

"因为你不相信他们能承受真相。"宁知微说。

"不相信。阿洄例外。他有归鹤的保护符和陆知秋的记忆碎片，他能保留跨日记忆。其他人不行。"沈闻钟顿了顿，"顾长穗曾经问过我饭里的米为什么永远是圆的。我骗她说宗门用的是上好的千粒珠米。她知道那不是千粒珠米。但她没有再问。不是因为信了我，是因为她不想知道更多。"

"顾长穗还在等，我想在合适时机告诉她真相——"沈闻钟继续说。

程问岳合上账册。"你现在可以告诉她。"

"现在？"

"现在。"李无咎说，"不是所有人都需要主动找到真相，但不是所有人都应该被替做决定。这不是修阵的问题，是修阵之前必须先处理的事——谁有权利要求别人继续活在不知道自己死了的那一天。"

沈闻钟转身走进晨课室。他找到正在分药的顾长穗。顾长穗的双手正把第九十几份药材分到小纸包里，动作精准，分毫不差。她的脸上没有什么表情，只是在做一件做了二十年的工作。

"顾师妹。"沈闻钟叫她。

顾长穗抬起头。她的脸上带着一种安静的了然。不是被说服后产生的情绪，是所有证据都摆在自己面前二十年，只差一个人亲口说出来的那种了然。

"今天的饭不是千粒珠米。"

"我知道。粥里的米粒比千粒珠米硬，咬开之后有一点土腥味，还有根。每年中秋粥里的土腥味都比平时淡一点——因为那天山下的人会更勤奋地祭祀，灵田里的生机反而会回涨半分。"她把药包放在一边，抬头看着他，"沈师兄，我尝了二十年土味的粥，不是因为没有味觉。是因为每天重置一断，我就再也不用尝了。"

她知道。她一直知道。她只是没有找到合适的人说"我知道"。

沈闻钟沉默了很久。他伸手把顾长穗分药的那叠纸包往旁边移了一半。他的动作和每天晨课修正师弟们书页姿势时一样，是习惯性的照顾。但这一次他移开的手停在药包边缘，没有抽回去。"以后我不会再提前重置了。从今天起，谁想知道真相，谁就可以一直留着。"

顾长穗把剩下的药包分完。"好。那我要下山去学二十年后的医术。阮秋禾说山下种了一批新药材，我从来没有见过。"她把药铲搁回药架，铲柄上磨出的手印和二十年前一模一样。但她说出的话已经不属于二十年前的顾长穗。

山门外，阮秋禾接过话头。她一直没有坐，站姿还是扛锄头时的样子，脊背挺得很直。

"我们村里也有隐瞒。老村长八年前拿了归鹤的银锭，回村以后跟全村人说山上有老神仙做法需要借水。第一年他用了'借'字。第二年开始只说是天旱。第三年他死了。死之前把银锭给了我。他没有告诉任何人银子是归鹤给的。他怕村民知道真相之后上山闹事，怕镇邪司追查，怕井水停了但田还没干——他就瞒了。瞒到他死。"

她把银锭放在阿阮的碗边。"这不是替老高洗白。他确实拿了钱，也瞒了村里人。但你们知道那锭银子他用来干什么了吗？"她从布袋里掏出一本村里的小账册，"他每年用这块银子买种子。不是买粮食分给村民——他买新种子，每年试种两行，看哪种种子在缺水的地里还能发芽。他试了八年，试出了三种耐旱的麦种。现在东区麦田里种的就是第三种。如果不是他偷着试，这片麦田在五年前就全死了。"

她翻开老村长的试种记录。每年一行，精细到每天浇水几合、出苗几天、枯苗几株、改种几行。字歪歪扭扭，是挑了一辈子水的手勉强捏笔写的。最后一行停在去年秋天，没有写完——"今天东区试种三行，苗出——"笔画断了，人走了。

"他收了封口钱，也把命给了地。"阮秋禾说，"我不替他开脱，但你们要把账算清楚——他欠的归鹤那锭银子，用八年试种的种子还了。剩下的差额是你们的阵法抽的，不是他偷的。"

郑停云最后一个开口。他把封山令册子翻到被撕掉的那三页，又从怀里抽出第四页，和被裴照夜找回的青州回执放在一起。四页纸拼在一起，才是一份完整的封山记录。

"我的上司不止一个人。当年撕我第一份报告的是青州一位老镇抚。我写报告的时候他已经退休了，但档案室的封册仍旧由他的旧令指认管辖。他在任时安排了对封山令的十年续签，续签用的是归鹤留下的那份旧维护记录，不是新调查。他不知道地脉在下降，但用过归鹤的维护记录就等于承认了阵法还在运作，他知道至少这一点——但他在那份记录上签了字，没去查。"

他停了一下。"第二个上司收了我第二份报告。他看完之后叫我进办公室，说封山令不能拆，拆了会出事。我问他出什么事，他说他也不知道，但二十年前签封山令的几个人，签完之后都死了。他怕下一个是自己。所以他选择了什么都不做。"

"第三个上司撕了我第三份报告，给了我青州回执，回执上写着'已知悉。维持现状'。他没有威胁我，没有处分我，只是让我把这件事忘了。他是在保我——他知道如果这件事捅到更上面，被撕的不止是报告，是我。"

他把四页纸铺在台阶上。被撕的报告、续签令、青州回执、他自己加写的巡查日志。四页拼出一条封山令从有效到失效、从保护到隐瞒的二十年轨迹。

"我不是没有错。我知道封山令已经失效了十年，但我没有主动查。因为我也怕——怕查了之后没有替代方案，只能把封山令解除，让阵里的东西流出来。"他看着程问岳，"我知道阵里面有活的东西。不是妖，是人的记忆。但我不知道他们是不是人。所以我连'不知道'都没有说出口。"

四张笺上的"曾隐瞒"栏全部填满。程问岳的逃亡。沈闻钟的配合重置。老村长的银锭与种子。郑停云的沉默与报告。每一处隐瞒都有真实的恐惧和真实的后果，没有人是纯粹的恶人，也没有人是纯粹的无辜。

李无咎把所有"曾隐瞒"的信息逐条抄到因果链图上。他画了二十三条因果线，每一条都标注了隐瞒者、知道的内容、不知道的内容、隐瞒的原因和造成的具体代价。画完后他把图摊在山门前，让所有人过目。

"从这一刻起，没有新的隐瞒。所有过去隐瞒的事写入公开记录。不是让你们互相原谅，是让你们从此不再被没说的话继续捆绑。"他把毛笔搁在图旁，"接下来你们要面对的是一件事：护山阵必须被改，代价必须重分。改之前每个人都可以选择参与或不参与决策。不参与的，我会把你的名字和理由写在记录里，但不代替你决定。"

没有人离场。

阿洄把陆知秋遗留下的画补完最后一笔——那扇通向山外第二天的大门。秦素娘坐在阮秋禾旁边，两个人都不说话，都在看那只刻了半个"阮"字的碗。程问岳蹲在荒坟名册旁边，用指尖一个个摸那些刻在纸上的名字，像是在重新认识自己逃掉的人。沈闻钟站在晨课室窗外，里面一百四十六个弟子正在上下午第二堂课，但他没有进去。他站在外面听，没有提前重置。

铁算盘翻开因果簿第三十三页最底栏。栏里压着四份差评的受理进度。他拨了一颗青珠标注"隐瞒事项已公示"，又在旁边加拨了一颗透明的珠子。"这颗是预留的。以后有人想起来还有什么没说的，随时来填。"

然后山上的风变大了。不是自然风，是阵法的灵压在波动。倒悬钟楼被归鹤的铜印激活后一直在阵心方向响应，现在响应频率忽然变了。从探测变成了请求——阵法在请求被修正。不是攻击，不是防御，是那种已经运转了二十年没有维护的器物第一次主动发出维修请求。

量灵尺上的金色印记同时发出持续的微光。李无咎低头看向尺身，尺子的刻度线排出了一行字：阵心已定位。封层可解。需要修补者本人确认是否继续。

他按在尺子上的拇指微微用力。印记上的光从他虎口未愈的伤口渗进去，沿着血路走了一圈。他之前流在井底的血已经沿着根须网络进入阵心，在倒悬钟楼的归鹤铜印上留了一个血手印。

不是替归鹤盖印。是他自己签的名。

阵心识别到了新修补者的授权。

铁算盘拨了一颗灰珠——归鹤的。归鹤的账，归鹤的信，归鹤封住的恐惧，归鹤没付够的灵石。然后他又拨了一颗青珠。青珠是李无咎的。

"交接了。"铁算盘说，声音很低，像是怕惊动什么，"不是父子交，是债主交。旧修补者把没修完的阵和新修补者的血都写进了同一本账册。你师傅用这种方式完成了移交——不是教你技术，是把他的名字从担保栏划掉，把你的名字填上去。"

李无咎低头看着量灵尺。尺身上的金色印记比他刚拿到尺子时淡了许多。不是因为归鹤的术力在消散，是他的血在逐步替代归鹤的血。等他完全接管阵心时，金色印记会全部褪掉，换成他自己的青。

"走。"他把尺子插回腰间，"去试第一次修补。不是直接改秘境，是试——能不能在不摧毁旧循环的前提下，让阵内和阵外的时间先同步三息。"

然后所有人都看到了一个在正常情况下不可能出现的画面。

山门外走过一个背着箩筐的采药人。他很老，弯腰弯得很厉害，箩筐里只装着几株半枯的草药。他经过山门时没有往门里看，只是埋头走自己的路。但他在经过第五口井时停了一秒。

然后他弯下腰，把手伸进井口。井里已经干了很久，不可能有水。但他从井壁上摸出了一件东西——一片瓷。和山门台阶上阿阮那只碗一模一样的粗瓷片。他把瓷片翻了面，看了看，又放回原处。然后他抬起头，隔着干涸的井口望了回风山一眼。

他不是在看山。他是在看山上正在和一百四十六个弟子一起念下午功课的阿阮——他已经知道阿阮不在那里了，但他还是往那个方向鞠了一躬。很浅，几乎只是弯了弯腰。然后他走了，箩筐里多了那块只有咸味的瓷片。

程问岳看着那个老人的背影，低声说："阿阮是孤儿。她没有家人。"

"有。"秦素娘站起来了，声音忽然变亮了一点，"她每天早上往山下送饭的邻居老翁，在井边等她送了二十年饭。她不知道老翁还活着。"她从怀里摸出一块旧帕子，帕子里包着一小片风干的咸菜。"这是阿阮最后放在碗底的。老翁收咸菜的时候没舍得吃，一直留着。"

没有人哭。但所有人都在做同一件事——把隐瞒的内容补完之后，开始补死者的信息。一件一件地从遗忘里翻出来。不是替死者还魂，是替活着的人重新认识自己失去了什么。
