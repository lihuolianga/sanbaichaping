# 第203章 土地公把地卖了两遍真正的故障

裴照夜从镇邪司调来的旧档在第三天中午到了。

不是快马送的，是铁算盘用因果簿的跨页传讯功能从青州司直接调取的。旧档一共三卷，皮纸封面，装订麻线已经朽了一半，翻开时需要用铜尺压着纸角，否则整页纸会散开。三卷档案分别标注为“旧天庭地方神制卷第十九，土地登记分契规程”“青州府各镇土地印蜕汇编（残卷）”“地方神权变更录（辛卯年补录）”。

第十九卷分契规程是核心。规程第一条写得清清楚楚：“土地神印分上下契，上契录地表、日照、水渠、耕作；下契录深度、时辰、灯柱、阴火。上下契同印不同契，各生效于所录层面，互不覆盖。”第四条：“土地神须每年校准一次深度标尺，若上下间距变化逾三尺，须召集上下契持有人重新议约，并在天庭地册作分录变更。”

规程是完整的。问题不在规程本身，在规程的维护。第七条规定：“地方神制每年由本境土地司派巡视神差复核分契登记。连续三年未获复核者，上报天庭地政司裁定。”第十九卷末页附了一份复核记录，从戊寅年到庚寅年，十三年间，土地司的巡视神差一个都没来过双契原。庚寅年之后，连复核记录本身都断了，不是没人来，是土地司没了。

“旧天庭地方神制在庚寅年裁撤了地方土地司。”裴照夜把旧档翻到裁撤令那页。裁撤令是一份泛黄的铜箔，铜箔上只有一行字，“地方神制原地解散，神职留任候命。天庭地政司不再派员复核。”落款日期：庚寅年十二月三十。除夕。“梁守壤的信是二十七年前发的。二十七年前是戊寅年。他等了十二年没有回音，等到的是天庭裁撤了整个地方神制。”

十二年间，他一个人守着两块地，等不来一个神差。裁撤令到的时候，他大概连一个可以交信的人都没有了。

青州府土地印蜕汇编是残卷。残卷中保留了双契原土地神印的原始印样。印样显示这枚方印由三部分构成：印框、上印纹、下印纹。印框是固定边界，上印纹登记地表权利，下印纹登记地下权利。印泥的成分也不同，上层印泥掺了阳砂，下层印泥掺了阴土粉。盖一枚印，用两种印泥，印出的两张契各自的印色深浅、洇散程度和神力残留波形都是不同的。

裴照夜把赵家地契和墓民地契的印章与印样进行比对，结果完全吻合。赵家地契用的是上印纹，印泥含阳砂，印色偏浅，神力波形集中在地表一层。墓民地契用的是下印纹，印泥含阴土粉，印色偏深，神力波形集中在地下深层。两张地契的印章从来就不是同一层印纹。把它们放在一起比，就好比拿同一扇门的正面和反面说“这扇门只有一面”，门本来就有两面。

地方神权变更录记载的是辛卯年的事。辛卯年，归鹤真人途经双契原，在土地庙的香炉底压了一枚铜钱。变更录上记了这枚铜钱的信息：“辛卯年，无名道人于双契原土地庙压铜钱一枚，铜钱上留有对土地神的私下劝诫。劝诫原文录于后。”原文是归鹤留的那句话，“你托得住地，托不住所有人的决定。”旁边还有一行更小的字，是归鹤走后梁守壤自己添上去的：“他问我，如果公开沙漏，两边都不肯搬，你打算怎么办。我说我继续托。他问我托到什么时候。我说托到我裂成两半的时候。”

他果然裂成了两半。

这些信息组合在一起，案件的完整机制浮出水面。

李无咎没有坐在屋里宣布真相。他让赵谷生帮他在祠堂后院搭了一个半人高的木架，木架上铺了两张大白布。白布是闻灯娘从灯市商会库房里取出来的，用来画灯市地图的素布。布是白的，但布面残留着阴火的淡蓝色熏染，染得不均匀，有的地方蓝，有的地方白，像一张半透明的双层地图。

他在白布上画了七层因果图。

第一层：天庭地方神制正常运转期（戊寅年以前）。双契原采用上下分契制度。地表赵家持有上契，耕作灵田。地底墓民持有下契，经营灯市。上下相距十四丈，地脉稳定，互不干扰。土地神梁守壤每年校准深度标尺，登记在案，天庭地政司存档。系统完整运转。

第二层：求援无门期（戊寅年至庚寅年）。梁守壤发现地脉异常沉降，上报本境土地司。十二年间无一神差回复。沉降从十四丈缩至九丈。梁守壤开始用自身神力填补地脉裂口。他没有告知赵家和墓民，因为他认为自己还能撑住，说了只会引起恐慌。

第三层：旧制崩溃期（庚寅年除夕）。天庭裁撤地方神制，不再派员复核。梁守壤从此失去所有上级通道。他的印章仍在，但印章背后已经没有制度和力量支撑。他继续用神力垫在地下，阻止两层空间进一步坍缩。神像出现第一条裂缝。

第四层：地脉持续坍缩期（庚寅年至甲午年）。距离从九丈缩至七丈五。梁守壤继续隐瞒。赵元圭发现地下有灯火，但在问明土地神未回应后，选择自行向下打聚灵桩井。梁守壤默许了，因为他怕一旦阻止赵家，赵家会发现真相并要求废掉墓民地契。

第五层：灯市扩张期（辛丑年）。距离缩至四丈。闻灯娘发现灯市上层不断接近地表，选择往上加盖仓库，作为实物占地证据。梁守壤同样默许了，因为他怕一旦阻止商会，墓民会发现真相并要求废掉赵家地契。他的默许不是支持扩张，是两边都不敢得罪。他以为默许是维持和平，实际上默许让两边把扩张当成了合法。

第六层：空间急速坍缩期（壬寅年至今）。距离从四丈缩至一丈。地表灵田和地下灯市开始日常重叠。赵家继续向下打井，灯市继续向上建仓。梁守壤神力耗尽，神像从额头裂至基座。他藏在神像中的地脉沙漏因裂缝而暴露。他仍然没有主动公开，直到沙漏自行脱落。

第七层：自动条款激活（现在）。两张地契因长期未校准而在空间坍缩后同时执行“占地者逐出”，将所有未与土地神签订分契协议的居民标记为占地者。两张合法地契变成了互相排斥的武器。而这个局面不是任何一个人单方面造成的，是旧制度失去维护后，土地神、赵氏族长、墓民会首三个人各自的选择在二十七年里叠加累积的结果。

画完七层，白布还剩一角空白。李无咎在空白处画了一个井。井口朝上，井底朝下。井壁上画了两个小小的人影，一个人影在井口往下看，一个人影在井底往上看。两人的手各伸了一半，指尖之间隔着一掌宽的距离。他在这段距离中标了一圈虚线，虚线旁写了一个字：“共”。

他把白布揭起来，钉在祠堂的照壁上。白布被日光从背后照着，布上的阴火蓝斑在逆光中变成了透明的，蓝的变成通透的白，白的变成浅浅的金。七层因果在逆光中像七层叠在一起的玻璃，谁都能站在布前，透过第一层看见最后一层。

赵家农户和墓民站在照壁前看这张图。有人看懂了，有人只看懂了一半，有人只看到第七层那个井中小人。赵余氏指着井壁上的小人说，“那是谷生和石七”。赵谷生站在旁边，没说话，他看的是第三层那个日期，庚寅年除夕。那天正是他出生那年。他问了一句，“我落地那年，天庭就不管这块地了？”没人能回答他。裴照夜说，“管不了了。”不是敷衍，是真的管不了了。裁撤令是全域的，不止双契原一个地方。

闻灯娘看到第四层时停顿了很久。甲午年，赵家开始打井，梁守壤写在沙漏上的评语是“默许”。第五层辛丑年，灯市加盖仓库，评语还是“默许”。她说，“他把我们都默许了。默许他怕的人做他怕的事。最后他怕的事全发生了，发生的原因就是他默许了。”赵元圭在旁边站着，看的是第四层自己的名字。赵元圭，甲午年，发现地下灯火。知情后，命族人打聚灵桩井。他看了很久，把名字下那行字看了三遍，然后走开了。

三种方案，李无咎没有写在布上。他口述，铁算盘在因果簿上刻录。

第一套：强制废除一张地契。

做法是让裴照夜以镇邪司名义确认其中一张的效力，废掉另一张。废契的一方全部迁出双契原。最快，管理最简单，只保留一个权利体系。代价也很清楚：三十七户墓民或六十三户赵家农户中的一半以上将失去家园因果。失去家园因果的人会遭受空间排斥，身体可能逐渐透明或石化，严重者会失去方向感、记忆和姓名。迁出后需重新安置土地，但双契原附近没有适合墓民的阴土也没有适合赵家的同类灵田。代价预估：至少十二人死亡，四十人以上长期漂泊。

宣读这套方案时，所有人都沉默了。没有人敢答应，也没有人敢反对。因为每个人都可能在沉默中被变成代价。

第二套：强行恢复原有双层空间。

按第一次修补的方向继续推进，但主动切断共享水脉、通风口和道路。表面上最接近恢复原状，两张地契继续完整有效。代价是已被证明存在的：共享水脉断开后赵家至少三口井枯竭，灯市底层暗河改道。更严重的是，共享承重地层一旦被切断，赵家东田和灯市南街会同时坍塌。坍塌范围内有赵来福家、石老四家和另外六户边缘住户。此外，后续维护需要一个人持续垫在中间承担反冲。这个人之前是梁守壤，二十七年耗尽神力。换一个人，不管换谁，都是在重复土地神的错误：一个人撑住所有人。代价预估：边缘区域大面积坍塌，后续维护者寿命折损。

“这套不行。”赵来福站起来说，他站在自己的枯田里，脚底下还踩着枯穗灰。“已经塌了一次，不能再塌。”

第三套：时段与深度分区。

不追求完全恢复旧状。划定永久地表区（赵氏灵田核心区共二十八亩），划定永久地下区（灯市主街及住宅区共二十一间铺面及附属巷道），设置共同水脉、通风井和昼夜转换通道。对正在重叠的过渡区实行分时使用：白日归赵家耕作，夜间归灯市通行。双方放弃已扩张的区域：赵家放弃三口深井和东侧六亩灵田，墓民放弃上层仓库、部分接近地表的灯铺和一段向赵家祖坟扩张的通道。修复核心地脉，不是靠神力硬托，是注入双方共同供应的灵气进行周期性的维护。地脉沙漏不藏，任何一方都可查看。重新订立有期限、可复议的临时协议，第一次复议日期定在一年后秋分。

代价：两方都无法保留全部现有土地。赵家损失约四分之一的灵田和全部深井，墓民损失上层约三成的建筑面积。部分农田、商铺和祖产须永久放弃。双方需要长期共同维护通风井和水脉，冲突不会因为结案立刻消失。任何一方的不满都可以在复议时提出。铁算盘按目前面积和人口核算：赵家损失灵田共九亩八分，三口水井全废，受影响二十二户。墓民损失铺面七间，仓库一间，通道两条，受影响十四户。合计三十六户须重新安置或调整生计。

石七听完第三套，举手了。

“我可以让出我家上层铺子。那间铺子之前被赵家井管捅穿了两次，修了两次。修是能修，但我妹妹每次都在那间铺子里睡。她今年十一岁，三年里被吓醒了四回。我家不要那间铺子了。换灯市公共通风井，正对着赵家水渠的出口。我愿意。”

石小妹从人群里钻出来，站在石七旁边。她手里捏着她自己缝的那个只有“小妹”两个字的名字牌。她说，“那间铺子我不要了，但我缝的名字能挂在通风井上吗？通风井我不怕，井是上下通的，不是堵的。”

赵谷生也举手了。

“我家东侧那三亩灵田放弃了。不打井了，也不用灵田了。把这块地改成上下共用的通道区。白天赵家能走，夜里灯市能走。赵家的牛不能踩灯市的灯柱，灯市的灯油不能倒进赵家的水渠。两样都不许，就是路。”

赵元圭看着他。没有阻止，也没有赞成。他只是站在枯田灰里，把那本削了土地神供奉的香火账从怀里摸出来，翻到最后一页，把自己五年前写的那句“不必再奉”用指头抹掉。墨迹已经干透了，抹不掉，他把纸撕下来，撕碎了，碎纸落在枯穗灰里混在了一起。

闻灯娘把商会的仓库钥匙取下来，放在神像左半前的石台上。她没有说放弃，她只是把钥匙放下了。

梁守壤没有现身。但他的木盒里那只空的神库账本最后一页原本写着“神库里没钱不丢人”，此刻那行字下面又多了一行。不是他自己写的，是铁算盘的因果簿在他的账本上自动追加了一个条目：

“己巳年七月，李无咎携赵氏农户与墓民商会在双契原祠堂照壁前公开七层因果图。双方首领未再隐瞒。分摊方案已提，梁守壤知情权负债项：二十七年间剥夺双方对地脉坍缩的知情权。债未偿，但账已开。”

三套方案放在照壁前。满院站满了人，没有人走。赵余氏站起来，走到照壁前，指着第三套方案那个“共同水井”的位置，说她的石凳能不能放在井边上。她说，“我老了，不种田。田分出去就分出去。但是井边上给我放一把椅子，我白天坐那儿，夜里还在那儿。管他是田还是灯市，我都能坐着。”

宁知微在石凳的位置画了一个小圆圈。圆圈下标了一行极小的字：“赵余氏，自愿放弃个人名分田，迁移至共同水井旁。保留石凳一把，昼夜不分。”

铁算盘把她这一个圆圈折算成了第三套方案中赵家放弃面积中的千分之三。千分之三不大，但每一分都是自愿的。

天快黑了。

李无咎在照壁前宣布：“下一步不是斗法，是公开选择。三套方案都列在这张布上，天擦黑之前，每个人都看一遍。明天开始，想选哪套的人到神像前按手印。选第一套的人站左边，选第二套的人站中间，选第三套的人站右边。弃权的，不勉强。但弃权等于把决定权交给选了的人。你们自己掂量。”

赵元圭当场表示：“赵家不会放弃一寸祖田。”他说这话的时候声音没有之前硬了，但仍然不肯松口。闻灯娘也表了态：“墓民不会向地上人再退一步。”她说这话的时候钥匙已经放下了。

两人说完背对背站着，谁也不看谁。但他们中间那块曾经隔开两方的墨斗线不知什么时候被风吹歪了，歪成了弧线。弧线两端还是赵家和灯市，但中间那段弧弯下来，把赵来福的枯田和石老四的破铺子圈在了同一个半圆里。
