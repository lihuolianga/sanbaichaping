# 第979章 未来残影与执页先动手

第一次修补失败后，未来残影与执页抢先动手了。它们控制自行增长的差评，以维持秩序为名，扩大了故障。

"李先生！"一个未来受害者跑进来，脸色惨白："李先生，差评记录——差评记录，被夺了！像是——像是未来残影和执页，夺了差评记录！像是——像是它们，要控制差评记录！"

"差评记录被夺？"李无咎冲到未来废观中心。中心——未来残影和执页，正控制着差评记录。像是……像是它们，要控制差评记录。像是……像是它们，要以维持秩序为名，扩大故障。

"李先生！"宁知微赶到，"未来残影和执页控制差评记录——像是……像是它们，要控制差评记录。像是……像是它们，要以维持秩序为名，扩大故障。像是……像是它们，不让差评被公开。"

"李先生！"未来废观外，又传来喊声。一个未来受害者跑进来，脸色惨白："李先生，差评记录——差评记录，具象成执念了！像是——像是执念，把活人拖入未来旧事了！像是——像是他们，快撑不住了！"

"差评具象成执念？"李无咎冲到未来废观外。远处——几个活人，正被差评执念拖入未来旧事。像是……像是他们，快撑不住了。

"李先生！"裴照夜冲进来，"末将核了权限变更——未来残影和执页，变更了差评记录的权限。像是……像是它们，把权限，收到了自己手里。像是……像是它们，要独自控制差评记录。"

"它们收权？"李无咎说，"那这套差评——"

"像是……"裴照夜说，"像是这套差评，被它们独占了。像是……像是它们，把权限收到自己手里——它们想控制差评记录。像是……像是它们，不允许差评，被公开。"

"李先生！"未来废观里，又传来喊声。一个未来受害者跑进来，脸色惨白："李先生，协商时间——协商时间，被压缩了！像是——像是未来命令，压缩了协商时间！像是——像是它们，要尽快恢复预警！"

"协商时间被压？"李无咎说，"它们要尽快恢复预警？"

"像是。"未来受害者说，"未来残影和执页说——预警不能断。像是……像是它们，把协商时间，压成半天。像是……像是它们，要在这半天里，恢复预警。像是……像是它们，不给活人，自己选择的时间。"

"李先生！"宁知微说，"它们压缩协商时间——像是……像是它们，不给活人自己选择的时间。像是……像是它们，要恢复预警。像是……像是可恢复预警，就是继续标记活人。像是……像是它们，在替活人，决定未来。"

"李先生！"裴照夜说，"末将建议——先保全责任证据。差评记录、反对者名单、未来页——这些，都是责任证据。末将把它们，锁进废观的密库。"

"锁进密库？"李无咎说，"那密库——"

"密库，是废观最安全的地方。"裴照夜说，"末将把证据锁进去——它们，抢不走。"

"好。"李无咎说，"你保全证据——我去救人。"

第一步，救眼前的人。

李无咎冲到未来废观的差评阵前。未来残影和执页，正指挥差评执念拖活人。李无咎拦住执念："住手！拖活人进未来旧事——就是替他们决定未来！"

"李先生！"执页白衣的声音响起来，"拖活人进未来旧事——是维持秩序！李先生，你查了这么久——查不出结果。天律书决定——恢复预警！李先生，你让开——"

"我不让。"李无咎说，"恢复预警——就是继续标记活人。我不让——我不能让活人，继续被预警，被标记。"

"李先生！"未来废观里，又传来喊声。一个未来受害者跑进来，脸色惨白："李先生，差评记录——差评记录，被它们收进执念了！像是——像是它们，要把差评，炼成执念！像是——像是它们，要替所有活人，写定未来！"

"炼差评成执念？"李无咎冲到执念前。执念下——差评记录，正被收进去。像是……像是它们，要把差评，炼成执念。像是……像是它们，要替所有活人，写定未来。

"李先生！"裴照夜说，"它们在炼差评成执念——像是……像是它们，要替所有活人写定未来。像是……像是它们，不给活人自己选择的机会。像是……像是这套预警，还在继续。"

"李先生！"宁知微赶到，"它们在炼差评成执念——像是……像是它们，不给活人自己选择的机会。像是……像是它们要恢复预警——像是……像是可恢复预警，就是继续标记活人。像是……像是它们，在替活人，决定未来。"

"李先生！"未来废观里，又传来喊声。一个未来受害者跑进来，脸色惨白："李先生，一个活人——一个活人，被差评执念拖入未来旧事了！像是——像是他的选择，被压缩了！像是——像是他，快撑不住了！"

"活人被拖入未来旧事？"李无咎冲到那个活人面前。活人——脸色惨白。像是……像是他的选择，被压缩了。像是……像是他，快撑不住了。

"李先生！"宁知微蹲下看了看，"活人被拖入未来旧事——像是……像是差评执念，拖了活人。像是……像是活人，失去了自己的选择。像是……像是活人，快撑不住了。"

"李先生！"裴照夜说，"末将还在权限记录里，发现了一样东西——归鹤同源的术式。像是……像是未来残影和执页，用过归鹤的术式。像是……像是这套收权，用了归鹤的术式。"

"归鹤的术式？"李无咎说，"那归鹤——"

"像是……"裴照夜说，"像是这套收权，用了归鹤的术式。像是……像是归鹤的术式，被人拿来做过收权。像是……像是归鹤，可能不知情；像是……像是也可能，知情。像是……像是这段同源，不能定归鹤的罪——也不能洗白归鹤。"

"你说得对。"李无咎说，"术式同源，只能说明——归鹤的术式，被用过。被谁用，为什么用——还要查。归鹤，不能因同源定罪，也不能因'他是我师父'洗白。"

"李先生！"宁知微说，"末将还在救援现场，标了标记。像是……像是每个被救的活人，身上都有救援标记。像是……像是标记，是末将留的——可追踪，可核验。像是……像是这套救援，是有记录的。"

"救援有记录？"李无咎说，"那这些标记——"

"像是……"宁知微说，"像是这些标记，是救援的记录。像是……像是谁被救过，谁被拖过——都有标记。像是……像是这套标记，是救援的账。像是……像是账在——被救的活人，就不会被忘记。"

"李先生！"未来废观里，又传来喊声。一个未来受害者跑进来，脸色惨白："李先生，它们——它们，启动了最终节点！它们说——它们说，未来李无咎的善意独裁，将被强制写入当前！"

"最终节点？"李无咎冲到未来废观中心。中心——一道强光，正亮起。像是……像是它们，启动了最终节点。像是……像是未来李无咎的善意独裁，将被强制写入当前。

"李先生！"未来残影李无咎说，"最终节点启动——未来的我的善意独裁，将被强制写入当前。像是……像是它们，要替当前人，决定未来。像是……像是我们，只剩半天了。"

"只剩半天？"李无咎说，"那这半天——"

"李先生！"裴照夜说，"末将已保全了一部分证据——反对者名单、未来页、查看记录，已锁进密库。像是……像是末将，保住了大部分证据——可差评记录，还在执念里。"

"李先生！"未来废观里，又传来喊声。一个未来受害者跑进来，脸色惨白："李先生，一个活人——他，被差评执念拖入未来旧事了！像是——像是他的魂，被打散了！像是——像是他，死了！"

"活人死了？"李无咎冲到未来废观外。一个活人——魂体，正在消散。像是……像是他被差评执念拖入未来旧事了。像是……像是他的魂，被打散了。

"李先生！"宁知微蹲下看了看，"魂被打散——像是……像是他，死了。像是……像是差评执念，杀了他。像是……像是我们若先保全证据——眼前的人，就会死。像是……像是我们若只救人——幕后者，就会脱责。"

"两边都要做。"李无咎说，"裴照夜保全证据——我救人。不能因为保全证据——就让眼前的人死；也不能因为救人——就让幕后者脱责。两边，都要做。"

"李先生！"未来废观里，又传来喊声。一个未来受害者跑进来，脸色惨白："李先生，最终节点——最终节点，还在亮！像是——像是它，要在半天内，写入善意独裁！像是——像是半天一到——未来李无咎的善意独裁，就被写入当前了！"

"半天一到，善意独裁写入？"李无咎说，"那这半天——"

"李先生！"宁知微说，"这半天，我们要做三件事——救人，保全证据，查真相。三件事，都不能放。像是……像是它们，想用写入善意独裁，盖住真相——我们不能让它得逞。"

风从未来废观上吹过来。密库里，反对者名单锁着，未来页锁着，查看记录锁着。未来废观上，最终节点亮着，魂被打散着，未来李无咎的善意独裁等着被写入当前。像是这座未来废观，正被一场"写入善意独裁"逼到绝境——而李无咎，正带着救人和保全证据两条线，冲向那半天。
