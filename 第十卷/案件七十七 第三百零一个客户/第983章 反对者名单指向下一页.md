# 第983章 反对者名单指向下一页

三日后，未发生太平观废墟的善后，落了地。李无咎把最后的手尾，一件一件，做完。

第一步，是安置。

未归签了申诉——他申诉了自己的标记，补签了选择，退出了预警。未来残影李无咎——被安置在未来证物与复议站，作为未来的见证者。

"未归愿意申诉，未来残影愿意留下。"李无咎看着安置表，"他们不是被逼的——是自己选的。未归选了申诉，因为他要重新评价自己的选择；未来残影选了留下，因为他要见证未来。两个人，两种选择——都是真的。"

"李先生！"一个活人走上来说，"小人的选择，被压缩了。小人的赔付——什么时候到？"

"在核了。"宁知微说，"被压缩的选择，由天律书先垫，再由天庭追偿。选择，不能完全恢复——可赔付，会先落地。你先拿着这笔银子，安个家。"

"小人的选择——"活人问，"还能回来吗？"

"不能。"李无咎说，"被压缩的选择，不能完全恢复。可你的选择，会重新评价——你的压缩，会记在查看记录上。这笔账，记在预警的账上——不会抹掉。"

第二步，是维护培训。

裴照夜在未来废观里，开了一堂未来页维护课。愿意留下的活人、愿意轮换的仙人、愿意培训的凡人——坐满了一屋。

"未来页维护，不是预警。"裴照夜站在讲台上，"是登记。每次查看未来页，都要登记查看人、查看原因、查看次数。每次解释，都要质疑、复议。每次据未来行动，都要经授权、可停止。未来页维护，是制衡——不是预警。"

"李先生！"一个活人问，"小人查看未来页——会推动未来吗？"

"会。"李无咎说，"每次查看未来，都会增加它发生的可能性。你查看——你要知道，你在推动未来。可你不查看——你又要错过真实预警。所以，查看要登记，解释要质疑，行动要授权。未来页维护——是让你在查看中，保持制衡。"

第三步，是三次回访。

第十日，李无咎回到未来废观，看未归。未归补签了自己的选择——他申诉了标记，重新评价了自己的选择。

"未归，"李无咎问，"还梦见被标记吗？"

"梦见。"未归说，"小人梦见——小人被新天帝印标记。小人醒来——小人就看自己的印记。小人看着印记——小人的选择，是重新选的。小人……小人不再是服从对象了。小人……小人自由了。"

"你自由了。"李无咎说，"你的选择，是你自己选的。你不再被标记——你，是未归。"

第二十日，李无咎去看未来残影李无咎。未来残影站在未来证物与复议站里——他，是未来的见证者。

"未来的我，"李无咎问，"你还怕吗？"

"怕。"未来残影李无咎说，"我怕——未来的我，会成为善意独裁者。可我现在——我看到了反对者名单。宁知微反对我，裴照夜反对我——他们反对了。我看到了——这份反对，是制衡。我……我不再是一个人做决定了。"

"你看到了反对。"李无咎说，"你看到了反对者名单——你知道了，有人会反对你。这个看到——就是制衡。未来的你，没有这个看到——所以他成了善意独裁者。你，有这个看到——你可以，不成为他。"

第三十日，李无咎最后一次回到未来废观。废观里，未来页挂在厅里，反对者名单立在厅外，查看与复议记录贴在墙上。宁知微、裴照夜——他们的否决记录，公开挂着。

"李先生！"一个穿锦袍的仙官，站在牌匾前，"本官是天庭名声司的。李先生，这未来废观里，挂了这么多负面记录——预警的记录、标记的记录、善意独裁的旧事。天庭名声司的意思——这些记录，能不能撤了？撤了，天庭的面子好看些。"

"撤了？"李无咎说，"撤了——账就断了。撤了——未来的独裁，还会重复。名声司的仙官，你要面子——可面子，不能盖住账。这面负面记录墙，不能撤。"

"那——"仙官说，"至少，撤一半？把'善意独裁'那几行，改一改？"

"改账？"宁知微走到墙前，"改了——善意独裁就不存在了？改了——标记就不存在了？改了——未来李无咎的灾难，就不存在了？名声司的仙官，账可以难看，但不能假。这面墙，一个字，都不改。"

"李先生！"仙官的脸色变了变，"你不改——天庭名声司，就要追究——"

"追究就追究。"李无咎说，"未来页，是公开的；反对者名单，是公开的；查看与复议记录，是公开的。该做的，做完了。名声司要追究——追的，就是'账太难看'。可账难看，是因为账是假的——假账才难看。真账，难看也留着。"

仙官沉默了，退了出去。

"李先生！"宁知微走到他身边，"本案的差评，因果簿上，闭合了几条？"

李无咎翻开因果簿。珠面上，浮着几行字——都打了勾。他数了数："四条。因果簿出现不存在的客户，投诉人写着未来的李无咎；敌人伪造未来，用假记录冒充未来的李无咎；未来李无咎成了新天帝，替众人决定；查看未来，推动未来自证。四条差评——都闭合了。"

"四条差评闭合，"宁知微说，"可账——还没完。天律书的预警，追了一部分，还有一部分，在天庭；未来页的制衡，核了一部分，还有一部分，在等待复议。负面记录墙上的账，没有抹掉——它会一直挂着。"

"是。"李无咎说，"未来页保留为制衡证据了，反对者名单公开了，查看与复议机制建立了。可保留，不是结案——每次查看未来，都会推动其发生。未来残影造成的灾难、被预警改变的选择、当前行动留下的心理和制度压力——不能完全撤销。我可能成为善意独裁者——这个风险，将贯穿后续。"

"李先生！"宁知微说，"李无咎开始害怕自己——这个怕，会长期存在。像是……像是他，把这种恐惧，转化成可验证的制度约束。像是……像是他，允许宁知微、裴照夜和其他人，留下反对、否决与复议。像是……像是这条线，还没完。"

"是。"李无咎说，"我害怕自己——而非只怕师父。这个怕，是我的制衡。我不能用'我绝不会'代替制度——我要让团队制衡我。宁知微，裴照夜——你们，有否决权。未来的我替众人决定——你们，要反对。你们，必须反对。"

"李先生！"铁算盘的声音响起来，"因果簿——因果簿上，翻出了新画像！"

"新画像？"李无咎看向因果簿。珠面上，旧的画像散去，浮出新的画像——一座旧天庭，埋在宗门地下。画像下面，浮着一行小字："宗门地下，差评：旧天庭，埋在宗门地下。像是……像是旧天庭，埋在宗门的下面。"

"旧天庭埋在宗门地下？"宁知微说，"像是……像是旧天庭，埋在宗门的下面？"

"旧天庭埋在宗门地下？"李无咎说，"这桩案——和反对者名单，有关？"

"像是。"铁算盘说，"反对者名单的因果——和宗门地下，连着。像是……像是旧天庭，埋在宗门地下。像是……像是这份名单，指向下一页。"

"反对者名单指向下一页？"李无咎说，"那下一页——"

"李先生！"未来废观外，又传来喊声。一个活人跑进来，脸色惨白："李先生，宗门——宗门送来一卷文书！像是——像是文书上，写着——旧天庭，埋在宗门地下！像是——像是那个旧天庭，埋在宗门的下面！"

"宗门送来文书？"李无咎接过那卷文书。文书上——写着，旧天庭，埋在宗门地下。像是……像是那个旧天庭，埋在宗门的下面。

"李先生！"宁知微说，"旧天庭埋在宗门地下——像是……像是这桩案，和反对者名单有关。像是……像是这份文书，是下一案的引子。"

李无咎看着那卷文书。文书上，写着——旧天庭，埋在宗门地下。他看了一会儿，把文书，放在反对者名单下。

"李先生！"未来废观外，又传来喊声。一个活人跑进来，脸色惨白："李先生，宗门地下——一个凡人，抱着一卷文书，倒在废观外！他说——他说，他是从宗门地下那边来的！他说——那边，旧天庭，埋在宗门地下！"

"宗门地下那边的人来了？"李无咎走到未来废观外。一个凡人，抱着一卷文书，倒在废观外。文书上——浮着一道裂痕。像是……像是这卷文书，从宗门地下那边，一路带到这边。

"李先生！"宁知微说，"旧天庭——从宗门地下那边来。像是……像是这桩'旧天庭埋在宗门地下'——和反对者名单，是同一根藤上的果。像是……像是这卷文书，是下一案的引子。"

李无咎接过那卷文书。文书上——浮着一道裂痕。像是……像是这道裂痕，是旧天庭的痕迹。他看了一会儿，把文书，放在反对者名单下。

"李先生！"那个凡人，虚弱地说，"小人……小人只记得——旧天庭，埋在宗门地下。像是……像是那个旧天庭，埋在宗门的下面。像是……像是小人，从宗门地下那边，一路逃出来。"

"旧天庭埋在宗门地下？"李无咎说，"那宗门地下——"

"不知道。"凡人说，"小人只知道——旧天庭，埋在宗门地下。像是……像是那个旧天庭，埋在宗门的下面。像是……像是小人，从宗门地下那边，一路逃出来。像是……像是小人，追不上那个旧天庭。"

风从未来废观上吹过来。未来证物与复议站的牌匾挂着，反对者名单立着，旧天庭的文书躺着。像是这卷文书，正从宗门地下那边，带来一场新的"旧天庭"——正等着下一案，去查那个埋在宗门地下的旧天庭。
