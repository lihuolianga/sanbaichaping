# 第1013章 责任不再落给无辜者

三个方案摆在证物场上，老官沉默了，追兵沉默了。李无咎没有替任何人拍板——他把方案，交给了在场的每一个人。

"三个方案——拒绝选真师父、共同承担、暂不合一。"他说，"谁来选？你们选。可有一句话，我要先说：选了，就有代价。选了拒绝选真师父，两位归鹤要共同承担；选了暂不合一，人格要长期隔离。你们看见了代价，再选——选完，不许反悔，不许把代价，推给没来选的人。"

第一步，是拒绝选真师父。

宁知微把两只旧酒葫芦，摆到证物场正中的高台上。她又把互补记忆、相反方案，一并挂在高台四周。

"诸位，"她站在高台下，"我们不选真师父。两位归鹤——都是真实分身。他们各做过决定——各隐瞒，各救助，各牺牲。他们，必须分别对各自做过的决定、隐瞒、救助、牺牲与后果承担责任。所有证物和评价——同时保留。"

"李先生！"一个受害者喊起来，"不选真师父——那谁是真身？"

"两个都是真身。"李无咎说，"两位归鹤，都是归鹤在重大选择中切出的真实分身。我们不选真师父——因为选真师父，会删除另一半责任。两位归鹤，必须分别承担责任。"

第二步，是共同承担。

裴照夜在证物场一角，展开双责任书。责任书上——两位归鹤的名字，各签一份。

"这是双责任书。"裴照夜说，"两位归鹤，各签一份责任书。像是……像是归鹤甲，承担伐天的责任；像是……像是归鹤乙，承担维序的责任。像是……像是这套责任，要分开记。像是……像是这套责任，不能被合并。"

"李先生！"归鹤甲走上前，签下责任书。"我认——我主张伐天——我承担伐天的责任。像是……像是我认——我的责任。"

"李先生！"归鹤乙也走上前，签下责任书。"我认——我维持秩序——我承担维序的责任。像是……像是我认——我的责任。"

"两位师父都签了责任书。"李无咎说，"他们分别承担自己的责任。这套责任——不能被合并，不能被推掉。他们，都要认。"

第三步，是权限拆分。

宁知微在证物场另一角，铺开权限拆分令。令上写着：两位归鹤的权限，要拆分。师徒三方契，要拆权审计。容器图，要受控。

"这是权限拆分令。"宁知微说，"两位归鹤的权限，要拆分。像是……像是师徒三方契，要拆权审计。像是……像是容器图，要受控。像是……像是这套拆分，是防独裁的。像是……像是没有一个人，能独占全部权限。"

"李先生！"裴照夜说，"末将还建立了双证据库——两位归鹤的证词，各存一份。像是……像是这套双存，是防删除的。像是……像是每位归鹤的证据，都要保留。像是……像是这套双存，是防偏袒的。"

"李先生！"李无咎说，"权限拆分——双证据库。两位归鹤，各存一份证据。这套拆分——是防独裁的。这套双存——是防偏袒的。两位归鹤的责任——不能被合并，不能被删除。"

第四步，是暂不合一与可复核隔离。

"李先生！"宁知微说，"两位归鹤——暂不合一。像是……像是他们，要隔离。像是……像是可这套隔离，是可复核的。像是……像是三十日、三个月、一年——要回访。像是……像是核验人格稳定、命令外溢、赔付、权限和是否仍保持自愿。"

"暂不合一？"李无咎说，"那这套隔离——"

"像是……"宁知微说，"像是暂不合一——不是永久搁置。像是……像是这套隔离，是可复核的。像是……像是每次回访——核验人格稳定、命令外溢、赔付、权限和是否仍保持自愿。像是……像是这套复核，是长期的。"

"李先生！"李无咎说，"暂不合一——不是永久搁置。要设置三十日、三个月、一年回访。核验人格稳定、命令外溢、赔付、权限和是否仍保持自愿。这套复核——是长期的。"

"李先生！"证物场外，又传来喊声。一个追兵跑进来，脸色惨白："李先生，破坏者——破坏者，试图趁权限拆分，抢夺三方契！像是——像是他们，要抢三方契！像是——像是他们，不让权限拆分！"

"破坏者抢三方契？"李无咎说，"那三方契——"

"像是……"裴照夜说，"像是破坏者，试图趁权限拆分，抢夺三方契。像是……像是三方契，要被保护。像是……像是这套拆分，不能被破坏。"

"李先生！"证物场外，又传来喊声。一个追兵跑进来，脸色惨白："李先生，两位归鹤——两位归鹤，都想替李无咎做最后一次决定！归鹤甲说——他说，他要替李无咎，决定伐天！归鹤乙说——他说，他要替李无咎，决定维序！"

"两位师父都要替我决定？"李无咎说，"那我——"

"像是……"宁知微说，"像是两位归鹤，都想替李无咎做最后一次决定。像是……像是他们，想替李无咎决定。像是……像是可李无咎，要自己决定。像是……像是这套替人决定，是独裁的。"

"李先生！"李无咎走到两位归鹤面前，"两位师父——我不让你们替我决定。我承认——我深受你们影响。我承认——我被选为因果容器。可我——拒绝被'容器用途'定义。我——保留自己重新选择身份的权利。"

"李先生！"归鹤甲说，"李先生，我替你决定伐天——是为你好。"

"李先生！"归鹤乙说，"李先生，我替你决定维序——也是为你好。"

"两位师父都为我好？"李无咎说，"可'为你好'——不能替我决定。我承认我受你们影响——我承认我是因果容器。可我拒绝被定义——我保留重新选择身份的权利。我，要自己决定。"

"李先生！"宁知微说，"李无咎承认受师父影响——却拒绝被定义。像是……像是他，拒绝被'因果容器'、'继承者'、'伐天工具'定义。像是……像是他不通过选择慈悲版师父来逃避极端版师父留下的责任。像是……像是他，保留自己重新选择身份的权利。"

"李先生！"宁知微又说，"受害者——要分别评价两位归鹤。像是……像是有些受害者，被归鹤甲救过——他们认可归鹤甲；像是……像是另一些受害者，被归鹤乙害过——他们指责归鹤乙。像是……像是这套评价，不能被李无咎统一代言或统一原谅。像是……像是这套评价，要分别保留。"

"李先生！"李无咎说，"受害者的评价——分别保留。两位归鹤，各有受害者——受害者，要分别评价。不能被我统一代言，也不能被我统一原谅。这套评价——是责任的部分。"

"李先生！"裴照夜说，"末将还建立了隔离节点——两位归鹤，各占一个节点。像是……像是这套隔离，是防外溢的。像是……像是隔离节点，要可复核。像是……像是这套隔离，不是永久囚禁。"

"李先生！"宁知微说，"隔离节点——要可复核。像是……像是退出与复议条款——两位归鹤，可以申请复议。像是……像是这套退出与复议，是防永久囚禁的。像是……像是人格稳定记录——要长期核验。"

"李先生！"李无咎说，"隔离节点——可复核。退出与复议条款——两位归鹤可以申请。人格稳定记录——长期核验。这套隔离——不是永久囚禁。这套复核——是长期的。"

"李先生！"证物场外，又传来喊声。一个追兵跑进来，脸色惨白："李先生，客户——客户请求单独见李先生！他说——他说，他是裂隙的客户！他说——他要和李先生，单独谈一句！"

"裂隙的客户？"李无咎说，"那请他——"

"李先生！"宁知微说，"客户单独谈——像是……像是他有话，要对李先生一个人说。像是……像是那句，和容器有关。"

"和容器有关？"李无咎的脸色，变了一下。他承认受师父影响——却拒绝被定义。像是……像是这个客户，知道容器的真相。

"请他来。"李无咎说，"单独谈——谈完，再定。"

风从补天司裂隙吹过来。证物场上，双责任书签着，权限拆分着，双证据库立着。像是这道裂隙，正把"责任不再落给无辜者"的道理，一笔一笔，写进责任书里——而李无咎，正第一次，以拒绝被定义的身份，站在两位归鹤之间。
