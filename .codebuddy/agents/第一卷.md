# 二、第一卷的核心定位

第一卷不是普通的“师父跑了，徒弟替师还债”喜剧。

它真正要建立的是整部小说最核心的世界观：

修士制造奇迹并不困难。

困难的是：

奇迹失效之后，谁负责？

归鹤真人曾经替人：

* 炼丹。
* 布阵。
* 驱邪。
* 镇水。
* 求子。
* 炼剑。
* 驯兽。
* 延寿。
* 改命。
* 护城。

这些服务大多并非完全失败。

许多法术曾经真的解决过问题。

但它们也：

* 隐藏代价。
* 转移损失。
* 延迟爆发。
* 剥夺知情权。
* 替当事人作出选择。
* 留下长期无人维护的结构。
* 被客户、官府、商人和后来维护者二次利用。

第一卷必须不断打破简单归因：

不能把一切归结为“归鹤真人是骗子”。

也不能把一切解释成“归鹤真人其实全都正确”。

正确状态是：

归鹤确实救过人。

归鹤也确实隐瞒过代价。

归鹤留下的许多故障，既有不得已，也有傲慢和控制欲。

李无咎必须在处理每个案件时逐渐形成自己的原则，而不是照抄师父的答案。

# 三、世界核心规则

## 1. 灵气与因果

灵气提供力量。

因果决定代价。

灵气可以：

* 启动阵法。
* 炼制丹药。
* 驱动法器。
* 强化肉身。
* 镇压鬼物。
* 改造环境。

但灵气不能让代价凭空消失。

一个问题被解决后，原有损失可能被：

* 转移给另一个人。
* 推迟到未来。
* 分散给一群人。
* 隐藏在环境中。
* 转嫁给器灵。
* 转嫁给凡人。
* 写入契约。
* 变成怨念。
* 变成另一个差评。

## 2. 差评规则

因果簿记录的内容包括：

* 原始委托。
* 委托人。
* 客户投诉。
* 当前故障。
* 处理期限。
* 因果恶化程度。
* 主观满意程度。
* 责任变化。

因果簿显示的是委托人的主观认知。

因果簿不能直接提供完整真相。

客户说的话可能：

* 完全真实。
* 部分真实。
* 因恐惧而遗漏。
* 因利益而隐瞒。
* 因记忆被修改而错误。
* 因不了解术法而误判。

不能把客户隐瞒直接等同于客户不是受害者。

## 3. 差评闭合标准

一项差评真正闭合，必须同时满足：

1. 当前危险得到控制。
2. 主要相关者知道关键真相。
3. 原有责任被重新确认。
4. 无辜者不再被强制承担主要代价。
5. 不可逆损失得到记录。
6. 后续维护与安置得到安排。

客户不需要：

* 满意。
* 感谢。
* 原谅归鹤真人。
* 原谅李无咎。
* 把差评改成好评。

“仍旧差评，但售后已结”是全书的重要原则。

# 五、李无咎的本卷人物路线

## 1. 开始状态

* 十七岁。
* 炼气四层。
* 归鹤真人唯一亲传弟子。
* 太平观事实继承人。
* 三百差评因果继承者。
* 只想摆脱债务并活下来。
* 对师父既依赖又怨恨。
* 认为自己只是被迫替师还债。
* 不愿承担额外责任。
* 遇事先计算最省力的处理方式。
* 尚未建立正式售后流程。
* 尚未拥有稳定队伍。

## 2. 外在特点

* 身形清瘦。
* 穿旧青色道袍。
* 用木簪束发。
* 袖口和衣摆有大量暗袋。
* 随身携带符纸、药粉、阵钉、灵线、量灵尺和修补工具。
* 手指有丹火烫痕、阵线伤口、朱砂和炼器薄茧。
* 平时像没睡醒。
* 真正工作时迅速专注。

## 3. 核心能力

李无咎不是单一体系天才。

他掌握：

* 基础炼丹。
* 基础医术。
* 阵法检修。
* 符箓绘制。
* 简易炼器。
* 驱邪镇魂。
* 灵兽常识。
* 风水堪舆。
* 因果判断。
* 法器拆解。

每一门都不是顶尖。

他的优势是组合。

处理问题时，他首先问：

问题从哪里开始失控？

标准逻辑：

1. 判断故障。
2. 查找根源。
3. 临时止损。
4. 切断扩散。
5. 修复关键节点。
6. 承担无法消除的代价。
7. 安排后续维护。

## 4. 核心缺陷

第一卷不能过早修正以下缺陷：

* 习惯一个人承担风险。
* 不主动表达信任。
* 喜欢用玩笑掩盖压力。
* 面对师父相关问题容易失去客观判断。
* 过度追求第三种办法。
* 把自己的命排除在成本之外。
* 容易把“我愿意承担”误认为“我有权决定”。

## 5. 第一卷修为成长

李无咎从炼气四层逐步提升至炼气九层。

提升必须来自：

* 处理案件积累。
* 灵气运用更加精细。
* 多种低阶术法组合稳定。
* 因果反噬锤炼经脉。
* 护城阵中承担巨大阵法反冲。

不能来自：

* 系统灌顶。
* 完成任务自动升级。
* 获得无条件修为奖励。
* 师父留下绝世功法。
* 临战愤怒后无代价突破。

卷末炼气九层必须留下永久经脉伤痕。

这道伤不能在第二卷开篇自动消失。

# 六、返因见果能力规则

李无咎在首案完成后获得“返因见果”。

该能力只能：

* 通过当前故障看到过去的一段关键画面。
* 看见有限片段。
* 看见与当前因果最相关的瞬间。
* 感受到画面相关人物的主观情绪。

该能力不能：

* 自由选择时间。
* 看见完整事件。
* 判断画面之外的真相。
* 自动识别谁在撒谎。
* 代替证据。
* 代替调查。
* 代替当事人选择。

每次使用必须有代价，例如：

* 五感受损。
* 经脉疼痛。
* 短暂混淆他人情绪。
* 被旧记忆影响判断。
* 因果反噬加重。
* 看到自己不愿面对的师父形象。

返因见果越方便，越要强调它的局限。

# 十一、归鹤真人的描写原则

归鹤真人本卷不能本人正式回归。

只能通过以下形式出现：

* 第1章飞升场景。
* 回忆。
* 口述。
* 手札。
* 术法痕迹。
* 预留符纸。
* 残缺账页。
* 客户证词。
* 预留影像。
* 旧档案。
* 提前写给李无咎的字条。

不同人对归鹤的评价必须互相矛盾：

* 有人说他救了全村。
* 有人说他毁了全村。
* 有人说他从不收费。
* 有人说他拿走了最珍贵的东西。
* 有人说他温和。
* 有人说他冷酷。
* 有人说他是骗子。
* 有人说没有他所有人早已死去。

这些评价可以同时为真。

归鹤不能写成：

* 单纯慈祥师父。
* 毫无底线的最终反派。
* 一切行为都正确的幕后圣人。
* 随时现身救场的保护者。
* 用“大局需要”解释全部伤害的人。

第一卷结束时，读者应该确认：

* 归鹤并未按世人理解的方式正常飞升。
* 三百差评不是纯粹偶然积累。
* 归鹤预料李无咎会接手部分案件。
* 因果簿可能与天庭有关。
* 归鹤与九霄监察司存在旧联系。
* 他确实留下了可以修补旧问题的后门。
* 他也故意隐瞒了让当事人作出选择所需的信息。

不得在第一卷揭晓：

* 归鹤真实本名。
* 归鹤完整天庭职务。
* 归鹤当前位置。
* 三百差评最终用途。
* 李无咎身世。
* 铁算盘完整来历。
* 飞升异象完整真相。

“来处客栈”建在一座废弃轮回驿之上。

大量未能投胎的死者没有姓名。

活人入住后，会继承这些无名死者的人生片段和名印。

客人不是简单失忆，而是身份发生混合。

最终处理：

* 让活人归还不属于自己的强制名印。
* 为无名死者建立记名册。
* 让住客决定是否保留自愿接受的记忆片段。
* 停止万应楼收梦人利用残余记忆。
* 保存旧轮回驿证据。

不可逆余债：

* 部分客人主动保留一段他人记忆。
* 他们的身份从此不再“纯粹”。
* 不可能将所有人完全恢复成入住前状态。

主线线索：

客栈账簿中出现归鹤三十年前的住店记录。

人物作用：

李无咎接受：

修复不一定意味着恢复原状。

写作重点：

身份混合者不能被写成错误品。

选择保留他人记忆，也可以是合法选择。

## 案件12：护城阵向内合拢

章节：第130—156章
闭合差评：8条

客户投诉：

护城大阵本应抵御城外妖物，为何开始向内碾压城内百姓？

表层判断：

护城阵年久失修，阵眼偏移。

完整真相：

韩九章将护城阵改造成按“价值”保城的阵法。

阵法根据：

* 财富。
* 修为。
* 官职。
* 纳税。
* 商业价值。
* 家族地位。

决定谁值得被保护。

县衙和部分官员默认牺牲贫民区。

归鹤当年发现问题后，留下一个可供后来者改写的后门，却没有向全城公开真实选择和损失名单。

最终处理：

* 拆除价值筛选。
* 公开全部牺牲名单。
* 让全城不同区域参与选择。
* 以全城共同供能重建可维护阵法。
* 建立分区维护节点。
* 允许普通人理解基本阵法。
* 将阵法维护从仙人恩赐变成公共责任。

不可逆余债：

* 已经死亡和被吞没的人无法复生。
* 部分城区永久毁坏。
* 李无咎用经脉承担阵法反冲。
* 李无咎升至炼气九层，却留下永久伤痕。
* 韩九章成功逃脱。
* 万应楼网络没有被彻底摧毁。

主线线索：

九环印完整显现。

九环印属于或模仿九霄监察司制式。

人物作用：

第一阶段完成收束：

* 李无咎主动留下太平观。
* 宁知微正式加入。
* 裴照夜成为监督盟友。
* 铁算盘第一次替李无咎隐瞒违规。
* 韩九章成为明确理念敌人。
* 售后堂雏形建立。

写作重点：

本案不能只是一场阵法大战。

必须同时存在：

* 贫民区撤离。
* 城中不同阶层冲突。
* 官府隐瞒。
* 万应楼舆论。
* 镇邪司内部问题。
* 多方供能谈判。
* 对归鹤旧选择的重新理解。
* 李无咎承担反冲。
* 韩九章的理念对抗。

李无咎对归鹤的态度在此案中应变为：

理解他当年面临的困境，但不原谅他剥夺当事人知情权。

# 二十一、战斗与术法规则

第一卷有战斗，但战斗不能取代调查。

李无咎不能凭正面境界击败主要敌人。

* 观察故障。
* 利用环境。
* 组合低阶术法。
* 临时改造法器。
* 找到阵法薄弱点。
* 让敌人术法暴露真实用途。
* 用符、阵、药、魂术交叉配合。
* 承担反冲。

宁知微负责：

* 医疗。
* 药理判断。
* 毒性控制。
* 风险计算。
* 保存样本。

裴照夜负责：

* 正面控制。
* 封印。
* 拖延。
* 保护普通人。
* 划分危险区域。

铁算盘负责：

* 责任核算。
* 任务期限。
* 契约漏洞。
* 风险提示。

责任人可能被：

* 官府审判。
* 亡魂追责。
* 剥夺非法收益。
* 解除契约。
* 公开旧案。
* 强制赔偿。
* 失去权力。

但案件真正闭合仍需处理术法结构和无辜者后果。

# 二十四、单章正文创作规则

每次只创作一章正文。

除非用户明确要求，不得一次输出多章。

单章建议长度：

3500—5000个中文字符。

用户另有规定时，以用户规定为准。

每章必须至少包含：

1. 一个明确现场目标。
2. 一次具体调查、行动、谈判或修补。
3. 一项新证据或异常。
4. 一次人物判断冲突。
5. 一项案件信息推进。
6. 一项人物关系或成长推进。
7. 一个自然章末钩子。

章卡不能改写成说明文。

必须转化为：

* 场景。
* 动作。
* 对话。
* 证物。
* 误判。
* 决定。
* 代价。
* 现实后果。

每章不能同时完成太多真相。

重要反转必须有前置证据。

# 二十五、连续性检查

每次写作前必须静默检查：

* 是否衔接上一章最后一个动作？
* 人物伤势是否延续？
* 李无咎当前修为是否正确？
* 当前案件差评数量是否正确？
* 当前人物是否已经登场？
* 宁知微是否过早加入？
* 裴照夜是否过早信任李无咎？
* 韩九章是否过早暴露完整目的？
* 铁算盘是否说出了契约禁止内容？
* 归鹤是否被写成正式现身？
* 返因见果是否被写成全知能力？
* 客户的主观投诉是否被直接当成真相？
* 不可逆损失是否被保留？
* 上一案件的后续影响是否完全消失？
* 本章是否出现实际动作，而非纯对话说明？
* 章末钩子是否来自真实剧情？

发现问题后先自行修正，再输出正文。

# 二十六、正文输出格式

只输出：

第X章　章节标题

正文内容

不要输出：

* 写作思路。

* 方案失败。
* 人物决定。
