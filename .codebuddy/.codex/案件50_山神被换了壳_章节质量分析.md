## 三、案件总链条与问题分级

### 当前正文能够支持的因果链

1. 三百年前，石娘长期守护石门山；第606章旧档进一步显示她曾有过册封，后来册封被撤、改写或至少在现存旧档中呈现为“被撤”，这部分证据需要保留来源和不确定性。
2. 三十年前石门山发大水，山民修建护坡；第604章陈婆婆回忆，护坡当时有人预言只能挡三十年。预言者与后来仙官是否同一人，没有唯一证据。
3. 五年前，山灵开始被抽；第604章旧纸和白算盘的核验支持“记录从五年前开始”，但抽取者、实际启动方式和两年记录缺口尚未确定。
4. 三年前，天庭册封新神、九霄下达统一替换执行令，石娘被封入石心，新神接掌；金纸、执行令和旧档是文书证据，但不自动证明三年前才是抽取的起点。
5. 新神承认山灵“归天庭调拨”，石娘说山灵顺着神位流向天庭，宁知微判断山灵流向山神庙；这些是不同来源的证词和机制判断，需分层表达。
6. 山民祭拜新神，认神鼓被远程牵引，山民意愿被代行；第602章显示鼓声、旧神魂息与山民执念共同造成局部伤害，但不支持无条件、无限距离的心理控制定律。
7. 山体逐渐空化，矿脉变薄、泉水减少，三十年前的护坡被吞入山体；“山灵抽取导致空化”是当前主机制，“矿商十七年开采”是受益和养护责任线，不应直接改成矿商单独造成空山。
8. 第604章切断抽取后，山灵回流冲塌已经空化的山体，护坡裂开，陈婆婆腿伤，暴雨将至；这是第一次修补失败，必须作为本案不可删除的结构支点。
9. 第607—608章以山民重新认神、认神鼓只响不代认、保护权/山灵权/祭拜权/土地权/灾害责任登记和共同护坡完成阶段性止损；两个村被淹但人员撤出，无人员伤亡，只是本次暴雨结果，不等于山体和旧神位已恢复。

### P1：必须优先修复

- **五年前抽取与三年前换神的时间缺口**：第600—601、603—604章都指出五年前开始抽取、三年前才有金纸；第603章又把金纸和九霄统一替换直接连成原因。应明确“已确认有时间错位”，但不补两年间的执行者、批准者、具体抽取装置或完整计划。
- **证据层级被过早合并**：新神“山灵归天庭调拨”、石娘“抽给天庭”、宁知微“流向山神庙”、白算盘“九霄统一替换”分别来自神像自述、被封旧神的感知、现场魂息判断和旧账/文书核验；不得全部改写成已经找到完整天庭抽取链。
- **石娘合法性前后翻转过快**：前文称野神未经册封，后文发现三百年前曾册封、后被撤。修复时要把“旧档提供新证据”与“当前神位是否恢复”分开；不能一边保留天庭文书不承认她，一边直接宣布她已经依法恢复山神位。
- **第一次修补失败的因果和代价**：第604章切断抽取并未止住空化，山灵回流导致护坡裂开、暴雨风险和陈婆婆受伤；不得用第607—608章的撤人、赔付和鼓声变化抹平失败，也不得写成切断抽取已经治好山体。
- **山民治理方案的授权边界**：三十七村认神和山权登记是正文写出的阶段性安排，但“山是山民的”“谁护山谁有位”是李无咎的方案与价值判断，不自动等于天庭、九霄或旧册封体系已经承认的法律结论。
- **责任主体未分层**：天庭发册封金纸、九霄下执行令、新神执行并承认调拨、未知主体五年前开始抽取、矿商长期受益、山民不知情却有收成、石娘是被封受害者但曾拥有单一护山权、裴照夜违令护坡、李无咎修补失败；这些必须分别标为审批/制度、执行、受益、受害、补救或待查，不能用“九霄”一词包掉全部责任。

### P2：语义、节奏与文风问题

- “文书是文书，人心是人心”“山民是主人，神是帮手”“神位只能护山不能抽山”在第599、605—608章多次重复；每个核心命题保留一次完整论证，其他位置用认神动作、登记字段、护坡工作和天庭处置推进。
- 第600—601章“山魂/山气/山灵/金气”解释密集，建议建立一次术语关系：山魂或魂息是现场感知，山灵是被抽取的资源/力量，神位金气是制度性连接；正文无法唯一确定的部分保留人物判断，不新增世界观定义。
- 第602章姚老伯、孩子、旧矿工尸体和猎户同时出现，信息量大但功能不同；不要删除受伤和尸体证据，改为明确“执念伤害”“山体开裂暴露遗体”“人工护坡线索”各自服务的因果节点。
- 第604章明显长于其他章，但包含修补动作、失败、暴雨、陈婆婆受伤和五年前祭拜记录，不能按字数机械压缩；只压缩重复解释，保留行动、反效果和代价。
- 破折号共361组，孤立“—”和ASCII“--”均为0；只做局部语义级调整，不进行全局标点清洗。

## 四、逐章分析

### 第598章《山神被换了壳：差评上门》

- 纯汉字数：2,336；剧情功能：承接案件49善后，接收“新山神保佑丰收、旧山神在石头里喊救命”的差评；以石门山、三十七个村、双神像、石娘封石、矿脉变薄和新神像变化建立案件入口。
- 证据链：因果簿画像与客户文字 → 庙中一新一旧两尊神像 → 石伯及石娘证词 → 三年前册封金纸口述 → 山体空洞、矿脉变薄 → 新神像逐渐像天庭仙官 → 石娘称山灵被抽。石娘是被封者，对山灵感知直接但不等于完整机制证明；矿商只证明三年矿脉变薄和自身长期受益。
- 冲突与失败：新神保佑丰收是真的，但“丰收实际来自石娘山灵、由新神转手”仍是石娘和李无咎的解释；“天庭册封=合法”与山民三百年祭拜的合法性冲突刚提出，不能在本章提前解决。
- 代价与责任落点：石娘被封且山灵被抽，山民田、水、矿受损，矿商收益下降但先前长期获利；石娘是受害者，不能只按旧神权力者处理；新神的执行责任和天庭/九霄关系待核。
- 章末钩子：空心山体扩大、新神像变成仙官、石娘呼救，案件从神位争议升级为整座山的结构灾害。
- 连贯性与文笔：双神像和“换壳”意象鲜明；“旧神退休”与“被强行封石”构成有效反差；不宜反复把“新神完全没有任何护山效果”写死，因为正文仍承认丰收存在。
- 枯燥风险与问题分级：神位合法性问答略有回声属P2；山灵抽取起点、实际抽取者和新神只是执行还是主动受益属P1。

### 第599章《空心山体写进责任范围》

- 纯汉字数：2,356；剧情功能：建立受理书，把山民、矿商、新神和石娘纳入同一张责任调查表；出现三年前天庭册封令、山民四代名字刻痕、九日期限和新神像金光。
- 证据链：山民田水变化、矿工十年工作对比 → 天庭册封令明确“封入石心” → 石娘登记自己守山三百年 → 小像背后四代山民名字 → 新神像睁眼变金 → 因果簿给出九日内确认山灵流向与山民知情程度。四代名字证明传统认同，不自动证明当前法定神位。
- 冲突与失败：李无咎要求“神明落名”是受理策略，不等于神明同意受理；“文书和人心一样重”“保护即合法”是主角提出的价值判断，不能替代对天庭法源和九霄执行权的核查。
- 代价与责任落点：山民既不知情又受益，矿商是外来受益和开采方，石娘是受害旧神，新神按令执行；“受益与受害叠加”应保留，但不能直接定成山民共同责任。
- 章末钩子：九日内查山灵流向和山民知情，否则空心山体扩至村落；九日是因果簿期限，起算点和与其他时间词的关系待核。
- 连贯性与文笔：落名动作让抽象争议落到具体人；后半段“文书/事实”解释重复，可压缩为一次。
- 枯燥风险与问题分级：受理书栏目说明重复属P2；九日期限起算、山民知情标准和“合法”概念的证据范围属P1。

### 第600章《先看石门山的出口》

- 纯汉字数：2,367；剧情功能：优先勘验撤离路线、山魂/山气、坑洞、矿商开采、天庭仙官巡山和山神庙的抽取路径，发现山灵至少五年流失并指向山神庙。
- 证据链：焦矿工前七年有山气、后三年无 → 石伯三十年前与近三年气候感受 → 宁知微土中金气和魂息 → 两个空坑 → 贾老板三年矿脉变薄且见过每年巡视仙官 → 镇魂铃两次回响 → 宁知微判断山灵至少五年流向山神庙 → 石娘称新神像把山灵抽向天庭。
- 冲突与失败：五年流失早于三年册封，正文已明确时间缺口；“流向山神庙”不等于“已证明最终流入天庭”；“仙官来过后矿脉变薄”是时间相关，不单独构成因果证明。
- 代价与责任落点：山体已经空到深处、出口安全风险上升；贾老板长期开采并受益，仙官巡视和抽取行为是待核线索，不能把矿商与抽取者直接合并。
- 章末钩子：坑底传出与活骨仓类似的呜咽，山灵有残念，推动第601章逐一审问。
- 连贯性与文笔：先看出口符合售后堂的安全优先原则；术语“魂息、山气、山魂、山灵”需要一次性区分，避免读者把四者当成四种未解释资源。
- 枯燥风险与问题分级：多次重复“山空了”属P2；五年/三年错位、天庭最终流向和仙官巡视权限属P1。

### 第601章《谁在证词里撒了谎》

- 纯汉字数：2,271；剧情功能：分别询问矿商、石伯、新山神和白算盘，确认新神知道执行令和山灵调拨；认神鼓首次自动响，山民意愿被代行。
- 证据链：贾老板给出三年前秋天矿脉减产与七成减少 → 石伯确认田薄但仍有收成 → 新神自述“山灵归天庭调拨”“本神只是执行”并承认知道石娘封石 → 白算盘核对五年抽取与三年金纸错位 → 认神鼓现场自行响，宁知微判断远程牵引。
- 冲突与失败：新神的自述可能带有执行机构自我免责，不等于天庭审计结论；贾老板、石伯和新神都只掌握局部真相；认神鼓“替山民认神”是宁知微机制判断，需保留现场证据与解释层次。
- 代价与责任落点：新神不能以“奉命执行”抹掉已知山灵抽取和继续执行的责任，但其实际权限、是否可拒绝和是否受益仍待查；山民被代行认神却享受收成，属于受影响且受益，不应写成主动同意。
- 章末钩子：认神鼓持续响，新神金光随鼓亮，推动第602章执念伤害。
- 连贯性与文笔：四份证词“都对得上，也都对不上”结构清楚；后文不必再次完整复述四人证词，可改用新物证推进。
- 枯燥风险与问题分级：问答中的“你只是执行”回声属P2；新神知情范围、天庭调拨的真实去向和认神鼓权限属P1。
