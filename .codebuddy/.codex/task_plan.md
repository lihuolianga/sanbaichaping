# 下一个案件分析

## 目标

基于当前工作区的实际正文，确定下一个未完成/待分析案件，读取该案完整章节及相邻章节，输出案件功能、因果链、主要问题和可执行修复方案；本轮不修改小说正文。

## 阶段

- [completed] 1. 盘点正文、案件边界与当前工作区状态
- [in_progress] 2. 通读目标案件及前后衔接，建立证据链
- [pending] 3. 给出问题分级、修复顺序与章节级方案
- [pending] 4. 复核范围并交付分析

## 硬约束

- 以实际正文为事实源，卷纲、章卡和旧报告只作交叉参考。
- 不把版本归档、正文备份、卷纲章节卡计入正式正文。
- 不直接改正文，不覆盖用户已有改动。
- 分清已存在的问题、推断、建议和未执行的修改。
