## 三、逐章分析

### 第436章《城墙转身攻击城内：差评上门》

- 纯汉字数：2,375；“——”1组。
- 剧情功能：正式受理安北城投诉，建立十七名低阶居民被挡、垛口转向城内、身份色牌分级和天庭模板的表层冲突；章末色牌开始自行变色，把石敢娘划成黑牌。
- 证据链：贫民出口被封 → 十七人都有户籍、屋和地 → 垛口认青白色牌而非真实敌我 → 天庭模板写“低阶出城视为外敌” → 石敢娘黑牌自变色 → 城墙开始重新分类。
- 冲突：周远、韩墨把问题定义为阵法识别故障或天庭模板执行；李无咎指出它不是分不清敌我，而是分得很清，清到按身份决定谁可被推出城外。
- 失败与代价：尚未正式修补，但石敢娘病着被挡在城外，低阶居民失去出城抓药、探亲和回家的权利；石敢娘的身份已从青色变为黑色，排斥开始扩大。
- 责任落点：低阶居民、石敢娘和城外百姓是被排斥者；周远是地方执行者，韩墨是维护者；天庭模板和裴氏旧印只在本章形成上游线索，不能提前定成唯一幕后者。
- 章末钩子：色牌从红、青、白、黑之间自变，城墙准备把更多城里人划成“可以被推出城外的人”。
- 连贯性与文笔：起案现场清楚，石敢娘咳嗽、垛口转身和色牌变色把抽象制度具象化；“六天”是后续日期核验的起点。
- 枯燥风险与问题分级：P2。模板、色牌、敌我识别的说明略集中，但它承担机制定义，不宜整段删改。

## 四、机制、责任链和未决风险

### 正文已基本闭合的机制链

天庭战争模型把可牺牲人口写入城防模板 → 九霄监察司裴氏先祖签发 → 安北城依模板建城并由历代城守、军阵师维护 → 身份色牌执行“高阶入城、低阶出城”，黑线把安全区外者引向妖潮 → 红牌群体从制度稳定中受益，低阶居民、城北农人和临泉城石匠承担排斥与损伤 → 城外低阶者自设轮值钟守住城西缺口 → 局部剥离色牌指令失败，证明色牌只是执行工具 → 删除低阶条款、改为岗位牌、居民共议和自愿轮值 → 通过节点分责、退出权、监测、赔付、复议和公开档案建立新城防，但妖潮未到、缺口风险和上游责任仍在。
