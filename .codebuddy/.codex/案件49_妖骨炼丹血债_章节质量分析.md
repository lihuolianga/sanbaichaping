## 三、逐章分析

### 第586章《妖骨炼丹血债：差评上门》

- 纯汉字数：2,337；剧情功能：承接千工城善后，接收“续命丹有效但药材来自仍活着妖族”的差评，以会哭的丹丸、患者噩梦、尨族五头失踪妖和活骨仓建立案件入口。
- 证据链：因果簿画像 → 患者半年服药有效且持续梦见剥骨 → 丹丸触碰时发出呜咽 → 白算盘判断丹丸封存妖族被剥骨的疼 → 钱掌柜称取材牌合法 → 尨老者说壮年妖被以“献骨”带走且没有回来 → 活骨仓传出千百声呜咽。前半段“活取”仍是待查，不能把白算盘的判断写成最终司法事实。
- 冲突与失败：钱掌柜把合法取材牌等同于合法来源，尨老者只知道失踪和被骗，不知道五头妖的具体去向；“活取妖骨”与“死后献骨”的差异尚未由现场文书坐实。尨老者关于族人失踪的两段表述重复，可压缩一次。
- 代价与责任落点：患者因有效药而受益，却承担噩梦和身体痛；妖族可能遭受不可逆活取；药市掌柜、青炉谷分堂、天庭取材牌的责任尚未拆分；患者不能因为买药受益就被写成与活取者同等的责任主体。
- 章末钩子：活骨仓里的骨像想追随同族血，案件从个别丹丸转入药市基础设施和大量受害者。
- 连贯性与文笔：药效与血债的反差成立，丹丸会哭有鲜明视觉和听觉钩子；“药材来自活取”应保留为强烈嫌疑，直到第589、591章文书和证词出现后再逐步坐实。
- 枯燥风险与问题分级：反复解释“药有效但有代价”属P2；活取事实的证据层级、五头妖的具体身份和活骨仓数量属P1。

### 第587章《活骨仓写进责任范围》

- 纯汉字数：2,327；剧情功能：把患者、妖族、药市、收药、炼丹和销售关系纳入受理书；发现宁怀川早期审批文书；封存活骨仓并设置七日查明药材来源和患者知情程度的期限。
- 证据链：受理书三栏 → 尨老者登记五头失踪妖 → 两名患者家属登记续命丹批次和梦境 → 分堂档案出现宁怀川签名 → 钱掌柜承认封仓会断供 → 西街多名患者同时梦痛 → 因果簿给出“七日内确认药材来源与患者知情程度”。宁怀川签名证明文书上的签名，不单独证明其当时知道活取细节或拥有完整标准制定权。
- 冲突与失败：本章前面说要“查清来源”后再决定，后面又用“有问题/不合法”的二分法预设处置；“七日”从哪一事件起算没有交代。患者停药的医疗风险被提出，却没有临时诊疗、重症分级和替代药可用性的事实支撑。
- 代价与责任落点：封仓可止住来路不明药材继续流通，却立即把断供风险推给已有病人；妖族受害记录刚开始建立，责任不能只落在钱掌柜；宁怀川应作为待核的早期审批者，不应在本章凭一份文书被定罪。
- 章末钩子：七日内确认活取与知情程度，否则梦痛扩大至全城；这应是因果簿期限或风险提示，不要与前后章节的“第六天到达”“三天估算”混成一个自然日历。
- 连贯性与文笔：落名把制度责任具象化，患者和妖族被并列纳入是有效动作；“患者没罪、妖族没罪”的解释后续多次重复，可保留本章一次，后文用具体选择和代价推进。
- 枯燥风险与问题分级：受理书栏目说明略重复属P2；七日期限起算、断供后的救治安排和宁怀川证据等级属P1。

### 第588章《先看百骨药市的出口》

- 纯汉字数：2,338；剧情功能：先勘验三街、河流、水门、丹炉和活骨仓周边的撤离与火灾风险，再以骨粉、血水、取材牌和仓门异动把环境污染与妖骨因果连接起来。
- 证据链：药市中街/西街/后街布局 → 水门可撤 → 活骨仓旁火灾风险 → 河水含药味和骨粉 → 鱼绝、药田荒废 → 活骨仓排水口下游出现血色水珠 → 青铜“合法取材”牌编号 → 白算盘判断“有效取材范围”措辞含糊 → 仓内妖骨听见同族血而撞门。骨粉、血水与梦痛之间是现场检查和人物推断的组合，应区分已见物证与解释。
- 冲突与失败：钱掌柜先说牌照合规，白算盘又说“尽量取已故”或范围含糊的内容，牌面究竟写的是“合规”“已故”还是未写明，需要统一原文措辞；河里骨粉、下游血水来自多年淘洗的推断，没有量化范围，不能直接推出全城污染。
- 代价与责任落点：鱼死、药田废、下游可能受污染，药市多年经营收益建立在废弃环境和妖族身体上；钱掌柜可以是执行和收货环节，不等于取材牌签发者或整个天庭机构的唯一责任人。
- 章末钩子：仓内妖骨认出同族之血并想追出去，推动第590章血水扩散和紧急隔离。
- 连贯性与文笔：先看出口的安全勘验有实际功能，骨粉—血水—仓门的递进有效；“妖骨虽然死了却认血”应作为本案超自然规则的局部证据，不要顺势扩写成所有妖骨、所有血水都具有同一距离和强度。
- 枯燥风险与问题分级：布局、火灾和河道说明略密属P2；取材牌文字、污染来源、血水与梦痛的机制边界属P1。

### 第589章《谁在证词里撒了谎》

- 纯汉字数：2,339；剧情功能：分开询问钱掌柜、尨老者、周大叔和白算盘，形成“每个人都相信自己说的真话，却拼不出完整事实”的证词结构，并用旧牌时间和宁怀川印章把案件推进到历史责任。
- 证据链：钱掌柜承认偶尔收到被捆的活妖并称“待取材” → 尨老者说明族人以为死后取骨、反悔时已进药市 → 周大叔知道妖骨却不知道活取并承认曾选择不想 → 白算盘核出取材牌编号签发时间早于活取流程三年 → 档案房宁怀川印亮。活妖待取材和牌照时间是重要物证/证词，但“天庭说活取骨药效好”仍需注明为钱掌柜的口述。
- 冲突与失败：钱掌柜把“按牌合规”与“活妖待取”同时说出，说明执行者知道风险但未必知道审批链；尨老者的失踪记录不能单独证明五头妖全部已被活取；周大叔的“不知道”与其半年不追问构成道德压力，却不能直接等同法律知情。
- 代价与责任落点：活妖被捆等待取材是最直接的执行环节；被骗献骨的妖族是受害者；患者知情程度需要按购买时告知、患者本人理解、家属决定分别核算；宁怀川只进入责任核算名单，责任强弱尚待历史材料。
- 章末钩子：宁怀川旧印亮起，暗示几十年前的审批仍在影响今日梦痛。
- 连贯性与文笔：证词互相错位是侦查主线，白算盘“每个人都是真话”有主题作用；第594—595章不要再完整重复四份证词，只保留新出现的授权、批次和责任差异。
- 枯燥风险与问题分级：问答回声较多属P2；牌照旧签与活取流程时间冲突、患者知情标准和宁怀川的证据等级属P1。

### 第590章《宁怀川旧签再次失控》

- 纯汉字数：2,288；剧情功能：梦痛从服药者扩散到家属、农户和药市周边；第一次紧急隔离妖骨导致一具骨断裂、疼痛转移到儿童；宁怀川风险表显示他曾知道替代药风险却没有公开。
- 证据链：患者/家属/农户同步梦痛 → 活骨仓血水外流 → 宁知微判断骨是源头 → 隔离十具妖骨 → 一具骨自断 → 七八岁孩子出现同姿势疼痛 → 未署名替代药风险表 → 宁知微认出宁怀川笔迹。这里“骨断所以疼转给孩子”是现场因果判断，必须与已观察到的时间先后区分。
- 冲突与失败：前文说梦痛沿患者—家属—邻居因果链扩散，本章又把活骨仓和血水写成唯一源头，后文还加入河水、土壤和伤疤；需要把不同传播通道写成并行假设或已验证的局部路径。隔离妖骨到底减少了血水、改变了接触，还是主动触发疼痛转移，正文没有证实。
- 代价与责任落点：孩子成为紧急处置的二次受害者，农户和未服药者承担外溢代价；李无咎明确承认没有把握，这是重要失败和责任姿态；宁怀川风险表证明“曾意识到替代药不足”，不证明他已经完整知道活取血债。
- 章末钩子：宁怀川写过风险表却没有公开，形成“留路但没走”的责任线。
- 连贯性与文笔：隔离失败把抽象机制变成儿童受伤，情节力度强；“旧法止痛/新法治本”的两难可保留一次，避免与第593—596章反复复述。
- 枯燥风险与问题分级：自责和两难解释较密属P2；疼痛转移规则、宁怀川风险表证据范围和孩子受伤后的救治结果属P1。

### 第591章《第二个受害者带来会哭的丹丸》

- 纯汉字数：2,314；剧情功能：用七天携带会哭丹丸的货郎扩大案件地域范围，确认三年前批次和同源妖骨；货郎胳膊旧疤与丹丸相互感应；旧档案送入药市，出现宁怀川“活取骨效佳，然血债深重，请慎之。批：准”。
- 证据链：货郎三个月持有且丹丸哭 → 疤痕随哭疼 → 丹丸底部三年前批次 → 白算盘核出与活骨仓同源 → 路过客商喝河水后梦痛 → 货郎旧疤与三年前批次的时间相合 → 青炉谷总堂旧审批文书出现“活取”与宁怀川签名。批文是本案最强历史证据之一，但它证明某次或某类审批，不自动证明所有活取批次和宁怀川全部知情。
- 冲突与失败：货郎“走了七天”与第587章“七日内”可能被读成同一倒计时，需明确一个是路程/叙事时长，一个是因果簿期限；“喝河水所以梦痛”与客商是否真的喝水、喝了多少没有细写，不能作为全城传播定律。
- 代价与责任落点：货郎是无意持有旧丹的受影响者，不能因携带而成为责任人；三年前批次说明流通链远超本药市，责任应扩大到批次、流通和审批，但其他药市与宗门仍未被查实。
- 章末钩子：宁怀川在审批文书上写“血债深重”仍批“准”，父女责任线进入正面冲突。
- 连贯性与文笔：货郎对丹丸的舍不得有情绪辨识度，能把“物证”变成被听见的受害者；“一颗丹丸里藏着一条命”是有效句子，不宜在第597章再用同义抽象总结替代善后证据。
- 枯燥风险与问题分级：货郎问答略有同义回声属P2；旧批文书的适用范围、三年前批次流向和河水传播条件属P1。

## 四、问题分级与最小修复方向

### P1：必须在正文中解决或明确保留

1. **活取证据的层级不能跳跃。** 第586章的丹丸呜咽和白算盘判断是异常与推测；第587—589章的被捆待取材、取材牌文字和旧牌时间是证词/牌照证据；第591章宁怀川“活取骨效佳，血债深重，请慎之。批：准”是具体历史文书；第594—595章丹药司签发标准来自白算盘旧账。请把“已观察”“有人口述”“文书证明”“旧账确认”“责任仍待核”分开，尤其收窄第595章“完整链条核完”的绝对语气。

2. **梦痛的传播机制必须分层。** 当前正文先写丹丸/妖骨的疼传给患者，再写患者—家属—邻居的因果扩散，再写血水流出、客商喝水、农田和土壤，最后又说封哪一条都会顺下一条路。保留第590和第593章的失败与局部观察，但不要把“骨—丹—患者—血水—水土—疤痕”写成无限距离、无限对象、无条件必然传播的规则；说明哪些是现场检测，哪些是宁知微/李无咎判断，哪些仅待核。

3. **第一次修补的失败及其善后必须连续。** 第593章封骨、截水和撤农户没有在第597章交代血水是否处理、农户是否恢复、药田是否废弃、梦痛是否停止。第597章可保留“本案已完成的局部停取与赔偿”，但必须把污染、患者症状、替代药供应和未回访事项列为未决，不用“丹丸不哭了”代替全局修复。

4. **知情选择不能吞掉责任。** 第594章不是“李无咎完全不选”，而是他选择停止新增活取、封存和公开信息，再让具备表达能力的患者在旧库存/替代药之间选择。患者、家属、失能病人的选择权要分开；患者知情后继续吃旧库存，只承担其个人选择后果，不替青炉谷、药市、丹药司或审批者承担上游责任；妖族认领骨或接受赔偿，也不等于放弃追责。

5. **周大叔、周妻和北街病人的身份必须统一。** 第589、592、596、597章都出现半年肺痨患者、周大叔、周妻和“北街那户病人”。如果是同一人，必须保持“本人选择草木药—妻子因病情后悔—第七天死亡”的顺序；如果不是同一人，需最小区分称谓，不能让读者误以为同一患者既在选择后又被另一个家庭叙述替代。第597章的死亡结果只能归给正文能够确认的那一位患者。

6. **宁怀川、归鹤和丹药司的责任不能提前定案。** 宁怀川已经有签名、批“准”、写“血债深重”和留下风险表的证据，但其当时是否知道活取实际执行、审批范围、受益程度和后来未公开的原因仍未完全核清；归鹤有旧话、手印和未中止结果，但正式权限与失败原因未知；丹药司是旧账指向的标准签发机构，不等于已找到具体签发人、已经认账或全部分类责任成立。

7. **善后完成度要收窄。** 五具骨回族、已追溯对象的赔付、三十七份知情书、替代药培训和三次回访提醒可以保留；“按批次追溯”“赔了受害妖族”“患者选择做完”应说明范围，不扩成全部活取受害者、全部患者、所有药市或其他宗门均已处理。三十日、三个月、一年是检查计划，不是已完成报告。
