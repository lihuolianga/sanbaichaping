## 三、逐章分析

### 第511章《白骨庙把愿望变成痛苦：差评上门》

- 纯汉字数：2,287；破折号2组。
- 剧情功能：正式受理白骨庙愿望代价案，建立信众、庙祝、权贵、受害者、会自己称骨的秤、撤愿火盆和“代价另计”的初始机制，并把下一名未许愿受害者写进白签。
- 证据链：愿望实现而陌生人断腿或孩子夭折 → 会自己称骨的秤自动决定代价 → 许愿签只写“愿望必成”没有代价栏 → 白签背面自动写入陌生人姓名 → 代价可能落到许愿者，也可能落到未许愿者。
- 冲突：庙祝希望按“邪神恶意交换”快速处理，受害者要求公道，权贵只承认愿望实现；李无咎必须先阻止新代价，而不能把已实现愿望简单恢复。
- 失败与代价：本章尚未修补；赵满堂断腿、邻村孩子夭折、陌生人即将被写入白签，说明代价已不可逆或正在逼近。
- 责任落点：许愿者是受益者但未必知道具体代价；庙祝和秤/火盆的维护责任待核；白签与契台的规则责任尚未落到完整制度主体，不能在起案章压成单一“邪神”。
- 章末钩子：白签正在自动写入一个没有进过庙、没有许愿的陌生人，案件进入即时止损。
- 连贯性、文笔与枯燥风险：现场和受害者具体，开案有效；但“47个陌生人受伤”“赵满堂既是许愿者又被称为陌生代价”“每个愿望都对应陌生人代价”三种口径尚未区分，后文还会出现许愿者本人承受代价。问答复述略密。
- 问题分级：P1统一“受影响者总数、未许愿陌生受害者、许愿者自承代价”三个统计和称谓；P1不要把“代价随机落下”与“每次必有陌生人承受”写成同时无条件成立；P2压缩同义解释。

### 第512章《愿望白签写进责任范围》

- 纯汉字数：2,270；破折号0组。
- 剧情功能：把白骨庙信众、未许愿受害者、庙祝、权贵、庙神代表、最早维护者和不在场陌生人拆成七类责任/受影响对象，建立封存秤、白签、火盆和登记的止损方案。
- 证据链：七类人员落名 → 受害伤痕与愿望实现时间对应 → 秤自动写“愿望必成，代价另计，由秤自动称定” → 长期补偿簿存在空白且被骨老涂改 → 新愿望停止，证物隔离 → 期限从七天缩为五天。
- 冲突：骨三把责任解释成秤和庙神自动执行，李无咎要求维护者回答为何多年不问代价；信众的求医、求子、求活命需求与陌生人的人身安全冲突。
- 失败与代价：本章没有解除系统；封存新愿望只能阻止新增，不会自动抹去已实现愿望和既有伤害；期限缩为五天，但后文从第五天到第八天才进入执行，起算和截止语义未闭合。
- 责任落点：骨老对涂改补偿簿和隐去伤害负直接责任；骨三对日常收钱、维护和受益负责任；秤与庙神是执行节点；天庭功德转账同源只是正在形成的证据链，不能把所有责任提前合并。
- 章末钩子：秤显示下一次愿望代价已定，且白签背面已有名字，推动下一次转移。
- 连贯性、文笔与枯燥风险：七类登记有结构功能，但“知道/不知道/替谁决定”多次同构；五日期限需要在提示词中作为全案首要时间硬伤处理。
- 问题分级：P1五天期限与第515—521章的第三至第八天关系；P1七类对象不是互斥统计，不能让“庙神代表”和“秤”同时承担相同身份；P2压缩重复登记问答。

### 第513章《先看白骨岭的出口》

- 纯汉字数：2,215；破折号1组。
- 剧情功能：先撤离不涉事者，再查白骨庙旧档、秤、火盆和契台，确认三者分别接近记录、转移节点和规则层，并首次把秤与天庭功德转账契纹联系起来。
- 证据链：旧档批注“愿必成，价另计，秤称定” → 秤与天庭功德转账契纹同种 → 火盆烧起时邻村孩子夭折 → 秤、火盆、契台三者灵流相连 → 销毁秤会丢失记录，销毁火盆会让未转移代价失控 → 契台出现“愿已许，价未定，问价者未到场”。
- 冲突：受害者要砸秤、烧白签，庙祝和权贵要销毁证物；李无咎必须同时保护记录、限制转移和避免用一个节点替所有人决定牺牲对象。
- 失败与代价：未执行销毁或强拆；代价是证物仍在运行，白骨岭外仍有无辜人可能被写入白签。
- 责任落点：秤是记录/节点，火盆是转移中枢，契台是规则层；三者不可在修复提示中互换为同一个故障源。旧档证明同源关系，但不自动证明天庭完整制度的全部责任。
- 章末钩子：一个不在场的陌生人被“许愿”并等待代价，强化间接受影响者的主体性。
- 连贯性、文笔与枯燥风险：出口、证物和群体冲突清楚；庙门围堵段落前后近似重复，机制解释略像流程报告。
- 问题分级：P1统一秤、火盆、契台的上下游层级；P1把“同源/节点/制度责任”分成证据等级；P2删除重复围庙段落而保留双方诉求。

### 第514章《谁在证词里撒了谎》

- 纯汉字数：2,215；破折号0组。
- 剧情功能：用多组都自认为真实的证词拆解白签改式、陌生人代价和“免代价”收费的时间线，并通过错误结论让赵氏、钱百万和维护者主动纠正“愿望自愿等于代价自愿”。
- 证据链：三个月前白签已无代价栏 → 骨老称二十年前有人改签式 → 骨三称十五年前已有代价转移 → 骨老称三十年前提出免代价 → 钱百万确认加钱免代价 → 火盆指向李家村新生儿。
- 冲突：许愿者的选择权与未许愿者的身体/财产权冲突；错误结论把“愿望自愿”偷换成“他人代价自愿”，被赵氏纠正。
- 失败与代价：证词没有拼出唯一时间线；李家村新生儿仍是下一名可能受害者，火盆机制没有停。
- 责任落点：钱百万是付费受益者，骨三是收钱维护者，骨老是改签式和早期维护者；但“第一次改签、第一次陌生人代价、第一次免代价”的具体年份不能凭三份自述强行合并。
- 章末钩子：火盆路线指向一个刚出生的孩子，迫使案件从历史证词转入即时承接。
- 连贯性、文笔与枯燥风险：故意错误结论有推理功能；“三个说法”排比略整齐，时间矛盾目前是可保留的待核信息，不应被修复成单一年代。
- 问题分级：P1保留并标注三组时间尚不能唯一拼合；P1不把骨三、骨老、钱百万的知情范围写成同一层级；P2删减重复的“不是自愿/被写进签”复述。

### 第515章《撤愿火盆再次失控》

- 纯汉字数：2,252；破折号2组。
- 剧情功能：第三天验证代价扩散，李无咎第一次切断火盆通道并观察到代价转移到三个路人，逼出“堵一处、另一处加倍”的失败机制和长期补偿簿。
- 证据链：钱百万升官对应书生落榜断腿 → 孙二病好对应邻村孩子病重 → 宁知微给出扩散预测 → 火盆暂时吸住书生和孩子方向 → 三个路人同时承接代价 → 长期补偿簿记录大量未付账。
- 冲突：钱百万想退官，孙二想补偿孩子，骨三和群众要求保住愿望或保住火盆；李无咎拒绝把火盆选择的承接者当作可随意牺牲的人。
- 失败与代价：切火盆没有消除代价，反而让三个路人承接；预计每时约二十人、三天约三百人、两天约九百人的数字彼此缺少统计口径说明，不能直接当成同一模型的精确结果。
- 责任落点：李无咎承担切断火盆的现场选择和记录责任；火盆是转移节点而非根因；骨三、钱百万和长期补偿簿维护者分别承担受益、维护和历史欠账责任。
- 章末钩子：一名路人带出长期补偿簿，旧账从白骨庙内部显形。
- 连贯性、文笔与枯燥风险：失败结果具体，李无咎“我没有把握”有效；数字预警、单孔比喻和“救一处伤另一处”复述较多。
- 问题分级：P1统一三百/九百/二十每时的预测层级，不能补造统计口径；P1说明三个路人事件与第518章三个路人事件是否为同一批、不同阶段或不同承接；P2压缩相同机制比喻。

### 第516章《第二个受害者带来会自己称骨的秤》

- 纯汉字数：2,267；破折号1组。
- 剧情功能：货郎田七从青禾县带来同源秤，案件并案扩大到北地，证明代价系统不局限于白骨岭，并把梦境损耗、误工和跨地赔偿纳入案卷。
- 证据链：田七未进过白骨庙却连续三日梦见称骨 → 秤灵纹与白骨庙秤完全一致 → 磨损位置也一致 → 秤、白签、补偿簿是同一条线 → 归鹤留下“愿先问价，价问谁收”但未完成改秤。
- 冲突：骨三和钱百万试图把青禾县秤说成意外或仿制品；李无咎坚持同源证物不能被距离切断，田七则只希望回家且不再做梦。
- 失败与代价：田七已误工三日、精神受损；取走秤只能暂时保护他，不能证明全北地的代价系统已经停止。
- 责任落点：田七是明确受害者；白骨庙系统、秤的维护者和天庭同源规则仍是分层责任；归鹤的改秤未完成只能证明未竟补救，不证明他拥有完整授权或承担全部旧账。
- 章末钩子：归鹤未完成的改秤意图与白骨庙“愿先问价”警告连接，指向第517章知情追问。
- 连贯性、文笔与枯燥风险：并案让外溢代价落到具体人物；“同一台秤的两个端”“称代价/称欠账”需要保留一层主说法，避免读者误以为是两套系统。
- 问题分级：P1统一“同一系统、两个节点、同一台秤的两个端”三种表述；P1不把归鹤的未完成尝试写成已改成功；P2压缩梦境重复说明。

### 第517章《客户没有说完的话》

- 纯汉字数：2,369；破折号0组。
- 剧情功能：把知情责任拆成“知道有风险、不知具体受害者”“知情未细看”“知情且受益”“知情且维护”，并让受害者提出起诉、撤愿和补偿权利。
- 证据链：钱百万知道有代价并付费免代价 → 赵满堂看过“代价另计”但未细看 → 骨三知道代价转移仍收钱 → 骨老删去代价栏并知道转移 → 受害者要求起诉 → 白签浮出归鹤“愿先问价，价问谁收，未问者不得许愿”。
- 冲突：群众要求抄没钱百万，李无咎把单一受益者追责与制度拆解分开；孙二是受益但不知具体受害者，不能与骨三、骨老的主动维护责任等量齐观。
- 失败与代价：知情等级已登记，但赔付比例、返还顺序、起诉对象和天庭制度责任仍未定；归鹤警告未生效，系统仍未根治。
- 责任落点：四名当事人的责任深浅不同；孙二、钱百万、骨三、骨老的“受益/知情/维护”必须分层，不能用“都知情所以责任相同”收平。
- 章末钩子：白签上的未生效警告确认归鹤曾试图改式，下一章进入直接修补。
- 连贯性、文笔与枯燥风险：责任分类是本案人物和主题推进；“知道代价但不知谁承受”重复多次，可在不删分类的前提下压缩。
- 问题分级：P1责任等级与赔付/返还不能同时写成全额同责；P1归鹤改签未生效要与第520章旧档一致；P2减少群体口号化对话。

### 第518章《第一次修补失败》

- 纯汉字数：2,607；破折号2组。
- 剧情功能：以白签为临时闭环切断代价转移，现场让书生和孩子暂时止损，却把代价漏到水渠三个路人并加重，最终把病根从白签上推到契台和天庭功德总账。
