## 三、逐章分析

### 第523章《冥婚新娘其实还活着：差评上门》

- 纯汉字数：2,342；破折号3组。
- 剧情功能：正式受理柳林镇活人冥婚案，建立林月蘅活着、被登记死亡、被封进棺材、被嫁给亡子、名字和社会身份被抹除的核心故障；章末将故障从一个人扩展到王家媳妇。
- 证据链：棺中呼吸和温度 → 林月蘅本人自述活着 → 魂息完整、名字印有被删残痕 → 死亡户籍、冥婚文书和嫁妆密单存在 → 林氏家族是嫁妆受益者 → 新脚印和第二名看不见的活人出现。
- 冲突：林守正和县籍把活人当亡者，主张封棺、毁文书；李无咎坚持先开棺、先救活人、先保留身份证据。林月蘅要先离开柳林镇，安全优先于立刻恢复成哪一种身份。
- 失败与代价：本章没有执行修补；林月蘅已经遭受被封棺、被登记死亡和被迫冥婚的不可逆经历，且“看不见”开始向其他活人扩散。
- 责任落点：林守正、县籍、冥婚经手人、嫁妆受益者和可能的制度规则尚未同层归责；归鹤是否曾救她只能由后文证据补充，不能在开案章提前定性。
- 章末钩子：镇东王家媳妇也看不见，脚印成为身份仍存在的反向证据，案件从个人冥婚转成系统扩散。
- 连贯性、文笔与枯燥风险：棺中呼吸、脚印和“名字死了、身体活着”的现场感有效；“活着/看不见/身份死了”的问答复述较密，后续可删同义复述，但不能删掉证据和林月蘅的选择。
- 问题分级：P1明确“看不见”的直接证据是名字/身份被抹，不要把冥婚本身写成唯一法术源头；P2压缩重复确认，保留开棺、脚印和扩散钩子。

### 第524章《看不见的女子写进责任范围》

- 纯汉字数：2,282；破折号1组。
- 剧情功能：把林月蘅、妹妹、族长、县籍、冥婚经手人、见证人和受益者分成七类责任/受影响对象，建立封存死亡户籍、族谱和嫁妆密单的止损动作，并将期限从七天缩短为五天。
- 证据链：七张案登记 → 林月蘅脚印和名字印残痕 → 密单三笔转移分别由林守正、县籍、林婆签 → 名字删除被描述为族谱与官籍两层 → 县籍死亡印开始向其他活人移动。
- 冲突：每个经手人都以“按祖制/按文书/不知道她还活着”自辩；林月容提供昏睡按印证词，揭开冥婚不是本人同意；李无咎要求先封存而非销毁，以免身份记录和责任证据一起消失。
- 失败与代价：封存只能止住继续生效，不能恢复林月蘅身份；死亡印仍在寻找下一个活人，期限缩短后的起算点和扩散速度成为硬连续性风险。
- 责任落点：林守正、县籍、林婆各自掌握不同环节并受益，但“受益者”不是自动等于同等主谋；林月容是知情、恐惧、未能阻止，不能与删名和执行登记同责。
- 章末钩子：户籍死亡栏自动补写一个陌生名字，说明故障会继续寻找目标。
- 连贯性、文笔与枯燥风险：七案登记有结构作用，但问答模板高度同构；“两层删痕使用不同的笔”与第530章“族谱和死亡户籍由同一个名字印删改”存在直接证据冲突，必须最小核对。
- 问题分级：P1解决“不同笔/同一个名字印”的前后证据关系；P1把五天期限和第527—532章的第三至第七天明确为同一时间线或保留无法唯一判断；P2压缩重复落名问答。

### 第525章《先看柳林镇的出口》

- 纯汉字数：2,314；破折号0组。
- 剧情功能：先撤离不涉事者，再查柳林镇出口、户籍旧批注、活人棺封钉、族谱、死亡户籍和嫁妆密单，确认“恢复身份”比驱鬼更接近真实修补方向。
- 证据链：旧批注写明销名须验尸 → 棺钉有县籍官印 → 县籍不仅登记死亡还封棺 → 活人魂息完整且不在幽隙 → 族谱和官籍各有抹名痕迹 → 三样证物连到死亡户籍和财产受益。
- 冲突：林守正重复要求封棺毁文书，县籍要求销毁死亡户籍；李无咎拒绝破坏证物，主张保留记录、查清谁登记、谁签密单、谁划名字。
- 失败与代价：撤离和证据保存完成，但没有切断扩散；柳林镇居民因看见脚印而把活人误认作鬼，社会恐慌增加。

- 章末钩子：族谱中有人叫出“月蘅”，但叫名者以为她已死；被删身份与仍被记得的关系发生反差。
- 连贯性、文笔与枯燥风险：出口、旧批注和三件证物有调查推进价值；从“镇上开始有人往外跑”到县籍要求销户的一整段后文重复出现一次，属于可直接删除一份的明显重复。
- 问题分级：P1保留“官府封棺”和“死亡登记”事实，同时避免把它们写成已查明的完整制度源头；P1删除重复段落后仍保留群众恐慌和县籍自辩；P2收紧同义解释。

### 第526章《谁在证词里撒了谎》

- 纯汉字数：2,288；破折号1组。
- 剧情功能：用三组时间/证物证词拆解“病故、按印、登记、封棺、分嫁妆”并不等于同一件事；通过李无咎故意给出错误的祖制结论，让林月容、林婆、林守正和县籍分别暴露实际知情程度；周红玉带来临时红伞。
- 证据链：林月容见过昏睡按印 → 林婆承认知道林月蘅未断气仍按印 → 林守正承认知道未断气仍分田契 → 县籍承认听见棺内喊声仍封棺 → 周红玉指向县籍手中未登记名字册 → 红伞上出现另一个被抹名活人的名字。
- 冲突：裴照夜阻止群众只围攻族长，要求原件和逐层证据；群众要抄林家，李无咎把个人追责与恢复族谱、户籍、密单分开。
- 失败与代价：证词和证物让责任更清楚，但红伞只提供暂时见证，不能恢复整个身份系统；新名字仍未进入正式族谱和官籍。
- 责任落点：林守正是删名分田的直接受益者，县籍是知情执行者，林婆是知情经手者，林月容是恐惧下未能阻止者；周红玉是受过同类伤害的辅助见证人，不能替林月蘅决定。
- 章末钩子：红伞显示被抹名者不止一人，案件外溢并且有群体联络可能。
- 连贯性、文笔与枯燥风险：错误结论的纠正有效；“三个说法”“没有撒谎但拼不到一起”的结构有推理功能，但同类责任复述偏多。
- 问题分级：P1保留“都相信自己说的是真话”与真实知情被后文推翻的层次，不能把早期证词直接判成已解决事实；P2压缩重复的按印/删名复述。

### 第527章《周红玉红伞再次失控》

- 纯汉字数：2,224；破折号1组。
- 剧情功能：第三天验证死亡印扩散，展示红伞作为单孔临时隔离节点的失败，并引出“重新落笔”的新册子和县籍未登记名字。
- 证据链：王家媳妇、林家族老被标为死亡 → 死亡印按时辰扩散 → 红伞让林月蘅、王家媳妇和族老暂时可见 → 三名路人同时承接看不见 → 重新落笔的名字写进另一卷册子但未进入族谱/官籍。
- 冲突：林守正和县籍要求继续用红伞保住眼前的人；李无咎承认没有无害方案，拒绝用红伞替七百人决定谁承接故障。
- 失败与代价：临时隔离成功救下局部对象，却把故障转移给路人且损耗加倍；“每时约十五人、三天约两百人、七百人、两天所有人”的数字是不同口径还是同一模型，正文没有充分区分。
- 责任落点：李无咎承担试探和停止红伞的现场选择责任，但红伞不是根因；县籍未登记名字、族谱/官籍删名和更上游规则仍待查。
- 章末钩子：新册子里的“重新登记”可能是恢复，也可能是新的抹名，直接推动第528章追问。
- 连贯性、文笔与枯燥风险：承接失败具体，李无咎说“我没有把握”是本案较好的能力边界；数字预警、单孔比喻和“救一处、另一处加倍”复述较多。
- 问题分级：P1只做数字身份标注，不能重算或补名单；P1明确红伞是临时隔离/转移节点，不是身份恢复方案；P2压缩同一失败机制的重复解释。

### 第528章《客户没有说完的话》

- 纯汉字数：2,421；破折号1组。

- 证据链：林守正承认删名分田 → 县籍承认知道活着仍登记死亡、封棺 → 林婆承认知道活着仍按冥婚印 → 林月容承认害怕牵连而沉默 → 林月蘅承认醒来才知道名字消失 → 归鹤术痕确认救身体未还身份。
- 冲突：群众要求抄林家，李无咎指出只拿下族长不能让族谱、官籍和密单恢复；周红玉愿意联络但不能替客户发言；恢复名字会带来妹妹被连累的现实风险。
- 失败与代价：知情等级完成登记，但恢复身份、返还财产、撤销死亡和保护妹妹尚未执行；归鹤的补救仍是不完整记录，不能提前结算其完整责任。

- 章末钩子：棺上“余负之”把地方案与归鹤旧账接通，但只证明未完成补救。
- 连贯性、文笔与枯燥风险：责任分类和妹妹的选择有情感落点；中段反复用“知道她活着、仍然做了”推进，语言有报告腔，可做少量合并。
- 问题分级：P1保留林月蘅本人和林月容的选择边界，不能由李无咎单方面授权公开丑闻；P1不把归鹤写成删名主谋或完整制度责任人；P2压缩重复质问。

### 第529章《第一次修补失败》

- 纯汉字数：2,529；破折号2组。
- 剧情功能：首次尝试切断活人棺与死亡登记的错位，短暂让林月蘅可见，却把登记转移到镇东三名路人，进而逼近王三家新生儿，明确“活人棺只是症状，记录系统才是病根”。
- 证据链：镇魂铃、活人棺、死亡户籍、名字印残片和逆阵形成临时闭环 → 林月蘅短暂可见 → 三名路人名字被彻底划掉且家人记忆模糊 → 拆阵后路人记忆恢复、林月蘅可见收回 → 官印灵流指向王三家新生儿。
- 冲突：裴照夜追问授权和代价转移，宁知微说明不存在无害出口；林守正要求恢复冥婚，林月蘅拒绝牺牲路人保护自己；李无咎公开承认试验失败。
- 失败与代价：修补没有消除死亡登记，反而让路人承担更严重的抹名和记忆损耗；拆阵后的恢复不能抹掉“已经发生过失败试验”的责任记录。
- 责任落点：李无咎承担临场试探、授权不足和失败记录责任，但不因此成为原始删名制度的根因；族谱、官籍、死亡登记、嫁妆受益链仍需分层。
- 章末钩子：死亡灵流指向刚出生的孩子，逼出下一章的集体核查。
- 连贯性、文笔与枯燥风险：失败后果具体且有反转；“堵住一个口、另一个口漏出”的解释多次重复，机制说明略像流程报告。
- 问题分级：P1保留失败、路人记忆损耗和新生儿威胁，不得改成无伤试验；P1区分第527章三名路人与本章三名路人，正文不能唯一证明同一批时不得强行合并；P2减少重复比喻。

### 第530章《这次不能只听李无咎的》

## 四、跨章问题分级与最小修复方向

### P1：必须优先处理的硬连续性和证据问题

1. **名字印证据前后冲突。**第524—525章说族谱和官籍两层删痕使用不同的笔/墨，第530章又说两套记录由同一个名字印删改两遍。必须依据第530章后续比对结果做最小解释或收窄，不能同时保留为两个互斥的已确定事实，也不能凭空创造第三枚印、仿印或幕后操作者。

4. **授权不能被“都选第三”扩大。**第530章已经指出恢复姓名、公开丑闻和保护妹妹不是李无咎可以单方面替人决定的事；第531章的方案选择和第532章的本人书写才是执行授权依据。修复时必须区分林月蘅的姓名/婚姻选择、林月容的支持选择、受益者的认错/返还选择和售后堂的保护承诺，不能写成全镇或所有受影响者集体同意。
