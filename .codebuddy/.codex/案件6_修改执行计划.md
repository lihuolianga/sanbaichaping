**步骤一：在"羞耻频反弹"处插入具体羞耻记忆场景**


**步骤二：在"李无咎左臂铜粉倒灌"处改写为主动停手**

当前正文：
```
他的左臂经脉被铜粉堵塞了四条线。第五条线也岌岌可危。
```

替换为：

> 他的左臂经脉被铜粉堵塞了四条线。他可以撑第五条——但铜粉的流速在加快，不是往他左臂去，是往林芷心口的铜环方向拐。韩九章预设的联动被激活了。羞耻频的存储压力正在寻找最近的活人体内铜宿主——不是李无咎，是林芷。  
>   
> 李无咎在第五息时做了决定。不是技术判断。他的右手按在铜网上，拇指抵住林芷方向的铜丝——不是断开连接，是把倒灌的铜粉全部引向自己左臂。铜网的因果记忆在此刻替他做了一次算法选择：宁知微在病历上写"操作者将铜粉倒灌方向主动改向自身左臂"。  
>   
> 他停了。不是因为技术失败。是因为继续撑会把代价转给林芷。他在"自己受伤"和"让林芷承受"之间没犹豫。左臂从手肘往下失去了触觉。

**替换对象**：`第五条线也岌岌可危。` 至 `不是废了，是经脉被铜粉暂时堵住了。` 整段。

当前正文：
```
归鹤在六十年前把自己的名印嵌入了镜背核心。不是术法，是担保。他用自己的名印为镜子担保：如果有一天镜子伤害了人，他的名印会承担第一波反噬。今天反噬来了，被李无咎的左臂承受了一半。归鹤的名印丝线替他承受了另一半。
```

在 `归鹤的名印丝线替他承受了另一半。` 之后插入：

> 名印发光的瞬间，镜面上出现了一张脸。不是完整的脸——只有额头到鼻梁。六十年前的归鹤，坐在沈家堂屋的条案前写备忘。和镜背第九兽里那半张脸不同——归鹤这张脸有瞳孔。他正在往铜片上刻最后的存储上限标注。他的表情不是后悔，是算到了但来不及。  
>   
> 脸浮了一息，沉回铜胎深处。镜面上只剩未干的金屑，贴在第七兽喉骨内侧的缝线上，不亮，但热。缝线还没拉完。李无咎的左臂三天不能动——缝线的另一端握在归鹤名印的最后一根金丝上。那根金丝也从今天开始，只剩下最后一针的分量。

**插入位置**：`归鹤的名印丝线替他承受了另一半。` 之后，`"归鹤不是没修好。"` 之前。

**步骤四：补宁知微在反弹中的现场判断**

当前正文中宁知微的反应是 `喊"拔针！全部！"`，太快。

在 `宁知微发现时已经晚了半拍。` 替换为：

> 宁知微发现时已经晚了半拍。不是她没有看到铜粉流速异常——她看到了。她在铜网发出的第三十七道嗡鸣时就看到频率转向了林芷方向。她没有立刻喊停，是因为她正在算：如果她喊停，李无咎的左臂会承受全部倒灌；如果不喊，林芷的铜环会锁死。她算了两息。在第三息开始时喊出——"拔针！全部！"  
>   
> 她选择了李无咎的左手，放弃了她能救的病人。这个选择不写在病历上。裴照夜看到了，没有问。她把宁知微的判断记录在铜箔上：审核者在频段转向后延迟两息才下达拔针指令。延迟原因：审核者在计算转移路径，需在操作者左臂与被误锁者之间做选择。

**替换对象**：`宁知微发现时已经晚了半拍。` → `"拔针！全部！"她喊道。` 整段。

### 2.2 第74章《各人各自的选择》（第二优先级）

**当前状态**：2192字，24段  
**目标字数**：2600—2800字（+408—608字）  
**修改性质**：扩写——在"邻居回归"蒙太奇处插入两个具体人物场景，在章末插入理解频来源

#### 操作步骤

**步骤一：插入"拒绝回来的人"场景**

当前正文（邻居回归部分）：
```
傍晚。巷子里的黄纸被一张张撕掉。豆腐坊主第一个回来。他从门口捡起搬家通告，撕碎，走进沈宅堂屋。老夫人把一片碎镜递给他。
```

在 `傍晚。巷子里的黄纸被一张张撕掉。` 之后插入：

> 但不是每一家都回来了。  
>   
> 巷子最西头的酱菜铺，门上的搬家通告还在。铺子主人姓周，四十来岁，站在门口没动。他的儿子在铺子门槛上坐着，手里捏着一片碎镜——不是老夫人给的，是他自己从巷子地上捡的。碎镜上照出了他父亲的脸，但父亲把碎镜从他手里拿走了。  
>   
> "我不回去。"老周的声音不大，但每个字都硬得像酱缸底的老盐。"镜子说我的酱菜放多了盐，为了省成本。是真的。我放了。但镜子没说，省下的盐钱我拿去买了半斤阿胶——阿环走的那年，你咳了一整个冬天，药方上写阿胶太贵——我省了三年，省到你不咳了。阿环回来了，不需要阿胶了，我还在用那批多出来的盐。镜子只说了前半句。前半句是真的。后半句也是真的。但后半句被它吞了。"  
>   
> 他松开手，碎镜掉在地上。没有碎。他把铺子门关上，带着儿子回到屋里。门上搬家通告还在。黄纸下角被风吹起来又落下去，露出底层的铜锈——那是三十年前门环留下的印子。门关了，印子还在。  
>   
> 老夫人把周家的碎镜从地上捡起来。没有擦。铜锈和碎镜不矛盾。她把它单独放在条案最左边——和一叠不回来的人的名字放在一起。不回来也是选择。选择不回来的人，他的碎镜由镇邪司代存。有一天他想看了，随时来取。

**插入位置**：`傍晚。巷子里的黄纸被一张张撕掉。` 之后，`豆腐坊主第一个回来。` 之前。

**步骤二：插入"回来但不查询的人"场景**

当前正文（邻居逐个按手印后）：
```
巷子里的邻居一户户回来。杂货铺，布庄，茶馆，酱菜铺。每一家从老夫人手里接过一片碎镜。有的人哭了，有的人沉默，有的人笑着说早就知道。没有人要删。
```

这段"有的人哭了，有的人沉默了，有的人笑着说早就知道"用一个句子概括了至少五个人的反应。在 `没有人要删。` 之后插入：

> 杂货铺的老板娘接过碎镜，在钥匙串上按了手印——按手印的手上有铜秤磨出来的老茧。她把碎镜翻了过来，镜面朝下。  
>   
> "我不照。"  
>   
> 老夫人看着她，没有问为什么。  
>   
> "镜子说我偷偷给沈家大房的孙子多称了二两冰糖——是真的。那孩子长牙疼，含冰糖不哭。他娘说冰糖太贵，我说今天搞活动，多给了。没有活动。我用铺子的进价多称了二两，每个季度多一次，连续五年。镜子记得我每个季度多称的那一天。但镜子不知道——我儿子五岁那年也得过牙疼，疼了三天不哭——他不敢哭，因为他爹刚走。我当时没有钱买冰糖。"她把镜子揣进围裙口袋，镜面还是朝下的。"有些人做过的好事不是好，是补。补自己以前做不到的事。这件事不需要被照出来。我知道就行。"  
>   
> 她没有照镜子。但她的手印留在了钥匙串上——二十年来第一个按手印却没有查询的人。铜链上的手印比别人的淡，因为她按的时候没有用力。不是怕。是不知道这段记忆算不算自己的。

**插入位置**：`没有人要删。` 之后，`归鹤留在镜背的铜箔报告` 之前。

**步骤三：将"理解频"的档案记录改为一个具体场景**

当前正文：
```
宁知微在病历最后一页画了一张示意图，镜子核心的新状态。然后合上病历。"修完了。不是修好了。是修到镜子不会主动伤人了。但镜子里的记忆还在。六十年间三万两千四百人的恐惧、恶意、羞耻，永远封存在铜胎里。不能删。因为铸镜的人没给任何人删除的权限。他给了另一把钥匙。但钥匙在韩九章手里。我们拿不到。"
```

在 `宁知微在病历最后一页画了一张示意图，镜子核心的新状态。` 之后插入：

> 她画到第四频时笔停了。不是忘了名字。是名字还没被镜子自己说出来。  
>   
> 铜网在条案上发出一声极轻的振。不是恐惧，不是恶意，不是羞耻。是一个新频率——和铜网上封十娘第一次把铜网递出去时的振动一样。感应铜在金屑中认出了信任。  
>   
> 镜子没有开口。但镜面上浮现了两个字——极小，只占了指甲盖大的镜面，位置不在人脸的额头、嘴唇或心上，在镜面右下角，通常照衣领的地方。两个字：    
>   
> "送来。"  
>   
> 全堂安静。没有人说话。镜子也没有解释。但豆腐坊主懂了。他早上送豆浆的时候没和镜子说话。他只是把豆浆放在堂屋门口。他放了三十年。每天一碗，不放糖。  
>   
> 镜子记的不是他的恐惧。他从来没有恐惧。镜子记的是一个从没照过镜子的人，每天在同一个时刻经过。铜对铜的共振记录了这个重复——不是采样，是时钟。三十年重复变成了一个节奏。节奏的频率刚好等于心跳。镜子把心跳翻译成了两个字。  
>   
> 宁知微在病历示意图第四频的位置写上这两个字。不是定义，是镜子自己选的命名。"理解频——由重复信任形成的铜器共振记忆，非采样"。她没合上病历，让这页摊着。新频段的名字还湿着。

**插入位置**：`镜子核心的新状态。` 之后。

## 五、第4轮：P3语言润色

### 5.1 "不是……而是……"句式替换

逐章检查并替换：

| 章节 | 当前次数 | 目标次数 | 修改方式 |
|---|---|---|---|
| 第66章 | ~5次 | ≤2次 | 保留"不是铜镜本身，是镜背符式"。删除"不是推卸，是"。 |
| 第67章 | ~5次 | ≤2次 | 保留"不是有人害我，是我自愿"。删除"不是惩罚，是怕"。 |
| 第68章 | ~3次 | ≤1次 | 保留"不是来修镜子，是来收遗产"。 |
| 第69章 | ~2次 | ≤1次 | 保留"不是术法，是材质记忆"。 |
| 第70—75章 | ~13次 | ≤6次 | 保留最有辨识度的，其余改为直接陈述 |

替换原则：将"不是A，而是B"改为直接陈述B，或改为"他做了B，（因为他/虽然）"的因果结构。

示例：
- 当前：`"不是术法，是担保。"`
- 改为：`"这是担保——术法在名印形成的那一刻就已经写完了。"`
