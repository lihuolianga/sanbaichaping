## 三、逐章分析

### 第575章《器灵工坊集体罢工：差评上门》

- 纯汉字数：2,276；剧情功能：受理千工城法器街集体沉默的差评，建立“法器仍运转、器灵不回应、器灵疼痛外传”的核心故障，并用一盏灯和使用者被烫伤作为第一组可见证据。
- 证据链：因果簿画像 → 千工城法器街全街沉默 → 城主与坊主关于“邪修煽动/法器伤人”的判断 → 书生被灯烫伤 → 灯灵承认十年烧魂并第一次表达“不烧魂的权利” → 普通妇人出现同位置同步疼痛。
- 冲突与失败：李无咎先要求停用法器止损，但城里仍依赖灯、磨坊和水车；器灵从“不说话”到灯灵主动烫人之间的触发机制尚未说明；“器灵的疼找不到出口而撞到使用者”是现场解释，不等于已经证明排班表或洗忆池是唯一路径。
- 代价与责任落点：灯灵十年烧魂、书生受伤、妇人承担同步疼痛；城主把问题归给邪修，坊主把停工风险推回李无咎；受害者、使用者、工坊和城主府的责任尚未分层。
- 章末钩子：整条街的器灵沉默，妇人成为第一块裂痕，推动案件从“罢工”进入疼痛来源调查。
- 连贯性与文笔：法器仍亮、器灵不应的反差清楚，灯灵台词有现场感；“第五天，他们到了”应与后文“五日内”明确为抵达/处理期限两个不同时间层，不要让读者误以为期限已经在抵达时耗尽。
- 枯燥风险与问题分级：反复解释“器灵罢工不是不运转，而是不回应”属P2；疼痛转移路径、器灵主动伤人还是疼痛外溢属P1。

### 第576章《使用者同感疼痛写进责任范围》

- 纯汉字数：2,293；剧情功能：把直接使用者、维修师和工坊主纳入受理登记，建立三万七千件法器、二十年维修疼痛、十年使用和器灵契约缺失等账面证据。
- 证据链：城主府逐人落名 → 鲁坊主称器灵烧魂是“本分” → 十年账目三万七千件法器且无养护/休息/更换支出 → 何师傅二十年拆修时同步疼痛 → 书生承认十年知情使用 → 三万七千份契约“器灵按印”栏为空且鲁坊主承认工坊代按 → 全街同步疼痛 → 因果簿五日内确认来源的期限。
- 冲突与失败：三万七千件是宁知微从十年法器账中核出的数量，不能直接等同于当前全部活跃器灵；“器灵按印栏全空/工坊代按”与第580章老铜灯自称亲自按印形成硬证据冲突；五日期限没有交代从画像、抵达还是首次疼痛起算。
- 代价与责任落点：器灵被当作可消耗灵核，维修师疼了二十年，使用者十年知情却未被告知完整代价；工坊节省养护成本，城主府以行规为由不问，天庭标准的责任尚未有签发证据。
- 章末钩子：洗忆池被列为证物，三万七千个器灵“记得疼却记不清账”，迫使案件进入实物勘验。
- 连贯性与文笔：落名动作把抽象人格问题落到具体记录上；“三万七千件/三万七千个”应收窄为账目统计或当前核查范围，不能先行写成全城绝对总量。
- 枯燥风险与问题分级：责任问答和“值不值钱/疼不疼”回声偏多属P2；契约按印证据冲突、统计口径和期限起算属P1。

### 第577章《先看千工城的出口》

- 纯汉字数：2,290；剧情功能：先做人员撤离、水源和工坊布局勘验，再打开洗忆池，发现池底残念、两层符文和疑似天庭标准化印记。
- 证据链：工坊后门通官道 → 城西水车依赖器灵且已停转 → 工坊地基朝洗忆池倾斜 → 池水、旧纹与外加制式符 → 何师傅见过被洗散的“空壳” → 池底器灵轮廓印记 → 墙外残念回应 → 鲁坊主承认天庭标准化文书下发后照办。
- 冲突与失败：水车、后门和撤离只建立安全背景，尚不能证明洗忆池会爆炸或全城必然失火；“器灵被洗散”“魂沉池底”来自何师傅和鲁坊主证词，需与池底实际物证分级；符文笔法与兵器标准化相似，不能直接证明洗忆池由天庭建造或完整受天庭控制。
- 代价与责任落点：被洗空的器灵可能成为不可逆损失，工坊把洗忆解释为净灵和行规，天庭制式符的来源、授权、施加者未明。
- 章末钩子：池底残念与“应的是天庭的规矩”把个案连接到标准化制度，但只应作为待核跨层线索。
- 连贯性与文笔：先看出口的安全动作有效，池底一层层显影也有悬念；“洗了多少年”“千工城照办几十年”与后文铜灯一百二十年、最底层古阵“压了千年”需拆成不同时间对象，不能混成同一个洗忆池历史。
- 枯燥风险与问题分级：布局说明略密属P2；古纹/天庭符/工坊纹的层级和来源属P1。

### 第578章《谁在证词里撒了谎》

- 纯汉字数：2,263；剧情功能：用工坊主、维修师、城主和铜灯四份证词对照，确认洗忆频率、成本、记忆丧失和“洗吧，洗干净了，就听话了”的残存话语，并让器灵排出自己的休眠队列。
- 证据链：鲁坊主称一两年洗一次、半年前洗灯 → 何师傅称隔三差五见池中器灵 → 城主称工坊自管且从不过问 → 编号牌记载出厂三年已第三次洗忆 → 铜灯承认“不想亮”的念头被洗掉、想找回记忆但怕再次丢失 → 残存话语指向洗忆池 → 法器按休眠排班形状自行列队。
- 冲突与失败：三份人证都自认真实，却拼不出洗忆频率；编号牌支持高频洗忆，但不能单凭一块牌子还原全部时间；第576章契约按印栏为空与第580章老灯亲自按印需明确为不同档案、不同年代或保留冲突；排班表自启动的主动性和触发条件尚未坐实。
- 代价与责任落点：工坊以几十灵石洗一批、以几百灵石养一个的成本差，把节省转嫁给器灵；城主府因“天下都这样”不问；铜灯害怕恢复后再次被抹除。
- 章末钩子：器灵不是等待检阅，而是在排队等待某个契约或拒绝权被重新确认。
- 连贯性与文笔：证词互相错位是有效的侦查结构；“都是实话”不能替代证据层级，编号牌、账目、口述要分别标注可信范围。
- 枯燥风险与问题分级：四份证词的重复问答属P2；洗忆频率、契约按印和排班表触发关系属P1。

### 第579章《休眠排班表再次失控》

- 纯汉字数：2,280；剧情功能：把疼痛转移从局部外溢升级为排班表批量统筹，展示法器反向执行使用者急迫意图，提出独立隔离方案并造成新的损害。
- 证据链：南街、东街、城北按顺序同步疼痛 → 宁知微判断排班表按序统筹 → 磨盘放大“快点磨完”的意图而失控 → 隔离阵让磨盘停下 → 疼痛转到灯芯并撑裂 → 逐点隔离只能撑三天 → 鲁坊主要求重新洗忆 → 灯灵为避免被洗而烧完最后记忆并熄灭。
- 冲突与失败：排班表究竟是器灵自排、工坊阵基自动运行，还是两者叠加没有区分；“隔离一个节点，疼痛转到另一处”与第581章停统筹后全量爆发应建立同一守恒规则；灯“死了/记忆烧完/灭了”与第585章换芯重启不能混为同一结果。
- 代价与责任落点：磨盘毁粮、牛受伤、灯芯裂开并失去记忆/熄灭；李无咎拒绝用洗忆压回沉默，但三天期限迫使他在旧法止痛与新法不确定之间选择。
- 章末钩子：第一份器灵劳动契被提出，器灵可能仍记得曾经拥有拒绝权。
- 连贯性与文笔：反向执行真实意图是本案很好的故障可视化；“逐点隔离只能撑三天”应标明是宁知微按当前转移速度的估算，不要写成已验证的全城倒计时。
- 枯燥风险与问题分级：重复“不是罢工而是反抗/不是不干而是过度听话”属P2；疼痛守恒、排班权限、灯的不可逆代价属P1。

- 枯燥风险与问题分级：契文逐条解释和“问不问器灵”重复属P2；旧契有效性、按印证据和归鹤责任属P1。

- 章末钩子：必须先让器灵知道休眠不会再触发洗忆，才有资格谈停止统筹。
- 连贯性与文笔：失败具体、代价不可逆，是本案最重要的情节支点；“守恒”应作为现场模型而非万能世界法则，后续需展示养护如何承接、验证和限流。

## 四、问题分级与最小修复方向

### P1：必须先修的硬连续性、证据和机制问题

1. **处理期限与案件时点没有分层。** 第575章写“第五天，他们到了”，第576章出现“五日内”期限，第579章又出现“逐点隔离只能撑三天”，第581章发生第一次修补，第582—583章才翻池找根，第584章写“真相摊开后的第三天”，第585章又写半个月善后、第二周赔付/培训和三次回访。应把抵达日、因果簿期限、宁知微的风险估算、修补时点和善后计划分开；无法从正文唯一推算起算点时保留“期限起算待核”，不补绝对日期。
2. **疼痛转移—排班统筹—独立承受—养护接住的机制链没有闭合。** 第575—576章是器灵疼痛转给使用者，第579章是排班表按顺序统筹转疼，第581章停统筹后器灵同时爆发，第583章提出养护是“接住”疼痛，第584—585章却直接写成疼痛不再转移和全量善后。必须保留第一次失败，把“切断统筹”限定为错误的中间修补；说明养护/休眠/换芯只是拟议的承接机制，只有在正文已有现场证据处写成局部验证，不把疼痛守恒变成无条件万能规则，也不写成新契一签全城立即止痛。
3. **三万七千件/三万七千个的统计口径需收窄。** 第576章的三万七千来自十年法器账，第582—585章又把它当成当前全城器灵总量、全量回应、全量核查和全量签契。应区分账目累计件数、当前受影响登记数、可回应法器数和已核查对象；“约一半”“约三成”“七成不亮”必须标明统计基数和不回应是否算入，不能在正文没有核查过程时保留“每一件都完成”。
4. **器灵契约按印存在直接证据冲突。** 第576章宁知微称三万七千份契约“器灵按印”栏全空，鲁坊主承认工坊代按；第580章旧劳动契有模糊灵印，老铜灯明确说一百二十年前是自己亲自按印。最小修复应改成不同账册/年代/契约样本的范围，或明确“现有法器契档缺少可核验的器灵按印记录，但至少有一份老契和一盏铜灯自述亲自按印”；不能保留互相覆盖的绝对断言，也不能把模糊灵印直接认定为有效知情同意。
5. **洗忆池三层符的来源与权力层级需分开。** 工坊旧纹、天庭标准化符和更古老洗灵古阵可以构成“叠加层”，但底层纹路与南陵资源井同路数、天庭符与兵器标准化相同、白算盘称洗忆术来自天庭标准化，分别是现场纹路、旧账核对和阶段判断。不得补建造者、完整网络、授权者或幕后操作者；“天庭标准”不等于天庭所有机构或当前天器司已承担全部责任。
6. **排班表和器灵的主动权限没有统一。** 第578章排班表像器灵自排，第579章它按批次转疼，第581章阵基属于天庭标准化，第584章又将排班表改为公开表。应明确纸面排班、池底阵基、器灵意志和疼痛出口的层级；军令式“排队”是现场表现，不要把排班表写成有独立人格的全知管理者。第579章磨盘反向执行主人意图的解释也应保留为宁知微的现场判断，不能扩展为所有法器通用规则。
7. **第一次修补失败必须保留不可逆代价。** 第581章停统筹造成犁伤牛、粮食损失、纺车废料和一盏灯的记忆烧尽/熄灭，是本案的失败核心。第585章“换芯重启”不能自动抹掉第579/581章这盏灯的身份和记忆损失；必须区分灯灭、器灵记忆烧尽、器核损坏、是否仍可换芯和是否为同一器灵。后文新契只能改变未来规则，不能让旧伤害未发生。
8. **四方签契和授权范围过大。** 第583章说器灵、工坊、使用者、天庭标准“四方一起签”，第584章现场实际列出的是李无咎、鲁坊主、严城主、裴照夜、宁知微和铜灯代表，天庭标准签发者并未出场，第585章也只是白算盘从旧账认出天器司。应把新契写成千工城现场试行/在场主体签署的章程或契约样本；天庭标准链、其他工坊、全城使用者和所有器灵的长期效力列为待授权/待追责，不补全体授权。
