### 第477章《狐族所有人同一张脸：差评上门》

- 纯汉字数：2,290；“——”4组。
- 剧情功能：受理千面谷投诉，建立约四百名狐族、不到十人能认出原脸、三人裂脸、约三百户族谱和谷外猎人标记的调查盘面；引出涂山守玄、涂山小七和吴三。
- 证据链：全族同一祖先脸 → 小七试图恢复个人脸时裂开 → 裂脸沿模板牵连他人 → 猎人标记在谷外存在十余年 → 猎人可能按魂息而非脸追踪 → 族谱残页把姓名换成祖先脸印记。
- 冲突：守玄把问题定义为阵材故障，李无咎和铁算盘判断更像模板锁死；狐族要恢复个人脸，但恢复可能牵连全族；吴三把盯守谷口说成提醒。
- 失败与代价：本章没有修补，只能先止损；祖先脸既曾经保护族群，又可能早已变成猎人追踪模板；小七能看见自己，却不能稳定保留。
- 责任落点：祖先的生存决策、现任长老的沉默、猎人体系和外部登记均只获得线索，不能在起案章直接收束为单一责任人。
- 章末钩子：被刮掉的名字和祖先脸印记把“同脸”推进到身份抹除。
- 连贯性、文笔与枯燥风险：起案数字和现场裂脸有效，主题明确；“材料故障/模板锁死”对立清楚。问题分级：P1机制定义需与后文区分脸、名字、魂息和登记印；P2“脸是盾也是饵”类比略早重复。

- 证据链：残纸封存后裂脸仍转移 → 焚烧会让裂脸大面积爆发 → 二叔自画像与小七个人脸一致 → 画面被登记印记录为危险脸 → 孩子被登记印盯上 → 守阵确认登记印后接入伪装阵 → 残纸作为外部登记锚与内部登记印相连。
- 冲突：封存残纸只能减速，焚烧更危险；小七恢复个人脸的愿望与孩子被牵连相冲；吴三拿出猎人旧册既是补救又会暴露自身责任。

- 责任落点：登记印是后接的机制，不应被直接等同于归鹤或守玄；守玄接入登记印的知情事实仍需和“谁授权、谁受益、谁维护”分开。
- 章末钩子：孩子画像出现，登记印从惩罚想变脸者扩展为主动识别所有不同脸。
- 连贯性、文笔与枯燥风险：孩子被牵连使代价具体，故障可视化有效；本章解释和重复确认很多，是全案最容易显得机械的章节。问题分级：P1登记印触发与转移条件、P1“封/烧”语义、P1时间期限、P2重复对白。

- 剧情功能：补全守玄、守玄母辈、阿娘和吴三知道的真实姓氏与躲猎杀历史，把“改姓换脸抹名”从祖先生存决策推进到后代无退出权。
- 证据链：守玄自幼知道祖先脸是借的却长期隐瞒 → 旧帛证明猎人按真名追捕 → 真名被封在族谱夹层 → 阿娘确认原姓为胡 → 小七请求恢复真姓 → 面具背面留下归鹤“由本人决定、未竟反制”的警告。

### 第483章《第一次修补失败》

- 纯汉字数：2,369；“——”1组。
- 剧情功能：用小七自愿恢复个人脸的现场实验验证“把风险从一个人移开会压到孩子身上”，并把售后堂原则落为失败日志和个人选择。
