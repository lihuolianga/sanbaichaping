## 三、逐章分析

### 第449章《驱鬼后全城都成鬼：差评上门》

- 纯汉字数：2,293；“——”1组。
- 剧情功能：正式受理无灯城投诉，建立两千左右居民死后仍生活、城外时间过去三十年、城门关闭和三十七户家属等核心事实；陈九与母亲重复做饭把宏观故障落到亲情现场。
- 证据链：居民无呼吸无体温却继续生活 → 阳寿井被抽空、魂息连向井 → 城外空坟和魂息证明居民已死 → 刘长庚只给出天庭指标说法却不回答抽寿者 → 杜城隍三十年前上任并守城 → 归鹤驱邪引发瘟疫只是被要求接受的表层结论。
- 冲突：刘长庚要求尽快让居民轮回，杜城隍要求按“归鹤驱邪引发瘟疫”止损；李无咎拒绝在居民不知情时让他们消失。
- 失败与代价：尚未修补，但居民三十年困在同一时刻，陈九与母亲无法相认；若直接轮回，居民会在未被告知的情况下失去选择权。
- 责任落点：居民和城外家属是受害者；刘长庚只证明掌握阳寿记录，不足以单独证明抽寿责任；杜城隍承认守了三十年，但是否知情、为何隐瞒仍需后文证据。
- 章末钩子：陈九母亲的空碗和重复做饭成为“时间停在死亡前夕”的具象证据。
- 连贯性与文笔：起案清楚，调查动作先于归因；“处理期限七天”是后续日期核验的起点。
- 枯燥风险与问题分级：P2。概念说明较集中，但居民、家属、城隍、寿命吏四方立场清晰，不宜机械删段。

### 第450章《重复做饭的亡魂写进责任范围》

- 纯汉字数：2,335；无“——”序列。
- 剧情功能：把亡魂、城外家属、外来者、杜城隍、刘长庚、魂魄维护者、仍活着的相关人和城内死者分成八个登记位置，建立“先封井、先看守、先记录、先核墓碑”的止损顺序。
- 证据链：陈九母亲不知已死 → 何远想替妹妹轮回 → 郑守一承认维持假象三十年 → 刘长庚承认只记录不处理 → 宁知微确认城内时间固定在三十年前 → 因果簿把期限从七天改为五天。
- 冲突：李无咎坚持亡魂必须知道后自己选择；刘长庚担心封井影响天庭指标；杜城隍担心魂息断裂；郑守一以“怕他们崩”为维护假象的理由。
- 失败与代价：封井被提出但没有明确执行结果；知情延迟每天都减少居民选择时间，且“七天改五天”与后续第七至第十二天形成硬时间阻塞。
- 责任落点：维护者和城隍不能因为害怕就替居民决定“不知道”；天庭指标、维护和家属愿望必须分开，不得把家属想让亲人轮回写成居民本人同意。
- 章末钩子：城门口永不点亮的灯芯出现天庭符纹黑线，暗示灯不是普通症状。
- 连贯性与文笔：八张案清楚，但登记说明偏报告体；“八类”是责任位置，不应被后文扩写成固定总人数分类。
- 枯燥风险与问题分级：P1为处理期限；P1/P2为“先封井”只有方案，没有执行闭环。

### 第451章《先看无灯城的出口》

- 纯汉字数：2,511；“——”2组。
- 剧情功能：先布置城门、阳寿井、坟地三条路线，再核对旧档、空坟、魂息和井底记录，把“天庭抽寿—归鹤补魂息—居民假活”初步串起来。
- 证据链：空坟与墓碑保留魂息 → 陈氏夜里从坟回城 → 井记录两千一百三十七人阳寿转入天庭总账 → 井底另有归鹤术痕维持魂息 → 魂息开始向坟地渗出 → 李无咎提出封魂息、封井和暂不让家属进城。
- 冲突：家属想进城见亲人；李无咎认为三十年年龄差会造成二次冲击；宁知微指出封井会让居民开始察觉，裴照夜则发现城外坟地因魂息回流出现“活”的假象。
- 失败与代价：正文有“先封井”的决定，但未交代是否执行、执行失败还是暂缓；后续井仍运转，不能默认该动作已经完成。
- 责任落点：井证明天庭抽寿和归鹤补魂息是两段不同责任；“抽寿的人”仍未由本章唯一锁定。
- 章末钩子：井底传出“我拦了。我没拦住”，并带有城隍印味道，引出被驱逐的城隍证词。
- 连贯性与文笔：出口优先、证物并排和器灵问诊有效；“三条路”“三故障源”“井为末端”都是当下调查模型，后文若更新为灯的共同通道，要明确是阶段性结论。
- 枯燥风险与问题分级：P1为封井动作闭环；P2为井、墓碑、灯的根因层级尚未稳定。

### 第452章《谁在证词里撒了谎》

- 纯汉字数：2,437；无“——”序列。
- 剧情功能：用三组互相对不上的证词检验时间、城门关闭和轮回申请，李无咎故意抛出“归鹤驱邪引发瘟疫”的错误结论，再由郑守一、陈九母亲和裴照夜拆开驱鬼、抽寿、保存、隐瞒和证据层级。
- 证据链：陈氏、杜城隍、郑守一对抽寿时间和城门关闭各有不同口径 → 寿命吏说按天庭批示 → 郑守一指出阳寿井是天庭抽寿井 → 陈氏记得灰袍真人说“只能让你们这样走” → 三十七张差评自动并案。
- 冲突：群众想把责任集中到郑守一或归鹤；裴照夜要求先找阳寿记录、批示、总账流向，李无咎要求救援与责任核查并行。
- 失败与代价：证词都可能是本人相信的真话，却无法拼成一个时间；三十七户等待从个案变成跨三十年的共同投诉，处理范围扩大。
- 责任落点：天庭抽寿、归鹤保存与隐瞒、郑守一维护、刘长庚执行必须分开；不能用“所有人都没有撒谎”替代时间证据。
- 章末钩子：三十七缕黑线在灯上盘成三十七张差评，等待一个能回答亲人生死的人。
- 连贯性与文笔：错误结论—主动纠正—责任分层的调查节奏完整；证词时间不能在提示词中被强行拼成单一年份。
- 枯燥风险与问题分级：P1为处理期限承接；P2为证词较密但每组都推动责任边界。

### 第453章《三十七张同源差评再次失控》

- 纯汉字数：2,296；无“——”序列。
- 剧情功能：让铁匠、豆腐坊和教书亡魂的执念扩散，证明未完成心愿会把活人拖进旧事；李无咎首次把三十七张差评作为隔离节点，却验证出“堵住一个口，执念转移到三个活人”。
- 证据链：铁匠重复打三十年未完成的农具 → 豆腐坊重复给已死的王婆留豆腐 → 林昭爷爷把四十岁的孙子认成十一岁 → 三个活人同时承接豆腐执念 → 预计两天内约八百人受影响 → 旧帛证明鬼城契允许魂魄自行治理、轮回、留下或消散。
- 冲突：刘长庚把活人倒地归责于李无咎；杜城隍要求继续用差评堵住执念；李无咎承认没有把握，拒绝用一个方向的“救”挑选另一个方向的承受者。
- 失败与代价：差评节点短暂停住亡魂，却把执念转移给三个活人；第一天、第二天、第三天的损耗是估算，不能补造精确公式。
- 责任落点：受影响活人是被迫承接者，不是新责任源；差评是投诉与节点，不是治疗方案；鬼城契是居民选择权的证据，不能被寿命吏单方面覆盖。
- 章末钩子：鬼城契写明“不可强令轮回”，但城里的人从未被告知这项权利。
- 连贯性与文笔：失败可见、代价具体，李无咎“不假装有把握”的人物推进成立；“第三天”必须与第450章五天期限和第454章第四天核对。
- 枯燥风险与问题分级：P2。重复承接机制与前案相似，但本章增加三类执念和活人损耗，不应整段删除。

### 第454章《归鹤留下的第一座鬼城契》

- 纯汉字数：2,309；“——”5组。
- 剧情功能：返因见果确认鬼城契的术痕与归鹤相关，展示归鹤拦抽寿失败、以自身寿元保存两千一百三十七个魂魄并立契，同时提醒画面可能只留下归鹤想被看见的一面。
- 证据链：契上术痕与归鹤命契、文神册封和天账司残帛同笔锋 → 画面显示天庭官吏按指标抽寿 → 归鹤堵井失败、以自身寿元补井 → 立下“魂魄可自行治理”契 → 画面没有证明后来回访和告知 → 契痕方向与城门灯位置相反。
- 冲突：李无咎理解归鹤救人的困境，但宁知微和裴照夜指出画面可能有选择性，保存魂魄不能抵消隐瞒死亡事实的责任。
- 失败与代价：归鹤救下魂魄却让两千多人在假象中生活三十年；灯是否是归鹤标记、契痕指向何处、契痕方向和灯的通道是否为不同层级，正文尚未唯一闭合。
