# 案件29《宗门联合问责会》章节质量分析

## 一、事实来源、案件边界与总体结论

本报告只依据当前工作区的正式正文逐文件复核。卷纲、旧报告、自动化记忆和“案件提示词”目录不作为本案正文事实来源；本轮未读取、未修改“案件提示词”目录，也未修改任何正文。

- 案件编号：29
- 案件名称：宗门联合问责会
- 正文章节范围：第三卷第339—350章
- 前案边界：第三卷第338章《不存在的胜者指向下一页》，只核对上一案善后和联合问责函，不纳入本案逐章统计
- 下案边界：第四卷第351章《镇国龙脉每年续费：差评上门》，只核对本案收束和下一案入口，不纳入本案逐章统计
- 案件选择依据：案件16—28已有优化提示词；案件29在优化提示词目录中不存在；第339章从第338章末尾的十三宗联合问责函直接起案，第350章交出《镇国龙脉续费章程》，第351章正式进入新案
- 版本状态：第339—350章每章各发现一份正式正文；本轮没有合并、覆盖、重命名或删除正文

总体结论：案件29已经形成完整的“宗门联盟以损失榜启动联合问责—空席暴露受害者被登记为已赔付—库房、封口符、赔付转账和万应楼分账组成三层故障—第一次修补把压力转移到受益端名册—李无咎承认自己的承诺和修补失败，但拒绝替他人背账—公开失败账、追回商会款项并建立限期监督—找到许青芜并恢复其户籍—保留旧文书、补抄批注、商会欠条和韩九章未归等风险”的案件骨架。

本案最重要的问题不是李无咎有没有过错，正文已经明确写出他的逞强承诺、预案不足和失败账滞后；真正需要最小修复的是责任链中的对象和时间层级没有完全闭合。第342章把同一组“封口符”分别说成三年前、去年秋和五个月前封存，第341章又写三十七张封口符中十一张被撬、卷宗被换；第347章只证明真正的控制点在封口符背后，没有证明幕后主体。正文可以保留幕后未明，但需要让读者明确这是多轮封存/交接的不同时间层，还是同一物件的硬冲突。另有第344章灰袍人带铜牌箱与第345章灰袍旧道士、酒葫芦的身份不能仅凭“灰袍”合并。若正文不能唯一推出，相关处必须阻塞，不能按卷纲补幕后人物。

案件的责任落点应保持分层：李无咎和售后堂承担直接修补、承诺和记录责任；青州宗门联盟承担压名单、延后归档和问责归类责任；三个商会承担收取善后经费却未向受害者支付的受益责任；万应楼和韩九章承担集中转录、放大和重新归类责任；旧文书承担移档或删档的待查责任；许青芜、许伯、文桐及其他受害者承担真实且不可逆的损失。不能把这些责任重新折叠成“售后堂失职”，也不能因为第350章善后落地就提前消灭未明幕后、未还欠条和无法完全补救的损失。

## 三、案件事实链、冲突与责任落点

```text
第338章末尾十三宗联名问责函把上一案真实损失指向“售后堂破坏稳定”
→ 第339章损失榜列二十三条，十八条来自售后堂经手案件，榜单只列损失不列受益者、隐瞒者和删档者
→ 许青芜被列入“已赔付、已结案”，本人不在场、无签字、无领款和无回访，空席成为“人被变成条”的支点
→ 第340—341章发现领款页和回访页被撕、联盟档案库被撬、赔付科目被改成空白往来，三条灵路分别连向损失榜、空席和库房外
→ 第342章三方证词出现三种封口符时间，说明至少存在不同封存/交接层，具体层级尚未由正文唯一命名
→ 第343—344章损失榜把旧事故复现到现场，文桐带来预先抄写的榜和被裁掉的旧档，证明损失榜不是临时统计而是预先布置
→ 第345章确认联盟压下完整受害者名单，三个商会收到善后经费，旧文书把名单移入待销毁档，万应楼把真实损失集中放大
→ 第346章封榜、加封档案、建立许青芜独立记录并暂停万应楼后，损失从空席/榜单转到受益端宗门长老名册，十七条异常中十二条被填为“未说明”
→ 第347章证明联盟代管方案没有期限、权限、复议和退出边界，三条调查线共同指向封口符背后的未明控制点
→ 第348章把直接责任、受益责任、隐瞒责任、放大责任、受害者代价和仍未获得选择权分开，提出三个方案
→ 第349章选择有限监督而非否认或全权交接，公开四十七卷失败账、商会欠款和联盟隐瞒记录
→ 第350章拆除小室、找到仍活着但户籍被结掉的许青芜、恢复登记并保存负面记录；旧文书下落、补抄批注来源、商会欠条、韩九章本人仍未解决
```

### 三层故障

1. 症状层：论道台损失榜把回风山、轮生谷、千机试炼塔、正阳宗等不同案件的真实损失集中展示，并通过榜单复现干土、失忆和咳血。
2. 传导层：三十七张封口符、被换的旧事故卷宗、万应楼转录、联盟账册和分账把旧事故与榜单、名册、赔付系统连通。
3. 源头层：许青芜空席、被撕的领款/回访页、空白往来科目和地下小室把受害者身份和赔付款从“给谁”改成“有一条记录”，使人被变成条目、钱被变成无名往来。

### 责任分层

- 李无咎与售后堂：承认承诺过重、把“没有把握”写成“待观察”、失败账滞后和第一次修补的边界判断失误；不能因此背下联盟压名单、商会截留和万应楼放大造成的全部历史责任。
- 青州宗门联盟与齐望川：压下完整受害者名单、延后归档、把真实损失归类为“售后堂修补失当”；齐望川在第345、349章公开了联盟隐瞒责任，但不等于每个宗门代表或全部事故都已认罪。
- 三个商会：收到善后经费且未向受害者支付；能退的已退，不能退的写成欠条，债务未清不是案件已无代价。
- 万应楼、韩九章和单晋：集中转录真实损失并放大传播，单晋可记录“编排责任”，但正文没有证明韩九章制造了回风山、轮生谷或千机试炼塔原始事故。
- 旧文书与档案控制者：完整名单被移入待销毁档，要求删档的人和旧文书下落仍未唯一确定；不能把第347章“封口符背后”直接补成一个新反派。
- 归鹤：正文同时写出他当年压不住联盟、埋下名单并承认“没能拦下”的责任，也写出他曾让李无咎亲见失败；归鹤的原始批注是线索和责任记录，不是李无咎免罪符，也不是幕后设计证据。第347章发现一条新墨补抄批注，第348章保留一条旧墨原批注，二者必须分开。
- 许青芜、许伯、文桐及其他受害者：是被压名单、被错误结案和被统计重新分类的人，不是“稳定成本”或问责工具；许青芜本人恢复到场、户籍和登记，不等于三商会债务和所有损失已经恢复原状。

## 四、逐章分析

### 第339章《宗门联合问责会：差评上门》

- 纯汉字数：2,976；破折号：0处。
- 剧情功能：把第338章联合问责函落到青州论道台，展示二十三条损失榜，并以许青芜空席把问责从抽象名声争议落到一个失踪但未死亡的人。
- 证据链：损失榜、十三枚宗门印、万应楼账箱、榜上二十三条/十八条经手案件、许青芜名牌和“已赔付、已结案”记录、背面箭头、石台温度、七日处理期限改为五日。
- 冲突：联盟和万应楼要求李无咎承担总责，李无咎承认真实损失但拒绝接受未分责任的罪证；许伯指出儿子没有领取赔付，空席却被写成结案。
- 失败与代价：本章尚未执行修补；许青芜继续被记录为既不在场、也没有死亡证明的人，联盟仍准备把损失统一归为售后堂责任。
- 责任落点：本章应先落在“损失真实但归类不完整”，不能把李无咎的受理表态写成认罪；万应楼的编号只证明其参与数据转录，不单独证明其制造原始损失。
- 章末钩子：空席自己倒下，背面箭头指向正门，石台里存在长期放置物的痕迹，许青芜的空席成为实体故障源。
- 连贯性、文笔与枯燥风险：榜单、空席、名牌和温石是有效物证；“二十三条、十八条、十二条”的统计对象后文必须继续分栏，不得为了顺口把它们当成同一人数。

### 第340章《受害者空席写进责任范围》

- 纯汉字数：2,231；破折号：0处。
- 剧情功能：建立直接受害者、联盟文书、原档案保管、赔付去向等登记行，把“已结案”拆成可核验的五个问题。
- 证据链：许伯拒绝代替许青芜签名、不同笔迹、万应楼编号WYL-青州-0773、去年秋卷宗的撕页、未署名的“留席，待查”纸条、模糊盘兽印、库房新锁和活风。
- 冲突：齐望川要求先恢复论道台原状，宁知微指出这会把许青芜重新变回没人知道的记录；桑执交出被联盟要求不上交的纸条，证明“待查”曾被保留又被压下。
- 失败与代价：登记本身没有找到本人，处理期限从七日缩为五日；许青芜的领款页和回访页被撕，赔付是否真正到户暂时无法证明。
- 责任落点：联盟的档案权责、万应楼的转录和可能的付款中转都进入责任链；不能让桑执因为“经手归档”承担撬档和删页的全部责任。
- 章末钩子：损失榜自动新增一条，地下档案库成为下一层调查目标。
- 连贯性、文笔与枯燥风险：五行登记和“登记不等于定罪”很清楚；“留席”盘兽印的来源要与第341章仿镇邪司印、第345章归鹤旧名单分别核对，不能因印形相近自动视为同一枚印。

### 第341章《先看青州论道台的出口》

- 纯汉字数：2,155；破折号：0处。
- 剧情功能：从档案库和地下小室反向追查资金、封条和数据流，明确症状层、传导层、源头层三个故障源。
- 证据链：联盟账册中的“事故善后”改为“其他往来”、九条无去向款项、无编号仿镇邪司印、三十七张封口符、十一张撬痕、替换卷宗、三卷万应楼旧账、地下增补条和“我没结案、我还活着”。
- 冲突：齐望川要求公布旧档前先告知联盟，李无咎坚持由账本承担后果；账册写“已赔付、已结案”，地下增补条又写“此案未结”。
- 失败与代价：调查打开出口但没有找到写增补条的人；许青芜仍只以声音存在，真假赔付和户籍状态没有闭合。
- 责任落点：库房、空席和万应楼之间存在同一数据流，但正文尚未证明万应楼控制全部地下小室，也未证明仿镇邪司印来自镇邪司内部。
- 章末钩子：地下声音直接否认结案，空席灵息与增补条温度一致。
- 连贯性、文笔与枯燥风险：三层故障的结构有效；“三十七张封口符”与后文三种封口时间必须明确是不同轮次还是同一套物理封条的矛盾，列为P0/P1。

### 第342章《谁在证词里撒了谎》

- 纯汉字数：2,072；破折号：0处。
- 剧情功能：用三方都相信自己说的是真话，展示同一案件被不同档案时间切割，并把三卷万应楼旧账和归鹤批注带入问责核心。
- 证据链：封口符“三年前/去年秋/五个月前”三组日期、空席“两个月前/去年秋/今天”、损失榜“今早/三月底/午后”、桑执三卷编号、无回收凭证的转录记录、归鹤半个“权”字批注。
- 冲突：三种时间可以理解为不同封存、交接和修改阶段，但正文没有明确每个时间对应哪一轮物件；若它们指同一批三十七张物理封条，则存在硬冲突。
- 失败与代价：故意错误结论只逼出桑执的补充证词，没有查出谁撬封条、谁补榜、谁承担最终控制权；桑执还面临被人群推作弱责任人的风险。
- 责任落点：裴照夜明确反对无证据指控桑执；李无咎故意误述可以保留，但必须同时保留“误述可能把桑执推到围攻位置”的伦理风险。
- 章末钩子：归鹤半个“权”字把问责从档案流程接到师父批注，但批注未完成，不能作为完整授权或定责结论。
- 连贯性、文笔与枯燥风险：三组“三个时间”有悬疑效果，但若不补一处对象/轮次限定，读者会把它读成同一物件的三次互斥说法。

### 第343章《师父成长批注再次失控》

- 纯汉字数：1,988；破折号：0处。
- 剧情功能：让损失榜的旧数据在现场复现，证明榜单不是静态舆论；将归鹤批注从“师父预言”隔离为待核证物，并以文桐咳血把受害者重新带回现场。
- 证据链：回风山干土、药材商旧记忆回放、长老咳血、批注隔离区、榜单条目摘除、因果守恒数据、文家学馆风险记录和咳血现场。
- 冲突：摘掉一条榜单能停住一处症状，却让受益端土壤加倍；李无咎无法保证留榜或摘榜哪一边先伤及无辜。
- 失败与代价：局部摘榜不是修复，代价转到玄元宗受益端；文桐的新伤和旧风险被追加为“售后堂修补失当”，李无咎再次面对自己曾经留下“已告知、待加固”的责任记录。
- 责任落点：李无咎对曾经的风险告知和承诺负责，但榜单把“风险已告知”直接归成“售后堂失当”仍需核验；玄元宗是否属于回风山受益端也只到线索程度。
- 章末钩子：文桐倒下，纸卷上的地基风险记录和损失榜追加条同时出现。
