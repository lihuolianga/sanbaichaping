## 三、案件事实链与责任落点

```text
胜者榜出现游惊羽等不在千机院名册的人，封玄真家属确认十年前登顶后失踪
→ 铜牌编号、公开图纸和塔基灵纹证明存在高于十二层的第十三层夹层
→ 千机院代签归档，接引金册无本人签押自动登记，塔灵枢衡用锁链把真实胜者藏在塔内
→ 档案、告别字、金册和暗层证词的时间互相冲突，塔灵承认锁人是为阻止接引划走，但没有询问本人
→ 接引金册从考功台、军试场、问心台、邻州试场和私塾名册补录不存在的“胜者”，户籍和身份被擦除
→ 燕青崖带来自动改写名册的证据，归鹤旧字和天庭接引司“逃役”定性把案件接到师父旧案
→ 第一次修补隔离榜、封存金册、松开锁链并建立出口，却让接引网备用通道把压力转移到洛水试炼场八人
→ 李无咎撤回强制释放，宁知微逐人询问意愿，裴照夜核对权限，塔灵承认一半告别字由自己仿写
→ 时间线和七条因果线确认：协议、金册、塔灵、千机院和接引司都在替当事人做决定，没有人先问本人
→ 十四名被藏胜者按本人选择离开、留下、公开反抗或暂缓，锁链控制权拆分，档案和赔付公开
→ 接引金册“视为同意”、监察名单、洛水八人、备用通道和归鹤服役七载后除名仍未结清
```

责任不能压成“塔灵嫉妒天才”或“千机院一方造成全部失踪”：

- 千机院及历任管理者：长期用胜者榜维持塔誉、招生和资源，院印盖在代签归档文书上，现任院主闻津承继并享受了这笔账；其责任是制度维护、代签、隐瞒和受益，不等于单独设计天庭兵籍。
- 塔灵枢衡：确实把胜者锁在夹层，阻止部分人被接引划走，但未经同意藏人、仿写告别字、切断家属联系并扩展锁链到塔外；它既是保护者，也是未经授权替人决定者。
- 天庭接引司及接引金册：以“通过最高层即视为同意”自动编入兵籍，空白签押仍归档、追征并把人称为“逃役”或“损耗”；正文证明制度性征召和备用通道存在，但不支持在本案补出完整天庭幕后人物。
- 接引投影：执行金册和归档口径，把责任推向塔灵、千机院和售后堂；投影本身的权限、是否等同于接引司主体仍需保留证据边界。
- 李无咎、宁知微、裴照夜、铁算盘：分别承担受理、证据鉴别、权限封存和账目登记；李无咎第一次修补判断失误，不能因此承担旧制度和历史受益链的主要责任。
- 被藏胜者及家属：十四名胜者的选择不同，离开、留下、公开反抗和暂缓不能写成统一结果；家属因十年失踪和伪告别字承担真实损害，但不能被写成对征召制度的授权者。

## 四、逐章分析

### 第327章《试炼塔不放胜者：差评上门》

- 纯汉字数：2,412；破折号：0处。
- 剧情功能：以胜者榜上出现游惊羽、封玄真家属寻人和“第十三层”线索起案，确认“通过最高层试炼的天才失踪”不是普通失联。
- 证据链：胜者榜、封伯十年寻人告示、旧木桩刻名、游惊羽铜牌及丁未编号、公开图纸十二层、塔根旧木纹、接引金册投影、图纸背面的“旧层十三，封”和“勿登顶”。
- 冲突：李无咎要逐名核对，蒲冬以归鹤改过接引规矩推责，塔灵要求停止查询，接引投影建议按“逃役”注销未到册者。
- 失败与代价：本章尚未实施修补；封玄真等人继续被列为无下落，封伯十年的寻找被制度性“注销”二次伤害。
- 责任落点：受理首先落在胜者榜、塔灵、接引金册和千机院登记流程，不在封伯或失踪者本人；归鹤旧灵痕只证明关联，不足以证明他设计本案。
- 章末钩子：榜纸背面出现“第十三试，仅一人通关”，暗层“勿登顶”下还有人，调查从塔外进入隐藏结构。
- 连贯性、文笔与枯燥风险：榜纸、寻人告示、新米、木纹和裂纹把抽象制度落到具体物件上，起案清楚；“十年内木桩有11个名字”必须与第328章“14名通关者”建立统计对象或时间限定，P0。不得新增失踪者来填数字。
