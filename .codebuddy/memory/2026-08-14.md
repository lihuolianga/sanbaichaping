## 草稿ID时序坑（2026-08-14 补充，务必记住）
- **新坑：草稿ID异步生成，太早填标题会丢失**。点"新建草稿"后，新编辑页 URL 先是无 ID 的 `.../publish/?enter_from=newdraft`，约 1-2 秒后才变成 `.../publish/{草稿ID}?enter_from=newdraft`。如果在 URL 还没生成草稿 ID 时就填标题，"存草稿"后标题会丢失（草稿箱显示"未命名草稿"，正文却保存了）。
- **修复**（已写入 batch_upload.js）：①等编辑页时要求 URL 匹配 `/publish\/\d+/`（草稿 ID 已生成）才 break；②填标题后用 `titleSel.inputValue()` 校验，若为空自动重试（最多3次）。实测第1次填标题常失败（inputValue 为空），第2次重试成功。
- **教训**：任何"填表+保存"的自动化，填完后都要**回读值校验**，不能只点保存就以为成功（这次标题丢失就是没校验导致的）。batch_upload.js 现已内置标题回读重试。
