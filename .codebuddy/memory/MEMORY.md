- 第65章（案件5收尾结案）：火盆纸灰中归鹤三十年前烫金"再查一遍"浮出，指向沈宅照真镜案。七张伪造事故单编号归档，赵敬川四项因果、韩九章三项重分。赵敬川门槛铜钉未撤，不承认不等于不记录。封十娘为苏舟制新纸衣，用宁知微誊抄的病历副本作资料费，挂在纸匠铺价目表上方作来源警告。马厩石碑共鸣，沈鹤鸣名印挤出石缝："暂停调查不等于停止存在"。李无咎写售后日志，分已完成/未完成/不可逆损失/不可逆获得四类，宁知微添"不可逆获得"分类。裴照夜将日志纳入镇邪司档案编号TGH-005。陆承药教赵少衡封印阵识别（非修补），每三天用铜针量名印基准偏移。苏舟在归鹤"再查一遍"背面刮出"我活到了"，火盆纸灰掩金字等下一案有人来翻。因果簿翻到沈宅照真镜客户画像，沈家老夫人对镜，二房媳妇茶中下药，药粉包装九环缺一。案件5闭合差评1条。
- 第66章（案件6照真镜拆家开篇）：因果簿推照真镜差评至最前。封十娘借铜网，三十万道因果记忆作证人。裴照夜翻沈鹤鸣五年前拓片，镜背"念纹采样"三频符式：恐惧/恶意/羞耻，镜子分配机制被识别。整条巷搬空，门环贴碎镜。二房林氏被铜线隔离，承认三年前按老夫人要求安神散三钱增至五钱。镜中三十七道念头，筛选分频分配，真话在错误时机说出口。归鹤三年前符击切断第七兽，钥匙串与镜同炉铜，切镜断命，归鹤无法做完。碎镜自行生长新铜，第七兽被三十七人心念反向拼接，符式转向采样归鹤。镜中浮出飞升者最后一念：""概不负责""，不是推卸，是"我负不起所有，剩下的留给你们自己判"。李无咎首次面对"真话本身可能成为问题"。
- 第67章（受理书与老夫人自揭）：沈家老夫人沈余氏现身，手臂七道碎镜划痕，血渗镜缝铜与血置换复原。归鹤留备忘："此人不是不认错，是不认恐惧"。老夫人签受理书亲笔三行：割药方（怕被说"不会下蛋的母鸡"）、嫁丫鬟（怕女儿变成婆婆最恨的那种人）、承认钥匙攥在手心六十年。铜网以归鹤烫金频率倒逼镜子调低输出。镜模仿阿环声音"你不全，"。老夫人签小名"沈余阿嬷"。因果簿判：委托人自行写出全部责任清单→期限缩至一个时辰。林芷咬破拇指按碎镜入木，血字："五钱是我加的，我怕你死了就没有妈妈了"。第八兽开口不再是恶意，是你自己说了所以不是怕是爱。
- 第68章（三个故障源与铜讼堂到场）：李无咎用三根拆解针标出三处故障。第一针第七兽，符式内聚非断裂，归鹤切断发声但未阻止采样，三年三千七百万道念头堆成舌山推给第八兽。第二针林芷血中碎镜，检出外来源"讼钱"铜离子，铜讼堂私铸铜钱按大临律第二百一十三条合法吞产，林芷被动碰触杯底讼钱四十年即成合同条款。第三针老夫人钥匙串，账房钥匙被拧偏45度，钱如命三十年每月从后门跑铜讼堂交沈家账单，女儿嫁入铜讼堂作报酬，铜丝屏风精确阻断镜子采样。三个故障源：符式内聚/外部契约/内部渗透。章末讼师到场，指甲刮碎镜千分之一寸="到场确认"，六字四停顿"请，现场，开，门"，讼钱刻"收"。
- 第69章（钥匙串失控与因果守恒）：宁知微算出全量输出，三十七人六十年二百四十万道念头，一个时辰全量同时，中位数二十八人胸骨裂。钱如命不在崩溃名单，用屏风挡自己三十年零上传，赌房子归自己。钥匙串三针悬架隔离节点，同炉铜共振触发归鹤三层铜器设计，后门锁芯自弹反锁。五息内大房媳妇听见"推孩子"，三房丈夫听见"外面有儿子"，豆腐坊老板娘听见"偷听三年多收两文"。讼钱自裂铜心刻名"沈余氏"曝光。第六息铜网替代钥匙串，冒三十万道记忆烧毁风险，铜晶格分频筛重新分配。大房媳妇贴半张脸入镜，铜皮换人皮，继承九环血丝，铜脸映出丈夫自白"推的不是孩子是你"。讼师铜心裂后听见"讼棍是帮坏人抢好人房子的"，他也有女儿。章末阿环三十里外停下，握铜簪刻"回来"，转身往回跑。
