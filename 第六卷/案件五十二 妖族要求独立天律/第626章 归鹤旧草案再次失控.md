# 第626章 归鹤旧草案再次失控

归鹤的旧草案被翻出来之后，规则冲突就失控了。

先是虎族。虎族的契纸上，成年标准那一栏，涂改的痕迹，又深了一层——像是有人，还在改。然后是狐族。狐族的契纸上，成年标准那一栏，也多了新的涂改。然后是蛇族、狼族、鹿族——百族的契纸上，成年标准，都在被涂改。

"规则在自动改。"宁知微蹲在百族台的档房里，脸色发白，"百族的成年标准，都在被涂改——改一次，规则就换一套。规则换一套，跨族纠纷就判一次。"

"规则在自动改？"李无咎问。

"是。"宁知微说，"像是……像是有一套自动的规则，在按'一刀切'的方案，把百族的成年标准，往一套上改。改得越多，百族的差异被压得越平。"

"一刀切的方案，在自动执行？"李无咎说，"那这套自动执行的方案，是归鹤那卷草案？"

"像是。"宁知微说，"可归鹤批注'慎用'——他不想让这套方案执行。可它，还是自动执行了。"

"那这套自动执行的方案，是谁启动的？"李无咎问。

"不知道。"宁知微说，"草案是归鹤提的——可草案放在档房里，怎么会自动执行？像是……像是有人，把草案的规则，接进了百族的契纸里。契纸连着一刀切的规则——规则就自动改了。"

"有人把草案的规则，接进了百族契纸？"李无咎说，"那接的人，是谁？"

"不知道。"宁知微说，"我只核到——百族契纸的改动，用的术式，是同一套。像是……像是有人，把规则接进了契纸，让它自动跑。"

"李先生！"台下，又传来喊声。一个妖跑上来，脸色发白："李先生，虎族少主——虎族少主，方才又伤了一个狐族的孩子！他咬断了那孩子的胳膊——他说，按虎族规矩，他三岁成年，正当防卫！"

"又伤了？"李无咎冲到台下。虎族少主站在台边，嘴里还叼着一块血布。他五岁，按虎族规矩三岁成年——可他的眼神，不像是成年妖的眼神，更像一个被规则裹着走的孩子。

"虎族少主，"李无咎蹲下来，"你五岁。你咬人，是你自己想咬，还是规则让你咬？"

虎族少主愣了一下："我……我三岁就成年了。成年妖，守领地，天经地义。他闯进我的领地，我咬他，天经地义。"

"你三岁成年，守领地，咬人天经地义。"李无咎说，"那这'天经地义'，是你自己想的，还是有人告诉你的？"

"是……是族里的规矩。"虎族少主说，"虎族三岁成年，成年妖守领地。这是老规矩。"

"老规矩。"李无咎说，"可你的老规矩，被改过。虎族原来三岁成年，后来被改成十八岁——你五岁，按改过的规矩，你是未成年。你咬人，不是'天经地义'，是'未成年伤人'。"

虎族少主愣住了："我……我未成年？"

"按改过的虎族规矩，你未成年。"李无咎说，"你五岁，未成年——你咬人，不是成年妖守领地，是孩子伤了人。"

"李先生！"台下，又传来喊声。一个妖跑上来，脸色发白："李先生，狐族的杪——杪的腿，又疼了！这次，他疼得晕过去又醒过来——他说，他的成年，被人改来改去——改一次，他疼一次！他疼得受不了了！"

"孩子的成年，被人改来改去。"宁知微的脸色发白，"李先生，杪的疼，是规则的疼——规则改一次，他疼一次。规则不改，他就不疼。可规则，一直在改。"

"规则一直在改。"李无咎说，"那谁能让它停下来？"

"不知道。"宁知微说，"规则是自动的——它按一刀切的方案，把百族的成年标准往一套上改。改得越多，百族越疼。"

"李先生！"偏厅外，又传来喊声。一个妖跑进来，脸色惨白："李先生，老朽在百族台的档房里，又翻出一卷东西——是一份风险听证的记录！记录上记着——几十年前，有一场风险听证，主持听证的人，叫——叫宁知微！"

"宁知微？"李无咎一愣，看向身边的宁知微。

宁知微的脸色也变了："我的名字？几十年前的风险听证？"

"是。"妖说，"记录上写——风险听证，主持者，宁知微。听证的内容是——评估一刀切方案的风险。记录的最后，有一行字——'方案风险过大，建议中止。'"

"几十年前，宁知微主持过风险听证？"李无咎说，"可宁知微，你才多大？几十年前，你还没出生吧？"

"是。"宁知微说，"我今年二十出头。几十年前，我还没出生。这个'宁知微'，不是我。"

"不是你？"李无咎问。

"不是我。"宁知微说，"可我的名字，出现在了风险听证的记录上。像是……像是有人，用了我的名字。"

"用了你的名字？"李无咎说，"几十年前，有人用你的名字，主持了一场风险听证，建议中止一刀切方案——可方案，还是执行了。"

"李先生！"偏厅外，又传来喊声。一个妖跑进来，手里捧着一卷旧档，脸色发白："李先生，老朽核了那卷风险听证的记录——记录上，主持听证的人，写的是'宁知微'。可记录的笔迹，不是一个人的——像是两个人写的！"

"两个人写的？"李无咎问。

"是。"妖说，"记录的前半段，是一个人的笔迹；后半段，是另一个人的笔迹。像是……像是主持听证的人，中途换了。"

"中途换了？"宁知微的脸色变了，"那后半段，是谁写的？"

"老朽核了笔迹——"妖说，"后半段的笔迹，和归鹤旧草案的笔迹，是一样的。"

"归鹤？"李无咎说，"风险听证的前半段，是'宁知微'主持的；后半段，是归鹤写的？"

"像是。"妖说，"像是……像是那个叫'宁知微'的人，主持了前半段听证；归鹤，接手了后半段。"

"李先生！"台下，又传来喊声。一个妖跑上来，脸色发白："李先生，虎族少主——虎族少主方才，又咬了人！他咬的是——他咬的是他自己！他说，他不知道自己该不该咬人——他咬了自己一口，问自己疼不疼！"

"虎族少主，咬了自己？"李无咎冲到台下。虎族少主蹲在台边，嘴角带血，眼神茫然。他五岁，按虎族规矩成年，按改过的规矩未成年——他被规则改来改去，改得他不知道自己是谁，改得他咬了自己一口。

"我……我到底算不算成年？"虎族少主抬起头，看着李无咎，声音发颤，"我三岁成年，是族里的规矩；十八岁成年，是天律的规矩。我被改来改去——改得我不知道，我到底算不算成年。"

"李先生，"宁知微的声音发紧，"一个五岁的孩子，被规则改来改去，改得他不知道自己算不算成年——这不是规则冲突，这是规则，在咬孩子。"

"虎族少主，"李无咎蹲下来，看着他的眼睛，"你五岁。你咬自己——是你自己想咬，还是规则让你咬？"

"我……"虎族少主愣了一下，"我咬自己，是想问自己疼不疼。我咬了，我疼。我疼，我就知道——我咬人，别人也疼。可我不知道，我该不该咬人——族里说该咬，天律说不该咬——我被改来改去，改得我不知道，该听谁的。"

"你不知道该听谁的。"李无咎说，"那你先别听谁的。你先记住——你咬人，别人疼；你咬自己，你也疼。疼，是你自己的。规则改来改去，可疼，是真的。"

"疼……是真的？"虎族少主问。

"是真的。"李无咎说，"规则改来改去，可疼不会假。你咬人，别人疼；你咬自己，你疼。这疼，是你自己的——谁也改不掉。"

"那小人……"虎族少主抬起头，"小人以后，该听谁的？"

"先听你自己的疼。"李无咎说，"你疼，你就知道——别人也疼。你先记住疼，再谈听谁的。规则改来改去，可疼是真的——你跟着疼走，不会错。"

"小人……记住了。"虎族少主说，"小人先记住疼。规则改来改去，小人不听了——小人先听疼。"

风从百族台的方向吹过来。虎族少主蹲在台边，嘴角带血，眼神茫然。而台下，那个断腿的狐族孩子杪，正疼得直哭——像是整座百族台的规则冲突，又一次，落到了两个孩子的身上。
