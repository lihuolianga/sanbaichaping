# 第619章 无名妖城真正的故障

"名印可藏，不可无"这句话，让李无咎把因果图画了出来。

画图是在议事厅进行的。李无咎把沈见川的无脸印、第一张妖城公民证、烧名册灰、无法落款的契约、井壁的刻字、匾额里浮现的名字，全部铺在案上，用墨斗线连成一张大图。

"这张图，是本案的因果图。"他说，"几百年前，栖霞的妖，为了躲追杀，烧了名册，改叫无名城。这是起点。无名，最初是生存策略——城民躲过了追杀。这是第一层。可无名，让城民签不了契约，出不了城，得不到承认。这是第二层。沈见川设计了名印——'可隐藏'的名印，让城民能藏，能隐，也能落款。这是第三层。九霄户籍司，把沈见川的'可隐藏'，改成了'强制无名'——城民不能落款，不能出城，被永久排除。这是第四层。无脸印，把这个排除，扩大到了城门、石炉、契约。这是结果。"

"李先生，您这图，画得清楚。"狐老说，"可画清楚了，有什么用？"

"画清楚了，才知道谁在哪个位置。"李无咎说，"沈见川，设计了名印——他要认。九霄户籍司，把'可隐藏'改成'强制无名'——它要认。杜户籍使，执行了强制无名——他要认。城民，烧了名册，躲了追杀，也维持了无名——他们要认。归鹤，曾试图中止——他要认，可他没中止成。"

"那沈见川，是好人还是坏人？"药婆问。

"都不是。"李无咎说，"沈见川设计了名印，本意是让城民可藏可隐。可他的设计，被九霄户籍司改了——'可隐藏'成了'强制无名'。他设计了保护，也设计了监管的风险。他参与设计，就要为设计带来的后果负责——可他设计的是'可隐藏'，不是'强制无名'。责任，要按他设计了多少、九霄改了多少来分。"

"李先生，"裴照夜开口了，"末将核了沈见川的设计记录。沈见川设计名印的时候，在记录上，写了一句——'名印可藏，不可无。脸可隐，不可丢。'他设计名印，是让城民能藏，不是让城民没有。"

"他设计名印，是让城民能藏。"李无咎说，"可九霄户籍司，把他的名印，改成了'强制无名'。他设计的是保护，九霄改成了排除。"

"李先生，"杜户籍使开口了，声音有些发虚，"在下要说一句。九霄户籍司，把名印改成'强制无名'——在下不知道。在下只是执行。在下执行的时候，以为名印制度，就是让城民无名。"

"那你现在知道了？"李无咎问。

"知道了。"杜户籍使说，"沈见川设计名印，是让城民能藏能隐。九霄户籍司改成'强制无名'，是把城民彻底排除。在下执行了三十年——在下执行的是被改过的制度。在下的执行，把城民关在城外三十年。"

"那你觉得，"李无咎说，"你执行了三十年'强制无名'——这个责任，你该认多少？"

"在下……认。"杜户籍使说，"在下执行了三十年，把城民排除在制度外。在下认这个责任。可在下也想说——在下执行的时候，真的以为，那是制度。在下不知道，制度被改过。"

"你不知道制度被改过，可你执行了。"李无咎说，"执行的人，可以不知道制度被改过——可执行的人，不能不知道城民被排除。你看着城民签不了契约，出不了城，三十年——你只要看过一眼，你就知道，这制度有问题。你看了三十年，你没问。"

杜户籍使没有再说话。

"你执行的时候，以为名印就是让城民无名？"李无咎说，"杜户籍使，你执行了几十年。几十年里，你有没有核过，名印的本意是什么？"

杜户籍使沉默了很久："……没有。在下只是执行。"

"你只是执行。"李无咎说，"执行的人，不核本意。可执行的人，要认执行的后果。你执行了'强制无名'——城民被你排除了几十年。这份责任，你逃不掉。"

"李先生，"杜户籍使低下头，"在下认。"

"李先生！"议事厅外，一个城民跑进来，手里捧着一卷旧档，脸色发白："李先生，老朽在城北的废墟里，又翻出一卷档！档上记着——记着沈见川的身份！"

"沈见川的身份？"李无咎接过旧档。档是旧的，边角卷了。他翻开看，档上记着——"沈见川，无面者，西荒隐者。善设计名印、契约、身份。曾为无名城设计名印，为九霄户籍司顾问。后隐居，行踪不明。"

"无面者。"李无咎重复了一遍这三个字，"沈见川，是无面者。"

"是。"城民说，"档上写——沈见川是西荒的隐者，善设计名印。他为无名城设计过名印，也为九霄户籍司当过顾问。可后来，他隐居了，行踪不明。"

"他为无名城设计名印，也为九霄户籍司当顾问。"李无咎说，"那九霄把名印改成'强制无名'，他知道吗？"

"不知道。"城民说，"档上只记到这里。沈见川隐居之后，就没再出现过。"

"沈见川设计名印，然后隐居。"李无咎说，"他设计的是'可隐藏'——可九霄改成了'强制无名'。他隐居了，没看见自己的设计被改成什么样。他设计了保护，保护被改成了排除——而他，不知道。"

"李先生，"裴照夜说，"末将想问——沈见川设计名印，是他自己决定的，还是九霄请他的？"

"档上写——他为九霄户籍司当过顾问。"李无咎说，"那他的设计，可能一开始，就是九霄请的。九霄请沈见川设计名印——可九霄请的是'可隐藏'的设计，还是'强制无名'的设计？"

"不知道。"裴照夜说，"末将只能核到——沈见川的设计，是'可隐藏'。九霄户籍司的执行，是'强制无名'。中间的改动，是谁做的，末将没核到。"

"李先生！"议事厅外，又传来喊声。一个城民跑进来，手里捧着一卷纸，脸色发白："李先生，有人在城门缝里塞了一卷纸进来——纸上写着一行字！"

"什么字？"李无咎接过纸。纸上写着一行字，字迹工整，像是刻的："若见无名城，请告城民——名字是权利，不是控制。可藏，不可无。可隐，不可丢。落款：沈见川。"

"沈见川的留字？"李无咎看着那行字，"他留了字，请人转告城民——名字是权利，不是控制。"

"李先生，"宁知微的声音有些紧，"这份留字，是新的——墨迹刚干。像是……像是沈见川，刚来过。"

"沈见川，刚来过？"李无咎冲到城门口。城门外，空荡荡的——没有人。他回头，看着那卷留字，沉默了。沈见川设计名印，然后隐居；可今天，他留下了这行字——像是他回来了，看见了什么，留下了这句话，又走了。

"李先生，"宁知微忽然开口，她手里捧着一卷契约——是那份无法落款的契约，"我核了这份契约。契约的纸边，有一行极小的字，被墨盖着。我今天，才看见。"

"什么字？"李无咎问。

"写的是——'若此契无法落款，则制度已病。宜查名印。'落款处，是归鹤的名字。"

"归鹤？"李无咎接过契约，看着那行小字。归鹤，在无法落款的契约上，留了一行字——"若此契无法落款，则制度已病，宜查名印"。他看见过这份契约，他留下过这句话。可他，也没有中止。

"归鹤留了话，没做成。"宁知微说。

"是。"李无咎说，"归鹤留了'制度已病，宜查名印'——可他没查。他留了话，走了。这句话，压在契约的纸边，压了几十年，等一个后来人，把它翻出来。"

"李先生！"城门口，忽然传来一阵骚动。一个城民跑进来，脸色发白："李先生，城门上那枚无脸印——它停了！不转了！它像是——像是在听！"

"在听？"李无咎冲到城门口。那枚悬在城门上方的无脸印，果然停住了——不转，不动，像是被什么定住了。李无咎看着它，忽然想起——它停住的时刻，正是宁知微念出"若此契无法落款，则制度已病，宜查名印"的时候。

"它在听那句话。"李无咎说，"归鹤那句'制度已病，宜查名印'——无脸印，在听。"

"李先生，"宁知微的声音有些发紧，"无脸印是沈见川的。它听归鹤的话——说明，沈见川和归鹤，可能认识。"

"沈见川和归鹤，可能认识。"李无咎重复了一遍。他看着那枚停住的无脸印，又看了看案上那张因果图。图上，沈见川、归鹤、九霄户籍司、杜户籍使、城民——每一个位置，都站着一个人。而图的中心，那枚无脸印，停住了，像是整个案子的枢纽，正等着，下一个名字，被念出来。
