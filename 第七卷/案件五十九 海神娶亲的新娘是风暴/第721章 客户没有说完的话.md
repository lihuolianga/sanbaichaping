# 第721章 客户没有说完的话

几百个岛的新娘名印都被抹了，这让李无咎把所有人都叫到了庙前的棚子里。这一次，他问的不是证词，是把没说完的话，说完。

"风伯。"他先看向风伯，"送新娘的规矩，你知道多少？"

风伯沉默了很久："……小人知道，每年风季前要送一个新娘，送了风暴就弱，不送风暴就吞岛。"

"你知道要送新娘。"李无咎说，"那你知不知道，新娘被送进庙之后，去了哪？"

"……不知道。"风伯说，"小人只知道，送了新娘，风暴就弱。小人没问过新娘去哪。小人也不敢问。"

"你没问过新娘去哪？"李无咎说，"那你知不知道，新娘的名字，会被从族谱上划掉？"

"知道。"风伯说，"这是规矩。送了新娘的人家，女儿的名字，从族谱上划掉。"

"你知道名字会被划掉？"李无咎说，"那你知不知道，名字被划掉，意味着什么？"

"意味着……"风伯说，"意味着，她嫁给了海神。她不再是凡人了。"

"她不再是凡人了？"李无咎说，"还是——她从所有人的记忆里，消失了？"

风伯愣住了。他张了张嘴，没说出话。

"李先生！"人群里，一个中年妇人站出来，声音发抖："小人知道！小人知道新娘去了哪！小人的姐姐，四十年前，被送进了庙！小人一直没敢说——可小人知道，姐姐没有嫁给海神！小人看见过——姐姐被送进庙的那天晚上，有船来接她！"

"有船来接她？"李无咎说，"什么船？"

"是……"妇人说，"是岛主家的船。那天晚上，小人躲在礁石后面，看见姐姐被送进庙。然后——岛主家的船，靠了岸。船上下来几个人，把姐姐，接上了船。船开走了——姐姐，再也没回来。"

"岛主家的船，接走了新娘？"李无咎说，"那新娘不是嫁给海神——是被岛主家接走了？"

"是！"妇人说，"小人一直不敢说。小人怕说了，岛主家也把小人送走。可小人记得——姐姐被接走的时候，穿着嫁衣，哭了一路。"

"李先生！"人群里，又有人喊起来，"小人也有话说！小人是岛上的渔夫。小人看见过——每年风季前，岛主家的别院，都有人来！他们来挑姑娘——挑名字里带水的姑娘！挑走了，就说是海神看中了！"

"岛主家挑姑娘？"李无咎说，"挑名字带水的姑娘？"

"是！"渔夫说，"小人看得真真的。别院的人，拿着名册，一家一家地看。看到名字里带水的姑娘，就做记号。然后，祭司就上门——说海神看中了她。"

"祭司上门，说海神看中了她？"李无咎说，"那挑姑娘的名单——在岛主家？"

"在。"渔夫说，"小人在别院打扫过。别院的书房里，有一本名册——上面记着沿海几百个岛，名字带水的姑娘。每一个，都做了记号。"

"几百个岛的名字，都在岛主家的名册上？"李无咎看向岛主，"岛主，那本名册，是怎么回事？"

岛主的脸色，已经白了："……小人……小人不知道什么名册。"

"不知道？"李无咎说，"可岛上的人说，别院的书房里，有一本名册。渔夫在别院打扫过——他见过。"

岛主低下头，不说话。

"李先生！"人群里，祭司开口了，"贫道有话要说。贫道知道祭祀有风险。可贫道不知道——新娘被送到哪去了。贫道以为，她们嫁给了海神。贫道没想到——她们是被岛主家的船接走的。"

"祭司知道祭祀有风险，可不知道新娘去哪？"李无咎说，"那祭司，你主持了这么多年祭祀——你知不知道，新娘被献祭之后，名字会被抹掉？"

"贫道知道。"祭司说，"贫道以为，这是规矩。贫道不知道——名字被抹掉，是有人故意的。"

"你知道名字被抹掉，可你不知道谁抹的？"李无咎说，"你知道祭祀有风险，可你不知道风险落在谁身上。你知道新娘被送进庙，可你不知道她们去了哪。祭司——你知道的，和不知道的，得分清楚。"

"李先生！"人群里，一个老渔民站起来，声音发抖："小人知道新娘去了哪。小人不是岛上的——小人是别处来的。小人年轻的时候，在岛上做过船工。小人看见过——岛主家的船，把新娘送到海那边的'新地'。那里，有田，有房——新娘被送到那里，嫁给了别处的男人。"

"新娘被送到新地，嫁给别人？"李无咎说，"那她们不是被海神收走——是被岛主家，卖到了新地？"

"是！"老渔民说，"小人亲眼看见。新娘穿着嫁衣被送到新地，那里的男人付了银子，岛主家收了银子。新娘的名字从族谱上划掉——因为，她已经卖到了别处。"

"新娘被卖了？"李无咎的脸色，沉下来，"那'海神娶亲'——是岛主家卖姑娘的幌子？"

"是。"老渔民说，"小人不敢说。小人怕岛主家报复。可小人看得真真的——岛主家，每年卖新娘，收银子。祭祀是幌子——卖人是真事。"

"李先生！"人群里，又有人喊起来，"那迁居费呢！迁居费也是幌子！岛主家收了迁居费，说是给风暴要淹的人迁居——可银子，都进了别院！路是断的——因为没人修！"

"李先生！"庙前，又传来喊声。一个渔民跑进来，脸色惨白："李先生，风暴眼——风暴眼里的声音，又变了！它不喊'阿苇'了——它开始说话！它说——它说，'他不是海神。海神，是岛主家编的。'"

"风暴眼说，海神是编的？"李无咎冲到海边。风暴眼里，那道女声，正一声一声地说："海神是编的……岛主家编的……祭司帮着编……我们，是卖出去的……"

"风暴眼说，新娘是被卖出去的？"李无咎说，"那这声音——是哪个新娘的？"

"不知道。"宁知微说，"可她说的话——和船工说的，对上了。新娘被卖到新地，名字被抹掉。海神娶亲，是幌子。"

"李先生！"庙前，又传来喊声。一个渔民跑进来，脸色惨白："李先生，归鹤的旧劝告——旧劝告上，又浮现出一行字！像是归鹤后来加上的！"

"什么字？"李无咎问。

渔民念出来："'我曾劝，勿以少女祭风。未果。我曾记，少女之名于碑。碑被磨。我曾留，此劝告于庙。庙被移。我未能止此祭祀——唯愿后来者，知其非神，是为人害。归鹤，留。'"

"归鹤留的字？"李无咎说，"他说——他劝过，没成；他记过名字，碑被磨了；他留过劝告，庙被移了。他没能止住祭祀——他希望后来者知道，这不是神，是人为。"

"归鹤知道这是人为？"宁知微说，"他劝过，记过，留过——可他都没成？"

"像是。"李无咎说，"归鹤做过的，都留下了痕迹。可他没做成的——祭祀还在继续，卖人还在继续，名字还在被抹。他没能止住——这账，也要记。"

"李先生！"人群里，阿岚的爹娘站出来。老人的声音发抖："李先生，小人要说——小人当年送阿岚进庙，是因为怕风暴。小人不知道，阿岚是被卖出去的。小人要是知道——小人拼了命，也不会让女儿被卖。"

"你不知道阿岚是被卖的？"李无咎说，"那你——你送她进庙的时候，信的是什么？"

"小人信的是海神。"老人说，"小人信，送了女儿，风暴就弱，全岛就平安。小人不知道——海神是编的。小人不知道——女儿是被卖掉的。小人……小人对不起女儿。"

风从海岬上吹过来。风岬群岛里，新娘被卖的故事，一句一句拼出来；归鹤没做完的事，一桩一桩摆出来。像是这座每年送新娘的群岛，正从"谁撒谎"的争吵，走向"谁有权替别人决定命运"的清算——而真正的主使，正在那本几百个岛的名册后面，等着被揪出来。
