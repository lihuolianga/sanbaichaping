# 第517章 客户没有说完的话

第四天傍晚，李无咎把赵满堂、钱百万、骨三、骨老单独请到了正殿。他把会自己称骨的秤摊在案上，把田七梦里那句"愿先问价，价问谁收"记在最后，然后看着几个人，问了一个他一直没有问的问题。

"你们是什么时候知道，愿望的代价会落到陌生人身上的？"李无咎说，"你们什么时候知道，白签上没有代价栏，代价是秤自动称定的？"

殿里安静了很久。

钱百万先开了口。他低着头，声音很轻："小人……小人一直知道。"

"你知道？"李无咎说，"你知道代价会落到陌生人身上？"

"小人知道有代价。"钱百万说，"小人许愿升官的时候，庙祝告诉小人，愿望有代价，但可以免。小人加了钱，免了代价。小人以为，免了代价，小人就不用付了。小人不知道，免掉的代价，会落到别人身上。"

"你加了钱，免了代价。"李无咎说，"你免掉的代价，落到了别人身上。你花钱，把代价转给了别人。"

"小人不知道会落到别人身上。"钱百万说，"小人以为，免了，就没了。"

"你以为免了，就没了？"李无咎说，"代价不会没，它只会转。你花钱免了，它转到了书生腿上。你的官，是书生的腿换的。"

钱百万没有接话。

赵满堂坐在另一边，手放在膝上。他开口时，声音带着压抑的沉："李先生，小人……小人不知道。"

"你不知道？"李无咎说，"你许愿的时候，庙祝给你看过一张附录，上面写着'愿望必成，代价另计'。你看过。"

"小人看过。"赵满堂说，"但小人没细看。小人只想着，愿望能成，丰收能来。小人没想过，代价另计，是另算在小人身上。"

"你看了'代价另计'，没细看。"李无咎说，"你许愿的时候，想着丰收。你没想代价。你不知道代价会落到你腿上。"

"小人不知道。"赵满堂说，"小人要是知道，小人就不许了。"

"你许愿，是想要丰收。"李无咎说，"你的愿望实现了，代价落到了你腿上。你不知道代价会落到自己身上，但代价，还是落了。"

骨三坐在案前，手放在桌上。他开口时，声音带着压抑的沉："李先生，老朽……老朽知道。"

"你知道？"李无咎说，"你收免代价的钱，你知道代价会落到别人身上？"

"老朽知道。"骨三说，"老朽收了钱，知道免掉的代价，会落到别人身上。老朽没说。老朽想着，庙里多点香火钱，信众的愿望能成，是好事。"

"你收钱，知道代价落到别人身上。"李无咎说，"你想着庙里多点钱，信众愿望能成。你没想，代价落到别人身上，别人愿不愿意。"

骨老坐在旁边，声音很低："老朽也知道。老朽改过白签，把代价栏去掉了。老朽以为，去掉代价栏，信众就不会怕了。"

"你改白签，去掉代价栏。"李无咎说，"你以为信众不会怕。但你去掉的，不是信众的怕，是信众的知情。他们不知道代价，他们没得选。"

他把铁算盘叫过来，把"知情时间"记下来："钱百万，知愿望有代价，加钱免代价，不知代价落到谁身上。赵满堂，见'代价另计'未细看，不知代价落自己身上。骨三，收免代价钱，知代价转移，未言。骨老，改白签去代价栏，知代价转移，未言。分四条记。"

铁算盘拨了两下珠，声音沉下来："李先生，知情登记要拆开。钱先生知道有代价，不知道具体受害者，这是'知道有风险，不知具体受害者'。赵先生见'代价另计'未细看，不知道代价落自己身上，这是'知情未细看'。骨庙祝收钱，知道代价转移，未言，这是'知情且受益'。骨老改签去代价栏，知道代价转移，未言，这是'知情且维护'。四笔账，深浅不同。"

"知道有风险，知情未细看，知情且受益，知情且维护。"李无咎说，"四笔账，分开算。钱百万花钱免代价，把代价转给别人；赵满堂看了代价另计没细看；骨三收钱受益；骨老改签维护。他们都知情，责任都跑不掉。"

"李先生。"孙二站在门口，开口了，"小人想问，小人许愿病好，小人是'知道有风险'还是'知道具体受害者'？"

"你是知道有风险。"李无咎说，"你病好了，你不知道代价落到谁身上。你不知道邻村孩子得了你的病。你病好，孩子病重。你是受益者，也是不知情者。"

"小人受益了，小人不知道代价落到孩子身上。"孙二说，"小人的病好，是用孩子的病换的。小人的罪，怎么算？"

"你的罪，是受益不知情。"李无咎说，"你病好，是真的。孩子病重，是真的。你受益，你不知道代价落到孩子身上。你不是故意害孩子，但你受益了。你受益的，要认；孩子的病，要补偿。"

"小人认。"孙二说，"小人的病好了，小人的药钱，小人退回去，给那个孩子看病。"

"你退药钱，给孩子看病，是你的选择。"李无咎说，"你的选择，记下了。但你要知道，退药钱，是止损；孩子的病，可能好不了。你的补偿，要够孩子治好病，够孩子一家过活。"

"小人知道了。"孙二说，"小人会补偿，一直到孩子好。"

"李先生。"赵氏也站在门口，说，"民妇想问，民妇的男人断了腿，民妇能告白骨庙吗？"

"能。"李无咎说，"你男人的腿，是白骨庙的代价系统断的。你告白骨庙，是你的权利。告下来，庙要赔，许愿的人要赔，受益的人要赔。你的男人断了腿，他的账，要有人认。"

"民妇要告。"赵氏说，"民妇要告到，民妇男人断的腿，有人认账。"

正殿外，人群的声音忽然变了。不再是议论，而是有人喊："庙祝骗人！愿望有代价，收了钱，代价落到别人身上！""钱百万，你升官，书生断腿，你该受罚！"

李无咎走到正殿门口。免代价的事传出去了，人群知道了愿望有代价，知道了钱百万加钱免代价，知道了骨三收钱。人群里有人举着牌子，牌子上写着"还陌生人公道"，也写着"抄了钱百万"。

"抄了钱百万！"有人喊，"他升官，书生断腿，他该罚！"

"抄了钱百万。"李无咎走到人群前，"你们让抄钱百万，抄完了呢？"

"抄完再说！"有人喊，"先把他拿下！"

"拿下钱百万，愿望白签还在。"李无咎说，"白签是秤写的，秤是契台定的，契台连着天庭的功德转账。你们拿下钱百万，白签不废，下一个许愿的人，还会加钱免代价，还会让陌生人断腿。你们让钱百万一个人认，是让一个受益的，认整个系统。系统要拆，账要核，核到谁，谁认。"

他走回正殿，让四个人把隐瞒的选择写下来。他说："你们四个，一个花钱免代价，一个没细看，一个收钱受益，一个改签维护。你们的账，要单独核。你们知道了什么，隐瞒了什么，都要摊开。摊开之前，代价不能再落到陌生人身上，这是另一条线。"

"李先生。"钱百万问，"代价能不落到陌生人身上吗？"

"能。"李无咎说，"代价的转移，要公开。每个愿望的代价，要让许愿者知道，让受影响者知道。代价不能随机转移，要有告知，有撤回，有追偿。你们把知道的事摊开，代价的转移，先停。"

就在这时，愿望白签忽然亮了。亮起的签上，浮现出一行字。字迹不是秤写的，是另一只手写上去的，笔画很淡，像写的人犹豫了很久。字的内容是："愿先问价，价问谁收。未问者，不得许愿。"

"这行字，不是秤写的。"宁知微的声音发紧，"是另一个人写的。他写'愿先问价'，写'价问谁收'，写'未问者，不得许愿'。"

"写这行字的人，想改白签。"李无咎说，"他想让愿望先问价，让代价的承受者知道。他没写成。他的字，只留在签上，没有生效。"

"又是归鹤。"裴照夜说，"他想把'愿望先问代价'写进白骨庙，没写成。他留下这行字，但他的改签，没完成。"

李无咎看着白签上那行字。他知道，那是归鹤写的。归鹤想改白签，想让愿望先问价，没写成。他试图中止代价转移，留下"未问者，不得许愿"的警告，但没完成。他没有洗清自己参与或接触这套系统的责任，但他留下一行字，告诉后来的人：愿望，应该先问代价。他试过，没走完。
