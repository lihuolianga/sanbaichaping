# 第21章 青炉谷第七号丹房

青炉谷名义上是个药谷，实际更像一座由丹房与药市堆叠而成的小城。从山脚到谷顶分布着四十八座丹房，按药性五行分六个区。第七号丹房建在水区与木区交界处，药性与方位相生相克，专炼偏性丹药。

宁知微对这一带很熟。她四年前在第六号丹房做学徒，每天傍晚煎完药就靠在窗口往外看，能看到隔壁第七号丹房的炉烟。归鹤的丹炉烧得最勤，常常从傍晚烧到凌晨。她看着他被逐出丹房那天，四年前的正月十五，四个谷中执事搬走了他的实验样本，封了炉。归鹤站在洞口没进去。他手上还捏着一页写到一半的丹方。

陆承药已经在第七号丹房洞口等着了。老药师手里拿着谷主刚批下来的临时启封令，推了推鼻梁上的铜框眼镜。

“你们来得比我想的晚。我以为宁姑娘会在木化第一年就来找我。”

“第一年我只想自己验。”宁知微说，“第二年我开始追副印。第三年追到养护合约。第四年才追到归鹤的实验记录，他的备注里写的第七号丹房炉底残灰。”

“因为归鹤故意把线索分成四层。你先碰到哪一层，就得先把那一层的问题查完。”陆承药撕下封条，铁栅栏往后推开，洞窟深处涌出一股淡淡的焦味，木属性灵火灼烧后特有的气息，混着四年积累的灰尘。

第七号丹房的炉膛是空的。没有丹药，没有药材，只有厚厚一层灰白色炉灰。宁知微伸手摸了一下炉壁，灰是温的。温度极低，但持续了四年没有熄灭。归鹤在封炉前留了一道微弱的维持术法，把炉温保持在随时可以续炼的状态。

陆承药打开一本被火烧过边角的实验记录。

“归鹤当年在第七号丹房做了十一组对比实验。前六组用正常百年灵芝做对照，后五组用韩九章提供的药引样本。前六组正常。第五组开始异常，韩氏药引在丹火灼烧后释放的灵气频谱中出现了一个不该出现的峰值。他用红笔在峰值旁边标注：‘千年木灵根特征峰。该药引并非灵芝，疑似经过伪装处理的古树根屑粉末。’”

“他报告了没有？”

“写了。但没交。”陆承药翻到封底内侧，一行小字写在装订线边缘，“他在准备提交的前一晚，第七号丹房失火。火烧得不大，只烧掉了他办公桌和半柜实验样本。第二天谷主以安全隐患为由封了炉。归鹤被暂停进入青炉谷一切丹房的权限。”

“这把火是谁放的？”

“青炉谷的正式调查报告是‘炉火操作不当引发’。但我在炉壁靠办公桌那一侧的砖缝里发现了这个。”陆承药递上一小片碎瓷，瓷片上残留着暗绿色的油渍，“磷火油。遇空气自燃。归鹤的丹房里从来不存磷火油，他炼的是木属性丹药，磷火油是金属性矿物提取物，两种属性相克。”

宁知微接过碎瓷片。瓷片边缘有一道极细的弧线，是瓶子底部的弧度。她翻过瓷片，背面粘着半枚残缺的标签，残留的笔画隐约能拼出一个“秦”字。

“秦。是秦先生？”她抬头。

“不能确定。但磷火油瓶的瓷质是青炉谷药局统一配发的，批号显示是四年前正月十四日领出。”陆承药推了推眼镜，“失火是正月十五。领油和着火隔了一天。领油人的签名被熏黑了，但领用记录上有一行备注，‘送第七号丹房’。归鹤本人没有领过磷火油。”

李无咎蹲到炉膛前。炉底残灰中泛起极细碎的金色碎屑，不是混在灰里的，是从灰的内部慢慢渗出来的。归鹤在丹炉被强制封炉之前，将一样东西打碎混进了残灰。

他用墨斗线探进去。金屑在线上聚成一行字：

徒儿。炉底残灰中的寒铁矿物基可以中和古树根屑的扩散冲动。配合患者自身须根入药，可压制木化一至三年。缺的那味药引在我手里，古树第一年的初生根须。被韩九章的人放火烧炉那晚我从实验台抽屉里抢出来塞进了口袋。但他把我赶出谷后搜了我的住处，没找到。我放在周家案给你的镇邪符夹层里了。那纸符表面是镇邪经文，对着左眼逆光看，夹层里有实验数据。韩九章截获了丹房残存数据，但他不知道我在两个案子之间架了桥。

李无咎把纸条攥在手心。他的左眼，在周家案里被当成容器接过三十六道名印的左眼，归鹤在上面留了能读取夹层信息的能力。不是恩赐，是借器官传消息。他师父把证据拆成三份：青炉谷的残灰、周家符纸的夹层、矿坑石板的年轮。韩九章截获一份以为够了。他不知道还有两份在等他徒弟。

“他把真相藏在三个地方。”宁知微说，“怕被人一次性全部毁掉。”

“也对也不对。”李无咎站起来，炉灰从他指缝间漏下去，“他不信任任何人。包括他自己。所以他不敢把所有话当面说清，他怕哪天自己先死了，真相跟着一起埋。他把证据分散，至少会有一个活到最后。”

宁知微没有接话。她从炉壁上把归鹤未烧完的实验笔记逐页拍下来。归鹤在每一行配方旁边都有极为苛刻的备注，每种药材的道地产区、采收季节、干燥天数和入炉顺序。这个人在炼丹上一丝不苟，在人事上漏洞百出。

一张贴在炉壁内侧的纸条引起她的注意。纸条上写着四味药引的正品特征比对：正品古树根屑呈灰褐色，含微量寒铁共生矿；韩九章提供的假灵芝呈黄白色，外裹糖衣中和寒铁反应。备注：糖衣溶于丹火后释放甜味剂，掩盖古树根屑的土腥气。此掩味术为韩九章独创，归鹤三年前在同乡丹药交流会上见过他演示。

“他把韩九章的底摸得极清楚。”宁知微指着备注，“连糖衣的比例都标了。但他为什么不直接告诉病人？”

“因为他怕说了之后病人去找韩九章对质。韩九章会怎么做？”李无咎折好纸条，“他会说归鹤诬陷同行，然后把你父亲和其他服药者列入黑名单，把养护从免费变成收费，或者直接停止养护，让木化加速。”

“所以归鹤选择先稳住患者，同时收集证据。但他没来得及收集完就被封炉了。”

“对。他被封炉的那天晚上韩九章已经拿到了青炉谷的限期整改令。归鹤的实验记录一旦正式提交监察司，韩九章的整条假药链都会被追查。所以他抢在归鹤提交之前断了归鹤的通道。”

铁算盘翻开因果簿，在宁怀川的页面旁边另开了一栏，“归鹤真人·未完成举证”。他把归鹤留在炉灰、符纸和石板上的三条证据逐一编号录入：证据一，炉底残灰寒铁成分分析；证据二，符纸夹层古树根屑实验数据；证据三，矿坑石板年轮标注及名印丝线。三份证据互相印证，缺一不可。

洞外传来脚步声。

不是陆承药的徒弟。脚步声很轻，布底鞋踩在碎石上几乎没有声音。万应楼的代理人。不是昨天那个灰袍中年人，这个是女的，三十来岁，穿素白长衫，头发挽成简单的髻，没有首饰，没有纹身，看起来像普通的药铺掌柜。但她手腕上的那串九枚铜环，铜环内侧刻的是监察司药印备案号。

“宁姑娘。韩先生让我带句话：第七号丹房的炉底残灰含寒铁矿物基，确实能压制古树根屑的扩散冲动。但这方子只能压一到三年。三年之后患者对寒铁产生耐受，压制失效，木化会以三倍速率反扑。到时候别说逆木方，就是直接把患者泡在寒铁水里都不管用了。”

她站在洞口。没有进来。阳光从她背后照进来，把她的影子拉进丹房里，正好压在归鹤被烧焦的办公桌残骸上。

“韩先生的提议是：万应楼从公共储备池中划出百分之十二的份额，专门用于定期稀释患者体内的寒铁沉积。寒铁沉积每三年稀释一次，木化就能被无限期压制。不需要割须入药，不需要忍受每次取须根时的疼痛。宁庄主坐在竹椅上就能再多活二十年。费用由互济共保覆盖，宁家不需要多出一文钱。”

“条件。”宁知微没有回头。

“条件很简单。太平观把逆木方的完整配方交给万应楼，由万应楼统一配发。宁姑娘保留药理论证权，万应楼保留配方量产权。韩先生的原话是，‘归鹤的方子是好的。只是他没有人手把它做下去。我们替他做。’”

宁知微转过身。她看着白衫女子手腕上的九枚铜环，铜环内侧的监察司编号在炉火残温下泛着暗红色。

“你叫韩九章‘韩先生’。你是韩家的人？”

“不。我姓林。林蘅。韩先生是我老板，不是亲戚。”

“好。林蘅。帮我转告你老板三件事。”宁知微竖起一根手指，“第一，逆木方的配方是归鹤的，不是太平观的。归鹤本人授权了谁我没有权力替他决定，但我有权力不放给你的商业量产。”

竖起第二根手指。“第二，寒铁耐受性我已经在父亲的血清中测过了。三年期是个估值，实际耐受窗口因人而异。你刚才说的‘压制失效后三倍速率反扑’，这个数据是韩九章自己算出来的吧？你们在临床数据里删掉了一个变量：寒铁矿物基与古树根屑的天然共生关系。如果患者同时摄入寒铁和古树根须的活体提取物，寒铁耐受可以被延长到至少七年。这个变量归鹤在丹方备注里写了，你们知道吗？”

林蘅的嘴唇微微抿紧了一下。

“第三。”宁知微放下手指，“你刚才提到公共储备池的份额是百分之十二。这个数字恰好是我父亲在养护合约期间被抽取的总药田生机占整个副印网络抽取总量的百分比，百分之十二。你们用他自己被抽走的生机作为‘配额’，反过来劝他合作。这不叫互济共保。这叫拿贼赃做抵押，再借一次。”

林蘅沉默了三秒。然后从袖中取出一张折好的纸，放在洞口石桌上。

“这是韩先生给归鹤真人的亲笔信。四年前写的。没寄，因为归鹤真人封炉第二天被驱逐出谷，住址不明。信的内容是韩先生对归鹤真人实验样本被烧毁一事表示遗憾，并提出以商业合作方式续接归鹤的研究。信末附了七条合作条款。第一条就是，所有合作方签署长期养护合约，息诉息访，互不追究过往。”

她转身朝洞外走去，走到半路停下。

“宁姑娘。韩先生让我最后带一句实话。归鹤的逆木方最多只能治你父亲一个人。但韩先生签出去的延寿丹契书不止一张。其他服药者没有宁庄主这么幸运，他们不认识归鹤，拿不到逆木方，也等不到太平观的人来查现场。他们只能靠万应楼。你觉得万应楼的养护合约是剥削，但对他们来说，那是唯一还能讨价还价的东西。太平观修好了一桩差评很光彩。那剩下的呢？”

她走了。脚步声在碎石路上渐渐消失。

章末，陆承药从丹房角落翻出了归鹤失火那晚的最后一件遗物，一包被烟熏黄了的护脉针包装纸。纸片内侧用炭笔写了半行字：

宁庄主的药引是假货。韩，

后面被烧断了。归鹤在失火前最后几秒还在写这封信。他没有写完。
