# 第81章 客户没有说完的话

河边的月光把水面上那行柳村人的名字照得发白发亮，像一行沉不下去的浮标。

曹三娘是最后一个开口的。她的竹杖敲在青石上，声音比其他人的都沉——不是重，是竹杖中空的竹节里灌了水。她的房子在柳村最低处，水没过了竹杖底端的铜箍，走路时竹节会自己吸水。她每次敲地都能听见竹筒里水晃荡的声音，像一个人用竹管喝汤喝到碗底剩下的最后一口。

"我没说实话。"她把竹杖立在柳村那面歪墙上。墙上还能模糊辨认出一行旧标语——"人定胜天，柳村永固"。标语是十二年前归鹤封闸那天她领着村里女人用石灰浆刷上去的。当时石灰不够，她用自己灶房里的米浆兑了剩下的一半。米浆干了以后字迹比石灰更白。今天水泡了十二年，石灰掉光了，"人定胜天"只剩下米浆写的"人"字最后一捺还贴在墙上。米比石灰撑得久。

"归鹤封闸那年我帮着往闸门缝里塞过碎麻布。因为他说闸门封住了水就不往上走了。我塞了三天，手指头被闸门的铁锈割了三四道口子，我不在乎。我只要柳村不被淹。"她停了停，把竹杖横在膝盖上，"水往下游走的时候，我也知道下游会淹。但我没想过下游淹的是谁的田。下游对我只是个方向。不是具体的人。"

"你现在知道了吗？"

"知道了。下游淹的是王大喜的田。王大喜是具体的人。他今天第一个签字放水，他的田地里泡的水先往他家田里渗。"她从怀里摸出半块被水泡烂的旧烙饼，放在王大喜脚边的田埂上。饼是昨天烙的，今天水泡了以后已经成了一团面糊，但她还是放了下去。"这是一点干粮，不成敬意。"

章末。王大喜弯腰捡起面糊放进嘴里咽下去。咽下去之后他把田埂上被水泡软了的泥捧起来，在柳村的歪墙脚下重新糊了一层。他糊完没有立刻站起来——蹲在墙根下，用手指把泥压平。压平的手法和他每年开春在自家田里压稻秧的手法一模一样。拇指先按，食指跟，中指收。三个指头在泥上留下的印子方向和稻秧的方向一样，都是朝下游。压完后他在泥上擦了擦手。手上的泥混了他田里的土——他田里的土是褐的，柳村墙根的土是灰的。混在一起是一层中间色。像水停在两方田埂之间的那段颜色。

泥糊在"人"字最后一捺的底端，把这个米浆写的字接了一截。不是接标语——"人定胜天"是假话。这个人是"人们"的人——柳村的人和下游的人是同样的人。

但曹三娘的话还没说全。她握着竹杖的指节在月光下泛白——不是因为用力，是因为她在刚才开口的时候把竹杖底端从泥里拔了出来。竹杖底端原本插在她家院墙脚下一个旧排水沟的出口处。排水沟被她用碎砖和旧蓑衣堵了整整十二年了。堵了之后下雨天院子里的水排不出去，会从门槛底下倒灌进灶房。她每年雨季都要用三块抹布轮流吸灶房地上的积水，拧在木桶里倒回院子里。水倒回去又从门槛底下流回来。一个循环。十二年了。她不疏通排水沟是因为排水沟的出口正对着柳村下游方向——她怕一旦重新挖开沟，水会顺着老沟直接冲到下游王大喜家的田里。一份被堵在自家院子里反复循环的水，来回花了十二年不敢放出去。今天她第一次松开了堵排水沟的那块旧蓑衣。蓑衣从沟口拿开之后积压十二年的浑水一下子冲了出去，在月光下沿着几乎被杂草淹没的老沟流向下游方向。水流的速度不快，但很急，急到把她插在沟边的竹杖冲歪了半寸。

"放吧。再不放，我灶房里的米缸也要烂了。"她站在沟边，赤脚踩着被水流冲松的泥，脚底下有一块她自己年轻时埋的旧磨刀石。磨刀石已经嵌进泥里了。她弯腰把磨刀石挖出来，放在王大喜刚糊好的那截泥上。磨刀石的表面磨成了一道凹槽——十二年里她在这块石上磨了无数把剪刀和菜刀。凹槽的方向正朝着下游。

磨刀石放下的那一刻，柳村歪墙上那幅"人"字的最后一捺被泥糊住之后开始往下渗水。不是漏水，是歪墙背面的泥砖在月光吸潮之后开始自己往外析出这些年封在砖缝里的旧雨水。雨水顺着墙流到磨刀石的凹槽里，再从凹槽流到王大喜田埂的方向。柳村的墙不蓄水了，它把自己十二年在排水沟堵死的情况下从地底下偷偷吸进来的地下水全吐了出来。吐的不是想淹下游的恶意——只是一面歪墙吸不了那么多。它受够了，它吐了。水沿着磨刀石的旧痕流成了一条线，月光下那道水痕像磨了十二年的刀刃上终于能割开的第一道亮光。

阿沅在远处堤坝上看见这道水光。她从竹排上拔下一片自己刚脱落的旧鳞，用指尖掐了一个月牙形的缺口，然后对着水光来的方向——下游——吹了一口气。旧鳞在月光里翻了几下，落到了王大喜瓢里的半斗水中。鳞在水里溶成了几百粒细小的鳞粉，从瓢沿溢进田里。鳞粉不是药，是河神的体温。她用自己近千年的河底体温替这半斗刚从上游放下来的水测了一回水温——水温合适，不会冻伤田里的麦种根。她以前把体温用来制冷不让水漫堤；今天她把体温用来暖水。暖水不是赦免，是下游的人第一次没有被淹也没有被冷着。
