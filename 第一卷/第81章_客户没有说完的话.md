# 第81章 客户没有说完的话

泄洪名单摊在古堤上，十二页，每页记录了每年一次的泄洪。年年都是同一个月，雨季前。年年都是同一个方向，上游柳村。年年都有监察司的批文章。年年都有归鹤的签字，执行人：归鹤。但年年归鹤都在备注栏里写同一个词：反对。反对无效。批复。

李无咎把名单推给周太公。“你看过这份名单吗。”

“没有。我只知道闸门焊死了，不知道监察司每年在批泄洪。”

“那你知道归鹤每年都在写反对吗。”

周太公沉默。“不知道。他每次来，只在堤上站一会儿。量一下水位。记一下数据。然后就走了。我以为他只是例行巡查。他从来没说过他在反对。”

“因为说了也没用。”阿沅抬起头，“归鹤被监察司的批文压着。批文上写的是，镇水符压水，水往下游排。归鹤在设计符的时候本来留了一个可调整的泄洪方向。但监察司在批文上把泄洪方向写死了，只能往上游。归鹤每年在备注栏写反对，监察司每年批复：反对无效，继续执行。写了十二年。他所有的反对都被压在了档案里。你们今天才看到。”

曹三娘从堤上捡起一条长人牙的鱼。鱼嘴里的人牙掉了两颗，掉在古堤石板上。牙齿的牙髓里嵌着一丝极细的墨迹。宁知微用银针挑出墨迹，墨迹在琉璃片上化开，不是墨，是归鹤的签名。他把自己的名字写进了鱼牙里。十二年来，每一条吞了祈愿纸的鱼，牙齿里都有他的签名。签的不是“归鹤”，是“此处应停”。

“他在鱼牙里刻字。刻了十二年。不是术法，是留言。他知道自己拦不住泄洪，但他想让后来捞起鱼的人知道，他不同意。他用被鱼吞掉的祈愿纸背面刻满了速查。在鱼牙里刻满了此处应停。在柳村石碑背面刻了速查。他把能留的线索全留了。但每一个线索都被堵在了同一个地方，没有人翻。”

三村族老们把泄洪名单传着看。每看一页，脸色就白一分。不是被归鹤的反对震惊，是被自己的无知震惊。十二年了。他们以为焊死闸门只是保下游太平。不知道下游太平的代价是监察司每年都在批泄洪。他们以为自己在帮归鹤，其实在替监察司当焊工。

“归鹤有没有找过你们，让你们开闸？”

周太公的手按在拐杖上。“找过。十二年前压符之后第三年，他来找过我。说阵基被铁锈腐蚀了，要重做。要开闸放一次水。我没同意。我说开闸下游会淹。他说只放一季，水从蓄洪区过。我说蓄洪区已经种了稻，不能放。他站了很久。最后说，那我自己想办法。后来他就没来找过我了。”

“他自己想的是什么办法？”

“不知道。只知道第二年，他在古堤下面多压了一层东西。不是符。他从来没说那是什么。”

李无咎走到古堤下。量灵尺在阵眼旁边测到了一层隐藏结构，在镇水符下方三尺处，有一块归鹤额外埋入的铜板。铜板上刻着：此处为泄洪转换节点。可将泄洪方向从上改为下。需监察司批准。或无监察司批准，由三村、柳村、河神三方联名签字，手动启动。归鹤。

“他留了一条出路。”李无咎把铜板上的字念完，“不是符。是开关。归鹤在镇水符下面偷偷埋了一枚手动转换节点。只要三方联名，就可以绕过监察司的批文，把泄洪方向从上游改成下游蓄洪区。但需要三方都签字。三村、柳村、河神。”

“他为什么不早说？”

“因为他怕。怕说了之后监察司会发现。监察司一旦发现他在符底下埋了违规节点，会派人来拆。拆了之后连唯一的手动转换机会都没了。所以他把节点藏在铜板里，不告诉任何人。只等有人翻出来。今天翻出来了。”

阿沅从河床上站起来。裂缝还在胸口，但泥不再掉了。“我签。”

曹三娘替柳村签字。她的手很稳，签了十二年泥上刻字练出来的。她在铜板上按了柳村的手印。

周太公拿起笔。他的手在抖，不是怕签字，是笔太重了。铜板的材质是冷的，笔尖划上去刮出一道极细的铜痕。签完之后他把三村族印盖在旁边。和焊死闸门的印一模一样，但这一次，印不是用来焊的。是用来放的。

三个签名同时落入铜板，铜板开始发出低沉的嗡鸣。不是术法，是齿轮。归鹤在铜板下面埋了一套极简陋的纯机械转换装置。齿轮在河底的淤泥里转了十二年，生锈了，但还能动。齿轮转动的声音从河底传上来，像一颗生了锈的心脏重新开始跳。焊死的闸门在齿轮的带动下开始松动。不是完全打开，只是松了一缝。一缝就够了。

水从那一缝里流出来。不是往上游，是往下游蓄洪区。水流很细，只有手臂粗。但方向对了。下游稻田边缘那条白线在水流触到的同时散开了。河面上浮出新的名字，不是淹死的名字，是签了字的名字。王大喜。曹三娘。周太公。阿沅。每一个签了字的人，名字都浮上了水面。不是诅咒，是登记。归鹤在铜板上刻的最后一行字：签字者，因果自担。水润其田，亦淹其田。无怨。

章末，李无咎把归鹤留在鱼牙里的最后一颗牙撬出来。牙齿里不是签名，是一张极小的纸。纸上只有一行字：徒儿，监察司的批文我没拦下来。三村焊的闸门我没打开。柳村的泥字我没刻完整。我留了节点。但我不敢打开。不是因为怕监察司。是怕打开了之后，水淹了下游，下游的人会来砸我的符。砸了符，水就没方向了。那时候上下游一起淹。我不敢选。所以我留给你选。

李无咎把纸条折好放进袖中。
