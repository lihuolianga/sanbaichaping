# 第3章 一个时辰买一张脸

李无咎在花轿杆上发现了名册。

不是纸，不是竹简。是红绸——四根轿杆上缠着层层叠叠的红绸带，从最里层到最外层，缠了密密麻麻不知多少圈。每一圈都写满名字。朱砂写成，字迹各不相同。最外层的墨迹还很新，往里翻几圈就开始褪色，翻到最里层时红绸已经变成了黑褐色——不是褪色，是被血浸透了太久。

“这些名字是怎么回事？”他问周红玉。

“十一年前轿杆上只缠了一条红绸——写的是我和沈见川的生辰八字。后来每过一年，绸带便自己多缠一圈。上面的名字也越来越多。我数过——一共四十五条。”

李无咎用左眼看去。每一圈红绸上都系着一根因果线，从轿杆延伸出去穿过无面人的胸口，最终全部汇入周宅深处。线有粗有细，最粗的那几根来自那八个轿夫——他们不单单是被婚书抹了名印的人，还是和周家有过正式雇佣关系的家仆。工钱木牌、雇佣契约、名印——三样东西被婚书拧成了一条绳。

无面新郎走到他面前，指着自己那张什么都没有的脸。

“现在你告诉我——你要的‘脸’到底是什么？”李无咎拔出量灵尺抵在无面人眉心，“肉脸？面貌名印？还是婚契身份？”

尺中朱线猛地震颤。先落在“人”字——此人体内仍有微弱生机。又跳到“魂”——魂魄不完整。最后停在“名”字上抖个不停。活人五官长在肉上，鬼物相貌化在怨里，但眼前这个无面人既不是活人也不是鬼——他是被精准地沿着面骨边缘剥离了面貌名印，架在生死之间充当婚书的识别替身。

“你不是丢了脸。你是被借了名字。沈见川这个名字被刻在工钱木牌上那一天起，你就被婚书列入新郎候选。归鹤剥的是你的面貌名印——他切断了婚书识别你的路径。但他没有毁掉你的脸。他把脸封存在核心婚书里，和其他三十六个人的名字锁在一起。只要核心婚书还在周宅，你的脸就还在那里。”

无面人的手颤了一下。那张什么表情都做不出的脸上，忽然裂开一道细缝——从左眉骨劈到下颌。缝隙里没有血，没有肉，只有一片和左眼完全相同的空虚，像一张被折了太久的纸第一次试着展开。

铁算盘的声音就在这时变了。不是从因果簿里传出来的——是从李无咎肩头。他低头一看，一个不足一尺高的小老头正站在他肩上，灰袍长须，下巴尖尖，怀里抱着一把比他自己还大的铜算盘。算盘珠子噼里啪啦响了一阵，小老头清清嗓子开口。

“老朽铁算盘。因果簿伴生核算灵。当前案件责任比例已初步完成——归鹤真人四成。委托前未充分告知风险，处理时留下结构性故障，事后未回访。周家三成——周敬堂知情但隐瞒核心婚书位置，私自购买九章行续嗣保险，持续抽取婚役生机十一年。未知第三者三成。”

“什么第三者？”

铁算盘从无面新郎脖颈处挑起一缕残留灵气，算盘珠子往上贴了一下。九个小环的虚影从灵气中浮现，首尾相扣。环影极小，却极清晰——每一环都在缓缓旋转，转动时发出类似钟表走秒的极小声响。

“九环印。”铁算盘拨了一把算珠，“周红玉当初按手印签的是代兄承劫契——自愿替周承恩分担病气。但她的契书被附加了这枚九环印，代兄承劫被改写成群体婚役。三十六名在周家工籍上的女性与沈见川这个账房，全被拖入婚书。归鹤真人十一年前留下的账页最后一截便是被这枚印记撕走——撕口整齐，九个环相扣。这是术法层面的强制扩责，非太平观手法，非周家祖传术式。来源——韩九章。”

李无咎把量灵尺移到无面新郎颈侧。尺中朱线刚触到那道环颈焦痕便剧烈跳动——归鹤当年烧婚绳时留下的术法残留。先烧绳断开周红玉和沈见川之间的婚契牵连，再剥脸切断婚书对新郎的识别。两道工序，每一步都是在拆雷。但雷拆到一半，核心婚书被周敬堂藏进了周承恩体内——归鹤拆不动了。

“他拆不动为什么不硬拆？”

“因为硬拆会将三十六名婚役连同周承恩一并毁掉。归鹤只能先封存回头村，把脸和婚役锁在幽隙里，等找到九环解法再回来。他没找到解法，但他把找解法的线索留给了你——符纸背面那行字：先找账房，不要先找新郎。”

李无咎从袖中取出那张符纸，翻过来用左眼细看。血迹之下那行字此刻又多浮现了一句。师父的笔迹，潦草得像赶着逃命——沈见川在周家账房的用工契未被九环印覆盖。用工契是周家和沈见川之间的独立劳务契约，不受婚书约束。你若先找到账房身份，便能以周家雇员的名义向婚书索赔——而不是以新郎的身份。若先找新郎，你会把所有人的名印当成沈见川的脸一并修复。救一个，杀三十六个。

“这老东西。把说明书藏在背面，把藏说明书的方法写在说明书里，把读说明书的条件设定在‘必须瞎了左眼才能看见’。套娃都没他这么能套。”

李无咎把符纸折好，走到花轿侧面，用量灵尺沿着轿杆一寸一寸敲过去。每一圈红绸都在敲击后发出不同音高——低沉的表示名字还在，清脆的表示名字已经淡了。四十五条名字，十一条音高发脆。那十一个人已经被抽到只剩最后一丝名印残迹，下一个七日之内就会彻底消失。

“四十五条名字中有十一人在本周内会失去可识别身份，”铁算盘翻动因果簿，“按照归鹤真人设定的优先级——优先救还能救回来的。”

“周红玉算不算还能救回来？”

“她不算救——她本来就是死人。她是委托人，不是受害者。受害者是这四十五个被她父亲填入婚书的人。你要还的不是周红玉一个人的新郎——是这四十五个人的名字。”

李无咎收起量灵尺。“那就从账房开始。沈见川。”

他推开周宅大门。门后是一面铜镜，铜镜立在正厅中央，镜面擦得雪亮。他下意识看了一眼——

右眼里，镜中站着一个十七岁的年轻道士。青色旧道袍，木簪束发，脸上三道血痕，嘴角挂着似笑非笑的神情。

左眼里，镜中那张脸是完整的。但左边眼眶里什么都没有。不是闭着，不是瞎了，不是被遮住——是空的。像有人用刀把那部分存在从世界上剜掉了。眼白、瞳孔、虹膜，全部消失。只剩一个光滑的凹陷，边缘整齐得像被勺子挖掉了一块布丁。

李无咎抬手摸了摸左眼。手指触到了完整的眼皮和湿润的眼球。但镜子里那只手摸到的地方，依旧是空白。眼球还在脸上，因果层面已经被剥离了。他的脸能摸到，不能被看见——所有进入周宅的人，都看不见他左半张脸的存在。

正厅深处传来拐杖敲地的声音。一下，一下，很慢。一个头发花白的老人在两名家仆搀扶下从影壁后走出，穿着暗红寿纹长袍，身形消瘦，目光锐利。他先看向周红玉——眼中浮出水光。然后转向李无咎，目光落在右半张脸上，慢慢滑向左侧。

他的表情没有变化。不是冷漠，是根本看不见。那个位置的因果已经被剥离了，对他而言李无咎的左脸就是空气。

“这位道长，”周敬堂开口，“为何戴着半张隐身符？”

李无咎笑了笑。“因为有人欠了我的脸，还没还。周老爷——你就是周敬堂？”

“正是。”

“正好。我来查一下你们周家的婚书。看看上面除了你女儿、账房、三十六名女工之外——还有没有我丢的那只眼睛。”
