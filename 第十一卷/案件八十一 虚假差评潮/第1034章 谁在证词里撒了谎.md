# 第1034章 谁在证词里撒了谎

宋良的死，李无咎没有告诉任何人，但他把那张契纸，摆在了漏案时间线的最前面。

时间线铺在长案上——宋良的求救，从他第一次投出，到系统标低危，到沉入队列，到死亡——一条线，明明白白。线旁边，是另一个人的名字——那个屋顶漏水的老人，还有那个被误封的年轻人。

"诸位。"李无咎站在时间线前，"宋良，城南人。三年前，他家的井干了。他投了求救——系统标低危——没人看。他投了三年——死在那口枯井边。他的死，和这场假潮，有没有关系？"

"先生！"一个核验员站起来，"李先生！小人不认！小人核过宋良的投诉——他是低危，可小人是按系统排的序——小人没有不看他！"

"你按系统排的序？"李无咎说，"那系统，是谁建的？"

"是——"核验员顿了一下，"是售后堂建的。"

"售后堂建的。"李无咎说，"像是——像是系统是售后堂建的，你按它排序，可它把宋良标了低危——像是——像是你按系统做的，系统按它自己做的。像是——像是谁都没有'不看他'——可他就是没人看了。"

第一步，是问核验员。

"先生！"核验员急了，"李先生——小人核过宋良的契纸——小人真的核过！小人记得——小人在他投第四次的时候，把他的契纸，抽出来看了一眼！"

"你抽出来看过？"李无咎说，"那你看完，做了什么？"

"小人——"核验员的声音低下去，"小人看了——小人觉得他家的井，是真的干了——小人想把它排进紧急队列——可小人的权限，不够。像是——像是只有系统，能给契纸升级——小人的权限，只能按系统的分级处理。"

"你的权限不够。"李无咎说，"像是——像是你看见真话了，可你的权限，不让你救它。像是——像是你核过，可你没救成。"

"先生！"核验员说，"小人——小人核过，可小人的权限，只能做系统让小人做的。小人——小人觉得，小人没有责任！"

"你有没有责任，"李无咎说，"一会儿再说。可你先记着——你看过宋良的契纸，你知道他家的井干了——可你没救成他。像是——像是你核过，是事实；你没救成，也是事实。两件事，都记着。"

第二步，是问旁观者。

李无咎又请来了几个旁观者——他们投过投诉，也见过假潮。

"诸位。"李无咎说，"你们——有没有见过宋良？"

"先生！"一个旁观者想了想，"小人——小人没见过宋良。可小人见过他那张契纸——像是——像是它被标了'重复'，在云里飘过。小人看了一眼——小人心想——'又是重复的'——小人就没看第二眼。"

"你看了一眼，心想'又是重复的'。"李无咎说，"像是——像是你看见了一张'重复'的标签，就没有再看它。像是——像是你没有错——可那张契纸的主人，死了。"

"先生！"旁观者脸色发白，"小人——小人不知道它是真的！它标着'重复'——小人以为，重复的都是假的！"

"重复的都是假的？"李无咎说，"像是——像是你信了系统——像是——像是系统说'重复'，你就信了——像是——像是你没想过——一个人急了，才会重复。像是——像是重复的，不一定是假的——可能是真急了。"

"先生！"铁算盘走过来，低声说，"先生——老夫核了宋良的时间线——有问题。"

"有问题？"李无咎说，"什么问题？"

"先生。"铁算盘说，"宋良的投诉，他投了三次。可记录上——他投'第四次'的时间，和他投'第三次'的时间——之间，隔了半年。像是——像是他半年没投——像是——像是记录上，有人在他死后，补了一次'重复提交'。"

"死后补的？"李无咎说，"谁补的？"

"像是——"铁算盘说，"像是——像是系统自己补的。像是——像是系统按'同源'，把他第三次的投诉，归成了第四次——像是——像是系统，把一个死了的人，标成了'重复提交'——像是——像是他的死，就变成了'因重复提交被降权'——像是——像是他的死，就怪不到系统头上了。"

"把死人的投诉，标成重复？"李无咎说，"像是——像是系统，在替自己脱责。像是——像是它先把宋良标低危，又把他标重复——像是——像是它用两枚印，把宋良的死，盖成了一枚'他咎由自取'的印。"

第三步，是问旧案客户。

李无咎又请来一位旧案客户——三百客户里的老人，见过最早的差评制度。

"先生！"客户说，"李先生，老夫见过最早的差评——那时候，没有系统。每一个差评，都有人看。像是——像是看的人不多，可每一张，都有人看。"

"每一张，都有人看？"李无咎说，"那现在呢？"

"现在——"客户说，"现在，差评多了。像是一天，几万张。像是一个人，看不过来。像是——像是就得有东西，替人看——像是——像是系统，替人看。像是——像是系统说哪张急，就哪张急；系统说哪张不急，就哪张不急。"

"系统替人看。"李无咎说，"像是——像是人，把'看'，交给了系统。像是——像是系统，把'急'，排了序。像是——像是排序的时候，把宋良，排到了最后。"

"先生！"宣传司的人，忽然从人群外走进来。他穿着一身官服，身后跟着几个差役："李先生！九霄宣传司有话——这批假差评，确实有宣传司的接口参与。宣传司承认——可宣传司是被人冒用了接口！像是——像是真正的造潮者，藏在幕后！李先生——应当立刻，把那些真投诉母本，全部抓起来！他们是造潮的共犯！"

"抓母本？"李无咎说，"母本，是三百多个普通人，说过的话。你把他们的真话抄走，拼成假投诉——然后，你要抓他们？像是——像是你把受害者，当成了共犯。"

"先生！"宣传司的人说，"李先生——他们的真话，被用来造假投诉——他们就脱不了干系！"

"脱不了干系？"李无咎说，"你偷了人家的刀，杀了人——你要抓的，是刀的主人？像是——像是母本被盗者，是受害者，不是共犯。像是——像是他们要作证——不要被抓。"

"先生！"宣传司的人说，"那李先生——这场潮，就抓不到人了？"

"抓得到人。"李无咎说，"像是——像是造潮的人，抓得到；像是——像是偷话的人，抓得到；像是——像是我们自己的分级，把我们自己的宋良，埋了——这笔账，也抓得到。像是——像是抓人，不能只抓'好抓的'。"

第四步，是铁算盘的核验。

李无咎把四组证词——核验员的、旁观者的、旧案客户的、宣传司的——全数递给铁算盘。

"铁算盘。"李无咎说，"四组人，说的都对不上。谁在撒谎？"

"先生。"铁算盘拨了一遍算盘，"老夫只能确认——每个人，都说了自己相信的真话。像是——像是核验员相信，他核过，所以没责任；像是——像是旁观者相信，'重复'就是假的；像是——像是客户相信，系统替人看是应该的；像是——像是宣传司相信，他们只是被冒用。"

"都是真话？"李无咎说，"可真话，怎么拼不出真相？"

"因为——"铁算盘说，"每个人，都只看见自己那一环。像是——像是核验员看见他核过；像是——像是旁观者看见他看过；像是——像是客户看见系统替人看。像是——像是没人看见——宋良，最后那一次，是谁，把他标成了'重复'。"

"像是。"李无咎说，"像是——像是真相，不在谁撒谎——在谁都没看全。像是——像是我们每个人，都看了一环，可没看全一条线——像是——像是宋良，就是断在那条没人看全的线上。"

"先生！"裴照夜忽然跑进来，"先生——随机复核签——随机复核签，自己启动了！"

"自己启动？"李无咎说，"谁启动的？"

"没人。"裴照夜说，"像是——像是复核签，按系统的默认规则，自动启动了！像是——像是它随机抽了一张契纸，要求复核！"

"抽了谁？"李无咎问。

"先生！"裴照夜的声音发紧，"它抽中的——是那位老妇人！是那位母本被盗、铺子被砸的老妇人！像是——像是复核签，要求她提供证据，证明她的话，不是假投诉！像是——像是她不肯——因为那话，本来就不是她投的！"

"抽中受害者，要求她自证？"李无咎说，"像是——像是系统，不问真话是谁偷的——它只问，受害者，能不能证明自己没偷。像是——像是它把举证的责任，压在了被偷的人身上。"

"先生！"裴照夜说，"老妇人不肯公开她的隐私——她说，她不想让人知道，她十年前说过那句话。复核签——就开始惩罚她了！"

"惩罚？"李无咎说，"像是一张自动签，抽中一个受害者——因为她不肯公开隐私——就要惩罚她。像是——像是这套复核，不辨真假，只辨谁肯配合。像是——像是它转起来的第一签，就抽中了最不该抽的人。"

风从窗外吹过来，吹得那张随机复核签，在长案上，转了一圈，又停下。签上，老妇人的名字，还压着——像是那枚签，正等着它要的答案。

"先生。"宁知微轻声说，"这一签，抽错了。"

"抽错了。"李无咎说，"像是——像是它不只抽错了人——像是——像是它证明了——一场没有人工的复核，会先伤害最不肯配合的人。像是——像是这场潮，不光有假潮——还有一套，自己转起来的机器——正在替敌人，欺负我们的人。"
